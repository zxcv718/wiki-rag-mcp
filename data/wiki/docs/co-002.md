# 전사 행사 신청 취소 안내

## 대상

이 문서는 사내 세미나와 전사 행사 참가 신청자에게 적용합니다. 전 직원과 외부 협력사 모두 같은 기준을 따릅니다. 다만 행사별 운영 방식이 따로 공지된 경우에는 해당 행사 안내를 우선 확인합니다.

이 문서는 참가 신청의 취소, 대기자 반영, 노쇼 처리 기준만 안내합니다. 행사 내용, 참석 대상, 비용 처리 여부, 출입 안내 등은 각 행사 공지에서 확인합니다.

## 취소 기준

행사 참가 취소는 행사 시작 48시간 전까지 신청 페이지에서 직접 처리할 수 있습니다. 이 구간에서는 별도 승인 없이 본인이 취소하면 즉시 반영됩니다.

48시간이 지난 뒤에는 신청 페이지에서 직접 취소하지 말고, 주최 부서 메일로 취소 사유를 보내야 합니다. 주최 부서는 메일 확인 후 좌석 운영 상황에 따라 취소를 반영합니다. 행사 준비가 이미 진행된 경우에는 취소 요청 시점과 사유가 함께 기록될 수 있습니다.

사전 연락 없이 참석하지 않는 경우는 노쇼로 처리합니다. 노쇼가 월 2회를 넘기면 다음 달 행사 신청 시 우선순위가 내려갑니다. 우선순위가 내려간 경우에도 신청은 가능하지만, 좌석이 제한된 행사에서는 대기 순번 또는 승인 순서에 영향을 받을 수 있습니다.

반복적으로 일정 변경이 예상되는 경우에는 신청 전에 참석 가능 여부를 먼저 확인해 주시기 바랍니다. 좌석 수가 적은 행사일수록 늦은 취소와 노쇼의 영향이 큽니다.

## 대기자 반영 방식

대기자는 결원이 생기면 신청 순서대로 자동 승격됩니다. 별도 재신청이나 개별 확인 요청은 필요하지 않습니다.

승격 알림은 시작 3시간 전까지 발송합니다. 알림을 받은 뒤 참석이 어려운 경우에는 즉시 취소 절차를 진행해야 다음 대기자에게 자리가 넘어갑니다. 시작 직전 결원이 생긴 경우에는 운영상 추가 승격이 어려울 수 있습니다.

대기 상태에서는 참석이 확정된 것이 아니므로, 참석 확정 여부는 알림을 기준으로 확인합니다. 주최 부서는 좌석 상황에 따라 대기 인원을 조정할 수 있으나, 기본 원칙은 신청 순서 유지입니다.

| 구분 | 처리 방식 |
|---|---|
| 직접 취소 가능 기간 | 행사 시작 48시간 전까지 신청 페이지에서 처리합니다. |
| 늦은 취소 | 주최 부서 메일로 사유를 보내야 합니다. |
| 노쇼 | 사전 연락 없이 불참한 경우로 처리합니다. |
| 대기자 승격 | 결원 발생 시 신청 순서대로 자동 승격됩니다. |
| 승격 알림 | 시작 3시간 전까지 발송합니다. |

## 신청자 처리 방법

1. 신청 내역에서 행사 시작 시각을 먼저 확인합니다.
2. 행사 시작 48시간 전까지이면 신청 페이지에서 직접 취소합니다.
3. 48시간이 지난 뒤이면 주최 부서 메일로 행사명, 신청자 이름, 취소 사유를 보냅니다.
4. 대기자일 경우에는 승격 알림 수신 여부를 확인합니다.
5. 승격 후 참석이 어려우면 바로 취소를 진행합니다.

주최 부서 메일 제목은 아래 형식으로 보내면 확인이 빠릅니다.

```text
[행사 취소 요청] 행사명 / 신청자 이름 / 행사일
```

본문에는 취소 사유를 간단히 적습니다. 대리 참석 요청은 받지 않으며, 신청자 본인 기준으로 좌석을 운영합니다.

## 문의처

행사별 취소 처리와 대기자 반영 문의는 각 행사 공지에 적힌 주최 부서 메일로 보냅니다. 공지에서 주최 부서 메일을 찾기 어려운 경우에는 전사 공지 스페이스의 해당 행사 게시글 댓글로 문의합니다.

신청 페이지 오류로 직접 취소가 되지 않는 경우에도 먼저 주최 부서 메일로 상황을 알려 주시기 바랍니다. 문의 시에는 행사명, 신청자 이름, 확인한 오류 화면 또는 상황 설명을 함께 보내면 처리에 도움이 됩니다.
