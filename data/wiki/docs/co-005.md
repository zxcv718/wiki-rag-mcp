# 본사 오시는 길

## 대상

이 문서는 전 직원과 외부 협력사를 포함해 본사를 방문하거나 우편, 택배, 미팅 일정을 확인해야 하는 사람을 대상으로 합니다. 성수 사옥으로 이전한 뒤의 기준만 안내합니다.

## 위치

새솔소프트 본사는 서울 성동구 성수동 새솔타워 8층에 있습니다. 사내 기준 본사 근무지는 2026년 4월 6일부터 이 위치로 적용합니다.

방문 일정 안내, 미팅 초대, 외부 전달 문서에는 아래와 같이 적습니다.

| 항목 | 내용 |
| --- | --- |
| 본사 위치 | 서울 성동구 성수동 새솔타워 8층 |
| 근무 시작 기준일 | 2026년 4월 6일 |
| 가까운 지하철 | 성수역 4번 출구 |
| 도보 소요 | 성수역 4번 출구에서 걸어서 7분 |
| 방문객 출입 | 1층 안내데스크에서 방문증 수령 |

건물명과 층수는 반드시 함께 적어 주시기 바랍니다. 외부 방문객에게는 “새솔타워 8층”을 그대로 전달하면 찾기 쉽습니다.

## 방문 방법

대중교통으로 방문하는 경우 성수역 4번 출구로 나온 뒤 도보로 이동하면 됩니다. 일반적인 보행 속도 기준으로 성수역 4번 출구에서 걸어서 7분 걸립니다. 초행길인 경우 건물명을 먼저 확인한 뒤 입구로 들어오면 됩니다.

건물 도착 후에는 아래 순서로 방문합니다.

1. 건물 1층으로 들어옵니다.
2. 1층 안내데스크에서 방문 목적과 방문할 회사를 말합니다.
3. 안내에 따라 방문증을 받습니다.
4. 출입이 확인되면 엘리베이터를 이용해 8층으로 이동합니다.
5. 방문 대상자에게 도착 사실을 알리고 안내를 받습니다.

방문객은 반드시 1층 안내데스크를 먼저 이용해야 합니다. 사전에 방문 일정이 잡혀 있더라도 바로 8층으로 올라가지 말고 방문증을 받은 뒤 이동해 주시기 바랍니다.

직원이 외부 손님을 초대하는 경우에는 손님에게 본사 위치, 성수역 4번 출구 기준 이동 방법, 방문증 수령 위치를 미리 안내해 주시기 바랍니다. 특히 첫 방문인 경우에는 건물명과 층수를 함께 전달하는 것이 좋습니다.

## 방문 전 확인 사항

방문 일정이 있는 경우에는 사내 담당자와 시간, 목적, 방문 인원을 미리 맞춰 주시기 바랍니다. 택배나 우편 발송이 필요한 경우에도 수령 부서와 담당자를 사전에 확인하는 것을 권장합니다.

외부 협력사 인력이나 면접 대상자, 고객사 방문객도 동일하게 본사 위치는 새솔타워 8층이며, 출입 절차는 1층 안내데스크 기준으로 진행합니다. 건물 내 다른 층에서 별도 접수를 요구받더라도 회사 방문 목적이라면 먼저 1층 안내데스크 안내를 따릅니다.
