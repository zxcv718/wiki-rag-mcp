# 사내 용어와 제품 한눈에 보기

## 대상
이 문서는 전사 공지 스페이스에서 협력사를 포함한 모든 사람이 함께 보는 안내 문서입니다. 새로 입사한 구성원, 부서 이동자, 외부 협력사 인력 모두가 같은 표현을 쓰도록 기본 용어만 짧게 정리합니다.

문서에 적지 않은 세부 정책, 운영 기준, 절차는 각 담당 부서의 별도 안내를 따릅니다. 이 문서는 자주 나오는 제품명과 협업 시 혼동하기 쉬운 표현만 빠르게 확인하는 용도로 사용합니다.

## 내용
아래 용어는 전사 공지, 회의 메모, 업무 설명에서 자주 사용합니다.

| 용어 | 뜻 |
| --- | --- |
| 솔페이 | 중소 가맹점용 결제·정산 SaaS입니다. 회사의 주력 제품입니다. |
| 솔북 | 매장 예약 관리 앱입니다. 솔페이와 결제가 연동됩니다. |
| 레드브릭소프트 | 개발 인력을 파견하는 외부 협력사 이름입니다. |

제품 이름을 문서나 공지에 처음 적을 때는 한글 이름을 먼저 쓰고, 필요한 경우 영문 표기는 괄호에 넣습니다. 예시는 아래와 같습니다.

1. 솔페이(SolPay)
2. 솔북(SolBook)

같은 문서 안에서 이미 한 번 풀어 쓴 뒤에는 문맥이 분명하면 한글 이름만 사용합니다. 여러 부서가 함께 보는 공지에서는 제품 이름을 줄여 쓰지 않습니다. 특히 협력사를 포함한 문서에서는 제품명만 보고도 이해할 수 있게 적습니다.

레드브릭소프트는 외부 협력사 이름이므로, 회사 내부 조직명처럼 쓰지 않습니다. 사람을 가리킬 때는 필요하면 소속을 함께 적어 혼동을 줄입니다. 예를 들면 외부 협력사인 레드브릭소프트 소속 개발자처럼 씁니다.

## 사용하는 방법
문서, 메일, 사내 메신저 메시지에서 용어를 쓸 때는 아래 기준을 따릅니다.

1. 제품명은 공지 첫 언급에서 한글 이름을 먼저 씁니다.
2. 제품 소개가 필요한 문서에서는 솔페이와 솔북의 뜻을 위 표 기준으로만 설명합니다.
3. 협력사 이름은 회사명 그대로 적고, 필요하면 외부 협력사라는 설명을 덧붙입니다.
4. 문서 목적이 용어 안내가 아닐 때는 불필요한 배경 설명을 길게 붙이지 않습니다.
5. 새 사내 용어는 제품기획팀이 분기마다 이 문서에 추가합니다.

아래 예시는 권장 표현입니다.

- 솔페이 관련 공지 초안을 검토합니다.
- 솔북 기능 안내에 결제 연동 설명을 포함합니다.
- 레드브릭소프트와 협업하는 일정은 담당자 확인 후 공유합니다.

## 문서 관리
이 문서는 용어를 처음 접하는 사람이 빠르게 읽을 수 있도록 짧게 유지합니다. 제품 설명은 문서 안에서 서로 다르게 쓰지 않고, 위 표의 뜻을 기준으로 맞춥니다. 제품기획팀은 공지에서 반복 사용되는 새 표현이 생기면 검토 후 반영합니다.

수정이 필요할 때는 기존 문장에 임의로 다른 뜻을 덧붙이지 말고, 전사 공지 스페이스의 댓글이나 담당 부서 문의로 요청합니다. 협력사가 함께 보는 문서이므로 내부에서만 통하는 줄임말이나 비공식 표현은 넣지 않습니다.

## 문의처
문서 내용 수정 제안이나 용어 추가 요청은 제품기획팀으로 보냅니다. 전사 공지 스페이스 댓글 또는 메일로 전달합니다.

- 제품 용어 문의: product-planning@saesol.example
- 문서 오탈자 제보: docs@saesol.example

문의 시에는 수정이 필요한 문장, 제안하는 표현, 사용 맥락을 함께 적어 주시면 확인이 빠릅니다.
