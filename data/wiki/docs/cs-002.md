# VIP 가맹점 장애 보상 기준

## 적용 상황

이 문서는 장애 발생 시 VIP 가맹점 보상 여부를 고객지원팀과 제품기획팀이 동일한 기준으로 판단하기 위한 응대 매뉴얼입니다.

VIP 가맹점은 최근 월 결제액이 **1억 원** 이상인 가맹점을 말합니다. 월 결제액 확인이 어려운 경우에는 임의로 VIP 여부를 안내하지 말고 내부 확인 후 답변합니다.

보상은 장애로 인해 가맹점이 정상 운영을 하지 못한 시간이 확인된 경우에만 검토합니다. 단순 문의, 사용 방법 오해, 가맹점 내부 장비 문제, 통신사 장애로 판단되는 경우는 본 기준의 직접 적용 대상이 아닙니다.

보상 산정의 기본 원칙은 장애 1시간마다 월 이용료의 **10%를 감면**하는 것입니다. 장애 시간이 1시간 미만이면 실제 영향과 고객 불편 정도를 함께 검토하되, 최종 보상 여부는 **고객지원 매니저**가 정합니다.

## 응대 순서

1. 가맹점이 VIP 대상인지 확인합니다.  
   최근 월 결제액 기준으로 확인하며, 확인 전에는 보상 가능 여부를 확정적으로 말하지 않습니다.

2. 장애 발생 시각과 종료 시각을 확인합니다.  
   가맹점 진술만으로 확정하지 않고, 내부 공유된 장애 사실과 대조합니다.

3. 실제 운영 영향 범위를 정리합니다.  
   결제 불가, 예약 접수 불가, 정산 확인 불가 등 가맹점 업무에 직접 영향이 있었는지 기록합니다.

4. 1차 안내를 제공합니다.  
   장애 원인 분석이 끝나지 않았더라도 현재 확인된 사실, 추가 확인 필요 여부, 보상 검토 가능성을 분리해서 안내합니다.

5. 보상안을 정리해 승인 요청합니다.  
   장애 시간, 월 이용료, 예상 감면 비율을 정리해 내부 검토를 요청합니다.

6. 최종 결과를 가맹점에 안내합니다.  
   감면 적용 여부, 적용 기준, 반영 시점을 간단하고 동일한 표현으로 전달합니다.

## 보상 산정 기준

| 항목 | 기준 |
| --- | --- |
| 대상 가맹점 | 월 결제액이 1억 원 이상인 가맹점 |
| 기본 보상 방식 | 장애 1시간마다 월 이용료의 10%를 감면 |
| 판단 권한 | 보상 여부는 고객지원 매니저가 정함 |
| 적용 단위 | 확인된 장애 시간 기준으로 산정 |
| 제외 검토 | 가맹점 자체 환경 문제로 확인된 경우 |

장애 시간이 여러 구간으로 나뉜 경우에는 같은 장애로 이어진 사실이 확인되면 합산해서 검토할 수 있습니다. 다만 중간에 정상 운영이 충분히 가능했던 시간이 있으면 분리해서 판단합니다.

월 이용료 감면은 원칙적으로 이용료에만 적용합니다. 다른 비용까지 포함해 안내해야 하는 상황이 있으면 먼저 내부 확인을 거칩니다.

## 답변 예시

가맹점에 바로 확답이 어려운 경우에는 아래와 같이 안내합니다.

```text
현재 장애 발생 시간과 영향 범위를 확인하고 있습니다.
확인 결과에 따라 VIP 가맹점 보상 기준 적용 여부를 검토하겠습니다.
보상 여부는 내부 확인 후 다시 안내드리겠습니다.
```

보상 검토가 가능한 경우에는 아래와 같이 안내합니다.

```text
확인된 장애 시간 기준으로 보상 적용 여부를 검토하고 있습니다.
VIP 가맹점은 장애 1시간마다 월 이용료의 10%를 감면하는 기준이 있습니다.
최종 보상 여부는 내부 확인 후 안내드리겠습니다.
```

보상 불가 가능성이 큰 경우에도 단정적으로 말하지 않고 아래처럼 안내합니다.

```text
현재로서는 서비스 장애보다 다른 원인 가능성도 함께 확인 중입니다.
원인 확인 결과에 따라 보상 적용 여부가 달라질 수 있습니다.
확정되는 대로 다시 안내드리겠습니다.
```

## 에스컬레이션 기준

다음 경우에는 고객지원 담당자가 단독 판단하지 말고 즉시 상위 확인을 요청합니다.

- VIP 여부 확인이 바로 되지 않는 경우
- 장애 시작 또는 종료 시각이 불명확한 경우
- 가맹점이 강한 이의를 제기하며 즉답을 요구하는 경우
- 동일 가맹점에서 반복 보상을 요청하는 경우
- 월 이용료 외 추가 보상을 함께 요구하는 경우

에스컬레이션 시에는 아래 내용을 빠짐없이 정리합니다.

- 가맹점명
- VIP 해당 여부
- 장애 발생 시각과 종료 시각
- 가맹점이 주장하는 피해 내용
- 현재까지 확인된 사실
- 고객에게 이미 안내한 문구

최종 대외 안내 전에는 반드시 고객지원 매니저 확인을 받습니다. 제품기획팀에 별도 공유가 필요한 경우에는 장애 영향과 고객 반응을 중심으로 간단히 전달합니다.
