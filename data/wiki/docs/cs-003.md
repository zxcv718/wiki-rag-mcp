# 솔북 예약 오류 1차 응대 가이드

## 적용 상황
이 문서는 고객지원팀 상담원이 솔북 예약 과정에서 발생한 오류 문의를 처음 접수했을 때 사용하는 1차 응대 기준입니다. 대상은 전화, 메일, 앱 문의로 들어온 예약 실패, 중복 예약, 예약 확인 불가, 예약금 결제 실패 동반 문의입니다.

1차 응대의 목적은 원인 추정을 서두르기보다 재현과 분류에 필요한 정보를 빠르게 확보하고, 매장 운영에 영향이 큰 건을 우선 안내하는 데 있습니다. 특히 영업 시작 전 접수 건은 예약 시각 기준 최소 30분 전까지 1차 회신을 완료하는 것을 목표로 합니다.

## 응대 순서
### 1. 필수 정보 확보
솔북 예약 오류 문의를 받으면 아래 4가지를 먼저 확인합니다.

| 항목 | 확인 내용 |
|---|---|
| 매장명 | 솔북을 사용하는 매장명 |
| 예약 일시 | 고객이 시도한 예약 날짜와 시간 |
| 고객 연락처 뒤 4자리 | 예약 식별용 정보 |
| 오류 화면 캡처 | 오류 문구와 화면 상태가 보이도록 요청 |

오류 화면 캡처가 즉시 어려우면 우선 접수하되, 회신 전에 반드시 추가 요청합니다.

### 2. 증상 분류
상담원은 접수 내용을 아래 기준으로 나눠 확인합니다.

- 예약이 아예 생성되지 않은 경우
- 예약 완료로 보였으나 매장에서 확인되지 않는 경우
- 같은 시간대에 예약이 두 번 잡힌 경우
- 예약금 결제가 함께 실패한 경우

같은 시간대에 중복 생성된 문의가 있으면 BK-4010 가능성을 우선 확인합니다.

### 3. 기본 안내
고객에게는 확인 중임을 먼저 안내하고, 동일 예약을 반복 시도하지 않도록 요청합니다. 반복 시도는 중복 예약이나 결제 중복 확인을 어렵게 만들 수 있습니다. 매장 측 확인이 필요한 경우에는 매장명과 예약 일시 기준으로 우선 조회 중이라고 설명합니다.

## 답변 예시
### 일반 예약 오류
```text
안녕하세요. 솔북 예약 오류 문의 접수했습니다.
확인을 위해 매장명, 예약 일시, 고객 연락처 뒤 4자리, 오류 화면 캡처를 부탁드립니다.
확인 후 가능한 빨리 안내드리겠습니다.
```

### BK-4010 의심 문의
```text
안녕하세요. 같은 예약이 두 번 접수된 것으로 보인다면 확인이 필요합니다.
중복으로 생성된 예약 번호 2개를 모두 보내주시면 확인 후 안내드리겠습니다.
추가 예약 시도는 잠시 중단 부탁드립니다.
```

### 예약금 결제 동반 실패 문의
```text
안녕하세요. 예약 오류와 예약금 결제가 함께 실패한 것으로 접수했습니다.
예약 생성 실패와 솔페이 결제 실패 여부를 나누어 확인하겠습니다.
오류 화면 캡처와 고객 연락처 뒤 4자리도 함께 부탁드립니다.
```

## 에스컬레이션 기준
### 제품기획팀 전달
아래 경우에는 제품기획팀에 전달합니다.

- BK-4010 문의인 경우
- 예약 상태가 고객 화면과 매장 확인 내용 사이에서 다르게 보이는 경우
- 동일 매장에서 유사 문의가 반복 접수되는 경우

BK-4010 문의에서는 상담원이 중복 예약 번호 2개를 모두 받아 제품기획팀에 전달합니다. 전달 시 매장명, 예약 일시, 고객 연락처 뒤 4자리, 오류 화면 캡처를 함께 정리합니다.

### 페이코어로 L2 에스컬레이션
L2 에스컬레이션은 상담원이 풀지 못한 문의를 담당 스쿼드로 넘기는 단계입니다. 솔북에서 예약금 결제가 함께 실패한 경우에는 솔페이 결제 실패 여부를 분리 확인하고 필요한 경우 페이코어로 L2 에스컬레이션합니다.

다음 중 하나에 해당하면 페이코어 검토가 필요합니다.

- 예약 생성과 별개로 결제 실패가 반복 확인되는 경우
- 고객이 결제 시도 여부는 확인되나 예약 결과와 연결되지 않는다고 말하는 경우
- 같은 시간대에 결제 관련 문의가 연속 접수되는 경우

## 처리 시 유의사항
상담원은 확인되지 않은 원인을 단정해서 안내하지 않습니다. 특히 결제 실패가 함께 있는 경우 예약 오류와 결제 오류를 한 건으로 뭉뚱그려 설명하지 않고, 각각 분리해 확인 중이라고 안내합니다.

영업 시작 전 접수 건은 우선순위를 높여 처리합니다. 즉시 해결이 어렵더라도 예약 시각 기준 최소 30분 전까지는 접수 여부, 현재 확인 범위, 추가로 필요한 자료를 포함한 1차 회신을 완료합니다. 회신 채널은 고객이 최초로 문의한 채널을 우선 사용하되, 추가 자료 수신이 쉬운 방식으로 보완합니다.
