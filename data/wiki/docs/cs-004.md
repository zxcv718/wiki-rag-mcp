# 장애 공지와 가맹점 안내 템플릿

## 적용 상황
이 문서는 솔페이 또는 솔북에서 가맹점이 실제로 체감하는 장애가 발생했을 때 고객지원팀이 보내는 공지와 안내에 적용합니다. 접속 불가, 결제 실패, 예약 생성 실패, 정산 조회 지연처럼 기능 사용에 직접 영향이 있는 경우를 포함합니다.

안내의 목적은 원인 설명보다 현재 영향과 다음 안내 시점을 명확히 전달하는 데 있습니다. 원인이 아직 확인되지 않았더라도 공지는 지연하지 않습니다. 솔페이와 솔북이 동시에 영향을 받는 경우 제목에는 두 제품명 표기를 포함하고, 본문 첫 줄에 공통 영향 기능을 3개 이하로 요약합니다. 이때 문구 안에 "두 제품명" 기준을 빠뜨리지 않도록 확인합니다.

## 응대 순서
1. 장애를 인지하면 고객지원팀 담당자는 즉시 공지 초안을 작성합니다.
2. 장애 인지 후 "15분" 안에 1차 공지를 올립니다.
3. 1차 공지에는 다음 항목을 반드시 포함합니다.
   - 영향 받는 제품과 기능
   - 확인된 영향 범위
   - 다음 업데이트 시각
   - DRI 1명
   - 문의 회신 채널 1개
4. 원인이 확정되지 않은 상태라도 영향 범위와 다음 업데이트 시각은 반드시 적습니다.
5. 내부 추정 원인, 확인되지 않은 복구 시각, 단정적인 표현은 쓰지 않습니다.
6. 복구가 확인되면 "30분 안"에 최종 공지를 보냅니다.
7. 후속 보상 검토가 필요한 경우 최종 공지에 별도 안내 예정 문구를 포함합니다.

공지 작성 시 DRI는 작업이나 장애의 직접 책임자 한 명만 적습니다. 문의 회신 채널도 하나만 적어 혼선을 줄입니다. 예를 들어 메일을 쓰는 경우 support@saesol.example처럼 단일 창구로 안내합니다.

## 작성 원칙
제목은 가맹점이 바로 상태를 이해할 수 있게 간단히 씁니다. 제품명, 장애 상태, 작성 시각 순으로 정리하면 됩니다.

본문은 확인된 사실만 씁니다. 아래 원칙을 지킵니다.

| 항목 | 작성 원칙 |
|---|---|
| 영향 설명 | 사용 불가 또는 지연되는 기능을 구체적으로 적습니다 |
| 원인 설명 | 확정 전에는 원인 조사 중이라고만 적습니다 |
| 복구 시각 | 확인 전에는 예상 시각을 쓰지 않습니다 |
| 담당자 | DRI 1명을 명시합니다 |
| 문의 창구 | 회신 채널 1개만 적습니다 |
| 다음 안내 | 다음 업데이트 시각을 반드시 적습니다 |

솔페이와 솔북 동시 장애 시 본문 첫 줄 예시는 다음과 같습니다.  
`현재 결제 승인, 예약 결제, 정산 조회 기능에 공통 영향이 있습니다.`

## 답변 예시
### 1차 공지 예시
```text
[솔페이 장애 안내] 일부 가맹점 결제 기능 장애 안내 (14:20 작성)

현재 카드 결제 승인 기능에 영향이 있습니다.
영향 범위: 일부 가맹점에서 결제 승인 실패가 발생하고 있습니다.
원인: 확인 중입니다.
다음 업데이트: 14:40
DRI: 김하린
문의: support@saesol.example
```

### 솔페이와 솔북 동시 공지 예시
```text
[솔페이·솔북 장애 안내] 공통 기능 장애 안내 (18:05 작성)

현재 결제 승인, 예약 결제, 정산 조회 기능에 공통 영향이 있습니다.
영향 범위: 일부 가맹점에서 결제와 예약 결제 진행이 실패하거나 정산 조회가 지연되고 있습니다.
원인: 확인 중입니다.
다음 업데이트: 18:25
DRI: 이도윤
문의: support@saesol.example
```

### 최종 공지 예시
```text
[솔페이 장애 복구 안내] 결제 기능 정상화 (15:10 작성)

이전 안내드린 결제 승인 장애는 복구되어 현재 정상 이용 가능합니다.
영향 범위: 일부 가맹점 결제 승인 실패
복구 확인 시각: 14:55
DRI: 김하린
문의: support@saesol.example

이번 장애로 인한 후속 보상 검토가 필요한 경우 별도 안내 예정입니다.
```

## 에스컬레이션 기준
다음 경우에는 고객지원팀이 공지 등록과 동시에 제품기획팀에 공유합니다.

- 솔페이 또는 솔북의 핵심 기능 사용이 중단된 경우
- 장애 문의가 짧은 시간 안에 다수 접수되는 경우
- 복구 후 보상 또는 후속 안내 필요성이 예상되는 경우
- 솔페이와 솔북에 동시 영향이 확인된 경우

가맹점이 개별 원인 확인을 요구하더라도 공지 전 또는 공지와 다른 내용을 임의로 안내하지 않습니다. 확인되지 않은 내용을 전달하면 공지 신뢰도가 떨어질 수 있습니다. 개별 답변은 최신 공지 문구를 기준으로 동일하게 맞춥니다.
