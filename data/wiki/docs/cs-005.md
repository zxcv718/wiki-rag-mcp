# L2 에스컬레이션 접수 체크리스트

## 대상
이 문서는 고객지원팀 상담원이 해결하지 못한 문의를 담당 스쿼드로 넘길 때 확인할 기준을 정리한 절차 안내입니다. 여기서 L2 에스컬레이션은 상담원이 풀지 못한 문의를 담당 스쿼드로 넘기는 단계를 뜻합니다.

상담 중 확인과 안내만으로 해결되지 않거나, 상담 시작 후 "20분" 안에 원인이나 우회 방법을 안내하지 못한 경우 L2 에스컬레이션으로 접수합니다. 제품기획팀은 접수된 내용의 맥락 확인과 후속 조율이 필요한 경우 참조합니다.

## 준비할 것
L2 에스컬레이션 등록 전 아래 항목을 모두 준비합니다. 하나라도 빠지면 담당 스쿼드가 바로 확인하기 어렵고 재문의가 발생합니다.

| 항목 | 내용 |
| --- | --- |
| 가맹점 식별 정보 | "가맹점 ID" |
| 재현 정보 | 상담원이 직접 정리한 재현 절차 |
| 시점 | 발생 시각 |
| 영향도 | 영향 범위 |
| 증빙 | 첨부 화면 1장 이상 |

작성 기준은 다음과 같습니다.

- 재현 절차는 상담원이 따라 읽어도 같은 흐름을 확인할 수 있게 순서대로 적습니다.
- 발생 시각은 고객 설명 그대로 옮기지 말고 가능한 범위에서 날짜와 시각을 분리해 적습니다.
- 영향 범위는 단건인지, 특정 주문이나 예약에 한정되는지, 여러 사용자에게 반복되는지 구분해 적습니다.
- 첨부 화면은 전체 화면 또는 핵심 구간이 보이도록 올립니다. 글자가 흐리거나 잘린 이미지는 다시 받아 등록합니다.

## 단계별 절차
1. 상담 중 기본 확인을 먼저 진행합니다. 고객이 어떤 기능에서 문제를 겪는지, 현재도 같은 현상이 재현되는지, 이미 시도한 조치가 있는지 확인합니다.

2. 상담 시작 후 "20분" 안에 원인이나 우회 방법을 안내하지 못하면 L2 에스컬레이션으로 전환합니다. 이때 상담 기록을 정리하면서 누락 항목이 없는지 다시 확인합니다.

3. 필수 항목을 모두 채워 접수합니다. L2 에스컬레이션 등록에는 가맹점 ID, 재현 절차, 발생 시각, 영향 범위, 첨부 화면 1장 이상이 모두 포함되어야 합니다.

4. 담당 대상을 지정합니다. 솔페이 결제 실패 문의는 기본적으로 "페이코어"를 1차 담당으로 지정합니다. 솔북 예약 흐름이 함께 얽힌 경우 제품기획팀을 참조자로 추가합니다.

5. 접수 직후 고객에게 회신합니다. 고객지원팀은 L2 에스컬레이션을 올린 뒤 "10분" 안에 가맹점에게 접수 완료와 다음 안내 예정 시각을 회신해야 합니다.

6. 이후 추가 자료 요청이 오면 최초 접수 내용과 충돌하지 않게 보강합니다. 고객에게 다시 받은 화면이나 설명이 있으면 기존 내용을 수정하거나 덧붙여 최신 상태로 맞춥니다.

## 자주 하는 실수
- 가맹점 식별 정보를 상호명만 적고 "가맹점 ID"를 누락합니다.
- 재현 절차를 너무 짧게 적어 실제 흐름이 보이지 않습니다.
- 발생 시각을 오전, 방금 전처럼 모호하게 적습니다.
- 영향 범위를 적지 않아 단건 문제인지 반복 문제인지 판단이 늦어집니다.
- 첨부 화면 없이 텍스트만 등록합니다.
- 솔페이 결제 실패 문의인데 1차 담당을 "페이코어"로 지정하지 않습니다.
- 솔북 예약 흐름이 함께 얽혀 있는데 제품기획팀 참조를 빼먹습니다.
- 접수 후 고객 회신이 늦어져 다음 안내 예정 시각을 전달하지 못합니다.

## 문의처
절차 자체가 불명확하거나 접수 기준 해석이 필요한 경우 고객지원팀 팀장에게 먼저 문의합니다. 솔페이와 솔북 흐름이 함께 포함된 문의의 분류가 애매한 경우에는 제품기획팀으로 확인을 요청합니다.

문서 수정 제안은 고객 지원 스페이스 문서 의견으로 남기거나 고객지원팀 대표 메일 support@saesol.example로 보냅니다.
