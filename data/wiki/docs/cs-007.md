# 정산 금액 불일치 문의 응대

## 대상
이 문서는 고객지원팀 상담원이 가맹점으로부터 정산 금액이 맞지 않는다는 문의를 받았을 때 사용하는 절차 안내입니다. 제품기획팀은 문의 흐름과 에스컬레이션 기준을 확인하는 용도로 참고합니다.

고객지원팀은 가맹점 안내와 사실 확인을 담당합니다. 고객지원팀은 정산 원장 수치 자체를 수정하지 않고 조회 결과만 안내합니다. 수치 보정, 배치 재처리, 원인 분석이 필요한 경우에는 정해진 기준에 따라 담당 조직으로 넘깁니다.

## 준비할 것
문의 접수 시 아래 정보를 먼저 받습니다. 정보가 부족하면 확인 순서를 진행하지 않습니다.

| 항목 | 필수 여부 | 확인 내용 |
| --- | --- | --- |
| 가맹점 ID | 필수 | 조회 대상 가맹점 식별 |
| 정산 예정일 | 필수 | 가맹점이 기대한 입금 기준일 |
| 거래일 | 필수 | 실제 결제가 발생한 날짜 |
| 주문번호 1건 이상 | 필수 | 차이가 발생했다고 보는 거래 식별 |
| 문의 내용 요약 | 필수 | 누락, 중복, 금액 차이 중 무엇인지 |
| 가맹점이 인지한 차액 | 권장 | 에스컬레이션 우선순위 판단 |

누리는 가맹점별 일 단위 정산 배치 시스템입니다. 본 문서의 확인은 모두 누리 기준으로 진행합니다. 가맹점이 전달한 화면 캡처가 있더라도, 상담 기록에는 텍스트로 핵심 값을 남깁니다.

## 단계별 절차
1. 문의를 접수하고 필수 정보를 확인합니다.  
   정산 예정일, 거래일, 가맹점 ID, 주문번호 1건 이상을 받아 누리 기준으로 확인합니다. 주문번호가 없으면 먼저 주문번호 확보를 요청합니다.

2. 누리에서 가맹점과 거래를 조회합니다.  
   조회 시 거래일과 정산 예정일이 서로 다른 경우가 있으므로 둘 다 기준으로 확인합니다. 한 건만 다른지, 같은 날짜의 여러 건이 함께 다른지 구분해서 기록합니다.

3. 조회 결과를 분류합니다.  
   단순 조회상 오해로 보이는 경우에는 누리 기준 금액과 거래 범위를 설명합니다. 일부 주문 누락이나 중복처럼 추가 확인이 필요한 경우에는 해당 주문번호와 차액을 묶어서 기록합니다.

4. 즉시 에스컬레이션이 필요한지 판단합니다.  
   SP-E2003 문의는 상담원이 확인 즉시 데이터팀에 L2 에스컬레이션을 등록합니다. L2 에스컬레이션은 상담원이 풀지 못한 문의를 담당 스쿼드로 넘기는 단계입니다. 이 경우 상담 답변을 지연하지 말고, 접수 사실과 다음 안내 예정만 먼저 전달합니다.

5. 차액 규모와 기간을 확인합니다.  
   정산 차액이 5만원 이상이거나 3영업일 이상 누적된 경우에는 고객지원팀 리더를 참조자로 추가해야 합니다. 금액이 작더라도 동일 가맹점에서 반복 문의가 이어지면 상담 기록에 반복 여부를 남깁니다.

6. 에스컬레이션 또는 안내를 마무리합니다.  
   데이터팀으로 넘길 때는 가맹점 ID, 정산 예정일, 거래일, 주문번호, 차액, 가맹점 설명을 빠짐없이 적습니다. 고객에게는 현재 확인 기준이 누리이며, 고객지원팀은 정산 원장 수치 자체를 수정하지 않고 조회 결과만 안내한다는 점을 분명히 설명합니다.

## 자주 하는 실수
- 주문번호 없이 차액만 받아 바로 판단하는 경우가 있습니다. 반드시 주문번호 1건 이상을 받습니다.
- 거래일만 보고 확인하고 정산 예정일을 누락하는 경우가 있습니다. 두 날짜를 함께 봐야 합니다.
- SP-E2003를 일반 문의처럼 보류하는 경우가 있습니다. 이 코드는 즉시 데이터팀에 넘깁니다.
- 가맹점 요청에 따라 상담원이 정산 원장 수정 가능 여부를 약속하는 경우가 있습니다. 수정 약속은 하지 않습니다.
- 차액이 5만원 이상인데 고객지원팀 리더를 참조하지 않는 경우가 있습니다. 금액과 누적 일수 기준을 함께 확인합니다.

## 문의처
- 절차 해석이 필요한 경우: 고객지원팀 리더
- 누리 조회 결과와 실제 정산 흐름의 차이 확인이 필요한 경우: 데이터팀
- 제품 공지나 대외 안내 문구 조정이 필요한 경우: 제품기획팀

에스컬레이션 등록 후 진행 상황 공유가 필요하면 사내 메신저 대신 상담 기록에 먼저 남기고, 추가 설명이 필요할 때만 담당자에게 보조 연락합니다. 문의 예시는 고객 지원 스페이스 내 유사 사례 문서를 함께 참고합니다.
