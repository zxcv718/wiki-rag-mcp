# 솔페이 결제 실패 1차 응대 가이드

## 적용 상황
이 문서는 고객지원팀 상담원이 솔페이 결제 실패 문의를 처음 접수했을 때 사용하는 1차 응대 기준입니다. 전화, 메일, 게시판 문의에 공통으로 적용합니다.  
목적은 상담 초기에 필요한 정보를 빠짐없이 확보하고, 확인 가능한 범위 안에서만 안내하며, 추가 확인이 필요한 건은 제품기획팀으로 정확히 넘기는 데 있습니다.

다음 경우에 이 문서를 사용합니다.

- 결제가 되지 않았다고 가맹점이 문의한 경우
- 결제 시도 후 결과가 불명확하다고 문의한 경우
- 같은 결제를 다시 시도해도 되는지 문의한 경우

## 응대 순서
상담원은 문의를 받으면 먼저 아래 4가지를 확인해야 합니다.

1. 결제 시각
2. 결제 금액
3. 결제 수단
4. 가맹점 ID

위 4가지는 결제 결과 확인과 후속 전달에 반드시 필요합니다. 하나라도 빠지면 먼저 보완 요청을 합니다.

기본 응대 순서는 아래와 같습니다.

1. 가맹점으로부터 4가지를 확인합니다.
2. 문의 내용에 결제 실패 화면의 문구나 코드가 있으면 그대로 받아 적습니다.
3. 결제 결과 조회 화면에서 해당 결제를 찾습니다.
4. 조회된 내용과 문의 유형에 따라 아래 기준으로 안내합니다.
5. 상담원이 단정할 수 없는 건은 추정하지 않고, 확인된 내용만 전달합니다.
6. 추가 확인이 필요하면 제품기획팀으로 에스컬레이션합니다.

## 유형별 안내 기준
| 문의 유형 | 1차 안내 기준 | 주의 사항 |
|---|---|---|
| PRJ-204 | 상담원이 결론을 내리지 않고 결제 결과 조회 화면의 상태값을 그대로 전달합니다. | 승인 여부를 추정해서 말하지 않습니다. |
| GW-429 | 같은 결제를 연속으로 누르지 말라고 안내합니다. | 반복 시도로 같은 문의가 커질 수 있으므로 즉시 중단을 권합니다. |
| SP-E1001 | 같은 카드로 반복 승인하지 말고 다른 결제 수단 확인을 권합니다. | 같은 카드 재시도를 유도하지 않습니다. |
| 그 외 결제 실패 | 조회 화면에서 확인되는 내용만 안내하고, 판단이 어려우면 추가 확인으로 접수합니다. | 원인 단정, 환불 단정, 승인 단정 표현을 피합니다. |

상담 중 가맹점이 이미 여러 번 시도했다고 말하면, 마지막 시도 시각과 현재 진행 중인 추가 시도가 있는지도 함께 확인합니다. 같은 거래를 중복으로 진행 중인 상황이면 우선 추가 시도를 멈추도록 안내합니다.

## 답변 예시
아래 문구를 상황에 맞게 사용합니다.

```text
결제 확인을 위해 결제 시각, 결제 금액, 결제 수단, 가맹점 ID를 먼저 확인하겠습니다.
```

```text
확인된 내용 기준으로 안내드리겠습니다. 현재 조회 화면에 표시된 상태값은 [상태값]입니다. 이 건은 조회되는 내용 그대로 전달드리며, 추가 판단이 필요한 경우 별도 확인으로 접수하겠습니다.
```

```text
현재 문의는 GW-429로 확인됩니다. 같은 결제를 연속으로 누르지 말고 잠시 추가 시도를 멈춰 주세요. 확인 가능한 내용으로 접수해 추가 확인하겠습니다.
```

```text
현재 문의는 SP-E1001로 확인됩니다. 같은 카드로 반복 승인하지 말고 다른 결제 수단 사용 가능 여부를 먼저 확인해 주세요.
```

```text
지금 확인되는 범위에서는 결제 실패로 보이지만, 확정 안내가 필요한 내용은 추가 확인 후 다시 안내드리겠습니다.
```

## 에스컬레이션 기준
아래 경우에는 1차 안내 후 제품기획팀으로 넘깁니다.

- PRJ-204로 접수되었고 가맹점이 승인 여부 확답을 요구하는 경우
- 결제 결과 조회 화면에서 확인되는 내용과 가맹점 진술이 다른 경우
- 같은 시각대에 동일 가맹점에서 유사 문의가 반복되는 경우
- 상담원이 조회 결과만으로 안내하기 어려운 경우
- 가맹점이 이미 여러 차례 재시도하여 추가 혼선이 우려되는 경우

에스컬레이션 시에는 아래 항목을 함께 전달합니다.

- 결제 시각
- 결제 금액
- 결제 수단
- 가맹점 ID
- 가맹점이 전달한 실패 문구 또는 코드
- 상담원이 실제로 안내한 문구
- 가맹점의 추가 시도 여부

추가 확인 전에는 상담원이 개인 판단으로 원인이나 최종 결과를 확정해서 안내하지 않습니다. 확인된 정보만 간단히 전달하고, 필요한 경우 재안내 예정이라고 마무리합니다.
