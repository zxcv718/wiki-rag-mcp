# 가맹점 문의 답변 템플릿

## 적용 상황

이 문서는 가맹점에서 들어오는 일반 문의에 답변할 때 공통으로 쓰는 문구와 기본 응대 규칙을 정리한 문서입니다. 전화, 메일, 게시판 등 접수 채널이 달라도 같은 기준으로 적용합니다. 안내 내용이 아직 확정되지 않았거나 담당 확인이 필요한 경우에도 먼저 접수 사실과 확인 예정 사항을 안내합니다.

문의 내용이 단순 안내인지, 확인이 필요한 요청인지, 다른 부서 검토가 필요한 사안인지 초기에 구분합니다. 다만 분류가 끝나지 않았더라도 첫 응답은 문의 접수 후 1시간 안에 보냅니다. 첫 응답에서는 현재 확인 중인 내용과 다음 안내 예정 여부를 함께 적습니다.

## 응대 순서

1. 문의 내용을 빠르게 읽고 요청 사항을 한 문장으로 정리합니다.
2. 고객이 남긴 정보만으로 답변 가능한지 확인합니다.
3. 추가 확인이 필요하면 접수 사실을 먼저 안내합니다.
4. 필요한 경우 내부 확인 후 결과를 다시 안내합니다.
5. 상담이 마무리되면 종료 안내를 보내고, 상담이 끝나면 CSAT 설문을 자동으로 보낸다 는 점을 내부 기준대로 처리합니다.
6. 모든 답변 끝에는 상담원 이름을 적습니다.

아래 항목은 모든 답변에서 공통으로 확인합니다.

| 확인 항목 | 처리 기준 |
| --- | --- |
| 첫 회신 여부 | 접수 후 1시간 안에 발송합니다 |
| 문장 톤 | 짧고 분명하게, 단정하지 말고 확인 사실만 안내합니다 |
| 추가 정보 요청 | 필요한 항목만 요청하고 같은 질문을 반복하지 않습니다 |
| 종료 문구 | 처리 결과, 추가 문의 가능 여부, 상담원 이름을 포함합니다 |

## 답변 예시

### 1. 접수 확인

안녕하세요, 새솔소프트 고객지원팀입니다.  
문의해 주신 내용은 확인 중입니다. 확인이 끝나는 대로 다시 안내드리겠습니다.  
불편을 드려 죄송합니다.  
상담원 이름: 김하나

### 2. 추가 정보 요청

안녕하세요, 새솔소프트 고객지원팀입니다.  
남겨주신 문의 내용을 확인했습니다. 정확한 확인을 위해 아래 정보를 부탁드립니다.  
- 문제가 발생한 시점  
- 사용 중인 기능 화면  
- 확인하신 내용 또는 표시된 문구  
정보를 보내주시면 확인 후 안내드리겠습니다.  
상담원 이름: 이도윤

### 3. 처리 결과 안내

안녕하세요, 새솔소프트 고객지원팀입니다.  
문의하신 내용에 대해 확인한 결과, 현재는 정상 처리된 것으로 보입니다.  
같은 현상이 다시 발생하면 발생 시점과 화면 정보를 함께 보내주시면 추가로 확인하겠습니다.  
도움이 필요하시면 같은 문의에 이어서 남겨주셔도 됩니다.  
상담원 이름: 박서윤

### 4. 상담 종료 안내

안녕하세요, 새솔소프트 고객지원팀입니다.  
문의하신 내용에 대한 안내를 모두 전달드렸습니다. 추가로 필요한 내용이 없으면 이번 상담은 종료하겠습니다.  
문의 처리 후에는 CSAT, 즉 문의 처리 후 받는 고객 만족도 점수 5점 만점 설문이 자동 발송됩니다.  
상담원 이름: 최지훈

## 에스컬레이션 기준

아래 경우에는 고객에게 확인 중임을 먼저 안내한 뒤 관련 부서 검토를 요청합니다.

- 동일 문의가 반복되는데 안내만으로 해결되지 않는 경우
- 결제, 정산, 예약 정보 등 서비스 이용에 직접 영향이 있는 경우
- 고객이 안내 내용에 이의를 제기하며 재확인을 요청하는 경우
- 공지 여부 확인이 필요한 경우
- 문의 내용만으로 사실 판단이 어려운 경우

에스컬레이션 후에도 고객 응답이 끊기지 않도록 진행 상태를 간단히 공유합니다. 확인 중인 사안은 추정해서 답하지 않습니다. 내부 검토가 길어질 때도 마지막 안내 이후 장시간 공백이 생기지 않게 중간 안내를 보냅니다. 고객에게는 확인 중인 범위와 다음 안내 예정만 전달하고, 내부 담당자나 내부 처리 방식은 상세히 설명하지 않습니다.
