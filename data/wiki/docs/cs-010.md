# 환불 처리 기준 (2025)

## 적용 상황

이 문서는 2025년 가맹점 이용료 환불 문의를 받을 때 고객지원팀과 제품기획팀이 공통으로 참고하는 응대 기준입니다. 대상은 가맹점이 이미 결제를 완료한 뒤 환불을 요청한 경우입니다.

기본 원칙은 다음과 같습니다.

| 구분 | 처리 기준 |
| --- | --- |
| 전액 환불 | 결제 후 "7일 이내" 요청 건은 전액 환불합니다 |
| 부분 환불 | 부분 환불은 "L2 에스컬레이션"으로 처리합니다 |

여기서 L2 에스컬레이션은 상담원이 풀지 못한 문의를 담당 스쿼드로 넘기는 단계입니다.

다음 경우도 이 문서 기준으로 먼저 안내합니다.

- 가맹점이 결제 취소 가능 여부를 사전 문의한 경우
- 이용 시작 여부와 관계없이 환불 가능 범위를 확인하려는 경우
- 전액 환불이 아닌 일부 금액 환불을 요청한 경우

## 응대 순서

1. 결제 완료 일시와 환불 요청 접수 일시를 확인합니다.
2. 요청 내용이 전액 환불인지, 일부 금액만 환불하려는 것인지 확인합니다.
3. 결제 후 "7일 이내"인지 판단합니다.
4. 아래 기준에 따라 안내합니다.
   1. 전액 환불 요청이며 결제 후 "7일 이내"이면 전액 환불로 안내합니다.
   2. 부분 환불 요청이면 접수 단계에서 확답하지 말고 "L2 에스컬레이션"으로 처리합니다.
   3. 전액 환불 요청이지만 결제 후 7일을 지난 경우에는 즉시 가능하다고 단정하지 말고 확인이 필요하다고 안내합니다.
5. 가맹점이 재문의할 수 있도록 접수 내용에 요청 사유를 간단히 남깁니다.

응대 시에는 결제일과 요청일을 기준으로 판단하며, 상담 중 추정 표현은 줄입니다. 처리 가능 여부가 확정되지 않은 건은 확정된 것처럼 말하지 않습니다.

## 답변 예시

### 전액 환불 가능 안내

```text
문의하신 건 확인했습니다.
결제 후 "7일 이내" 요청 건으로 확인되어 전액 환불 기준에 따라 접수해 드리겠습니다.
환불 진행에 필요한 내용 확인 후 순서대로 처리하겠습니다.
```

### 부분 환불 요청 안내

```text
문의하신 내용은 일부 금액만 환불하는 요청으로 확인했습니다.
부분 환불은 "L2 에스컬레이션"으로 처리합니다.
담당 스쿼드 확인이 필요한 건이라 접수 후 검토 결과를 안내드리겠습니다.
```

### 즉시 확답이 어려운 경우

```text
문의하신 환불 요청은 접수했습니다.
현재 확인된 내용만으로는 즉시 확정 안내가 어려워 추가 확인 후 답변드리겠습니다.
확인 결과에 따라 환불 가능 여부와 처리 범위를 안내하겠습니다.
```

## 에스컬레이션 기준

다음 경우에는 "L2 에스컬레이션"으로 처리합니다.

- 부분 환불 요청인 경우
- 상담 중 환불 범위가 전액인지 일부인지 명확하지 않은 경우
- 결제 정보와 요청 내용이 서로 맞지 않아 상담원이 기준 적용을 확정하기 어려운 경우
- 가맹점이 예외 적용을 주장하며 별도 판단을 요청하는 경우

에스컬레이션 시에는 아래 내용을 함께 전달합니다.

- 결제 완료 일시
- 환불 요청 접수 일시
- 가맹점이 요청한 환불 범위
- 가맹점이 설명한 요청 사유
- 상담원이 이미 안내한 내용

## 응대 시 유의사항

가맹점에게는 기준에 따라 차분하게 안내합니다. 특히 부분 환불 건은 상담 단계에서 가능 여부를 먼저 약속하지 않습니다. 또한 결제 후 "7일 이내" 전액 환불 기준은 분명하게 안내하되, 그 외 건은 확인 후 답변한다는 원칙을 유지합니다.

제품기획팀에서 문의를 전달받은 경우에도 같은 문구와 같은 판단 기준을 사용합니다. 문서에 없는 예외 상황은 임의로 해석하지 말고, 필요한 경우 "L2 에스컬레이션"으로 넘겨 확인합니다.
