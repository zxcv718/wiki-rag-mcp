# 환불 처리 기준

## 적용 상황
이 문서는 가맹점이 이용료 환불을 요청했을 때 고객지원팀이 안내하고 처리 요청을 넘기는 기준을 정리한 응대 매뉴얼입니다. 현재 기준은 가맹점 이용료에만 적용합니다. 상품 변경, 별도 계약, 위약금 협의, 법적 분쟁이 포함된 건은 이 문서의 일반 기준만으로 확정 안내하지 않고 제품기획팀에 확인합니다.

기본 원칙은 다음과 같습니다.

| 항목 | 기준 |
| --- | --- |
| 전액 환불 가능 기간 | 결제 후 14일 이내 |
| 처리 기간 | 환불 접수 후 영업일 기준 3일 안에 처리 |
| 기록 의무 | 환불 사유는 VOC에 남김 |

VOC는 고객의 소리로, 가맹점의 불만이나 제안을 기록하는 항목입니다. 환불 문의도 동일하게 VOC에 남겨야 하며, 단순 취소 요청인지 서비스 불만인지가 드러나도록 작성합니다.

## 응대 순서
1. 가맹점의 환불 요청 내용을 확인합니다. 결제일, 요청일, 환불 사유, 연락 가능한 회신 수단을 먼저 받습니다.

2. 결제 후 14일 이내인지 확인합니다. 14일 이내이면 전액 환불 기준으로 안내합니다. 기간이 지난 경우에는 즉시 전액 환불을 약속하지 말고 제품기획팀 확인이 필요하다고 안내합니다.

3. 환불 사유를 VOC에 남깁니다. 사유는 가능한 한 가맹점 표현에 가깝게 적되, 사실 확인이 필요한 내용은 단정하지 않습니다. 예를 들어 기능 불만, 오결제 주장, 중복 결제 의심, 단순 변심 등으로 구분해 적습니다.

4. 환불 처리 예상 기간을 안내합니다. 접수 완료 후 영업일 기준 3일 안에 처리한다고 설명합니다. 다만 계좌 반영 시점은 결제 수단이나 금융사 사정에 따라 차이가 있을 수 있으므로, 실제 입금 시점까지 단정해서 말하지 않습니다.

5. 처리 요청이 필요한 경우 관련 내용을 정리해 제품기획팀에 전달합니다. 전달 내용에는 결제일, 요청일, 환불 기준 충족 여부, 가맹점이 말한 사유, 고객지원팀 안내 문구를 포함합니다.

6. 처리 결과를 회신합니다. 환불 승인 여부와 처리 완료 사실을 가맹점에 안내하고, 같은 내용을 VOC에도 남깁니다.

## 답변 예시
아래 문구를 상황에 맞게 수정해 사용합니다.

### 1) 전액 환불 가능 대상
안녕하세요. 확인 결과 결제 후 14일 이내 요청 건으로 확인되어 전액 환불 기준에 따라 접수해 드리겠습니다. 환불은 접수 후 영업일 기준 3일 안에 처리합니다. 요청 사유는 기록을 위해 함께 남기고 있습니다.

### 2) 기간 경과로 즉시 확답이 어려운 대상
안녕하세요. 확인 결과 결제 후 14일 이내 기준은 지난 상태입니다. 이 경우에는 바로 전액 환불을 확정 안내드리기 어렵고, 요청 사유를 확인해 내부 검토 후 다시 안내드리겠습니다. 검토를 위해 환불 사유를 남겨 접수하겠습니다.

### 3) 사유 확인이 필요한 경우
안녕하세요. 환불 접수를 위해 결제일과 환불 사유 확인이 필요합니다. 확인되는 내용 기준으로 접수 후 처리 일정을 안내드리겠습니다. 환불 사유는 기록을 위해 VOC에 남깁니다.

## 에스컬레이션 기준
아래 경우에는 고객지원팀 단독 판단으로 확정 안내하지 않고 제품기획팀에 확인합니다.

- 결제 후 14일 이내 여부가 명확하지 않은 경우
- 가맹점이 결제 사실 자체를 부인하거나 중복 결제를 주장하는 경우
- 서비스 장애, 기능 미제공, 계약 조건 해석 등 책임 소재 판단이 필요한 경우
- 부분 환불, 예외 환불, 별도 보상 요구가 함께 제기된 경우
- 환불 지연에 대한 강한 이의 제기나 분쟁 가능성이 있는 경우

에스컬레이션 시에는 사실과 요청 사항을 분리해 전달합니다. 추정이나 개인 의견은 넣지 않습니다. 가맹점에게는 검토 중임을 안내하되, 처리 기한은 기존 기준인 영업일 기준 3일을 벗어나지 않도록 우선 접수 상태를 명확히 설명합니다.
