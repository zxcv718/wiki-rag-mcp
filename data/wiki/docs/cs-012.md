# CSAT 수집과 후속 연락 기준

## 대상
이 문서는 고객지원팀 상담원과 리더, 제품기획팀 담당자가 참고합니다. 문의 처리 후 받는 고객 만족도 점수인 CSAT의 수집 방식, 저점수 응답 확인, 주간 평균 점수 점검, 월간 공유 절차를 정리합니다.

적용 범위는 솔페이와 솔북 관련 문의입니다. 한 문의에 대해 CSAT는 한 번만 수집하며, 동일 문의에 중복 발송하지 않습니다.

## 준비할 것
고객지원팀은 문의 종료 여부와 고객 연락 가능 상태를 먼저 확인합니다. 후속 연락이 필요한 경우에는 문의 내용, 응대 요약, 고객이 남긴 점수와 사유를 함께 확인합니다.

제품기획팀 공유용 정리에는 아래 항목이 필요합니다.

| 항목 | 내용 |
| --- | --- |
| 제품 구분 | 솔페이, 솔북 |
| 점수 | 고객이 제출한 점수 |
| 사유 | 고객이 남긴 선택 또는 서술 사유 |
| 문의 요약 | 문의 주제와 처리 결과 |
| 전달 목적 | 반복되는 불만 사유 확인 및 개선 검토 |

## 단계별 절차
1. 상담원이 문의를 종료하면 해당 문의에 대해 CSAT 발송 대상을 확인합니다. CSAT는 문의 처리 후 받는 고객 만족도 점수로 5점 만점이며, 고객지원팀은 종료된 문의마다 1회만 발송합니다.

2. 고객이 점수와 사유를 제출하면 고객지원팀은 응답 내용을 확인합니다. 점수와 사유가 모두 있는 경우에는 함께 기록하고, 점수만 있는 경우에는 점수 기준으로만 분류합니다.

3. CSAT가 2점 이하인 응답은 접수 후 1영업일 안에 고객지원팀 리더가 후속 연락 여부를 확인해야 합니다. 확인 시에는 단순 불만 표현인지, 처리 누락 가능성이 있는지, 제품 개선이 필요한 내용인지 구분합니다.

4. 리더가 후속 연락이 필요하다고 판단하면 담당 상담원 또는 리더가 고객에게 연락합니다. 연락 목적은 재설명, 미처리 사항 확인, 추가 불편 해소 여부 확인입니다. 후속 연락 자체가 점수 변경을 요청하는 행위가 되어서는 안 됩니다.

5. 상담원별 주간 CSAT 평균은 주 단위로 확인합니다. 한 상담원의 주간 CSAT 평균이 4.2 미만으로 2주 연속 내려가면 응대 문구 점검과 코칭 세션 1회를 배정합니다. 코칭에서는 인사 표현, 안내 순서, 종료 안내 문구를 중심으로 점검합니다.

6. 제품기획팀에는 매달 첫 영업일 오후 3시에 솔페이와 솔북의 CSAT 하위 사유 상위 5개를 묶어 전달합니다. 전달 내용에는 제품별 반복 사유, 대표 문의 예시, 고객지원팀 관찰 메모를 포함합니다. 개인 식별 정보는 제외합니다.

## 자주 하는 실수
- 문의가 아직 진행 중인데 미리 발송하는 경우가 있습니다. 반드시 종료된 문의만 발송합니다.
- 같은 문의에 다시 발송하는 경우가 있습니다. 한 문의에는 1회만 발송합니다.
- 2점 이하 응답을 단순 참고로만 두고 리더 확인을 넘기는 경우가 있습니다. 접수 후 1영업일 안 확인이 기준입니다.
- 저점수 고객에게 점수 조정을 직접 요청하는 경우가 있습니다. 후속 연락의 목적은 불편 해소와 사실 확인입니다.
- 월간 공유 시 솔페이와 솔북 사유를 섞어 적어 제품별 경향이 보이지 않는 경우가 있습니다. 제품 구분을 유지해 정리합니다.

## 문의처
운영 기준 문의는 고객지원팀 리더에게 전달합니다. 월간 공유 형식 변경이나 전달 항목 조정이 필요하면 제품기획팀 담당자와 협의합니다. 문서 수정 제안은 고객 지원 스페이스 댓글 또는 cs-lead@saesol.example로 남깁니다.
