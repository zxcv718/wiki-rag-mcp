# VOC 등록 기준과 분류표

## 적용 상황

이 문서는 고객지원팀이 가맹점 상담 중 불만과 제안을 기록할 때 VOC 등록 여부를 판단하는 기준을 설명합니다. VOC는 고객의 소리로서 가맹점의 불만·제안 기록을 뜻하며, 단순 문의가 아니라 제품 개선이나 반복 이슈 추적에 쓰는 항목입니다.

다음 경우에 VOC 등록을 검토합니다.

- 같은 불편이 여러 가맹점에서 반복 확인되는 경우
- 기능 개선 요청이 구체적으로 들어온 경우
- 현재 안내만으로는 재발 가능성이 높다고 판단되는 경우
- 같은 가맹점에서 같은 주제로 30일 안에 3회 이상 문의한 경우

특히 고객지원팀은 같은 가맹점에서 같은 주제로 30일 안에 3회 이상 들어온 문의를 반드시 VOC로 등록해야 합니다. 반대로, 사용 방법을 한 번 안내하면 종료되는 단순 문의나 일회성 확인 요청은 VOC로 남기지 않습니다.

## 등록 기준과 분류

VOC는 한 건당 대표 이슈를 기준으로 작성합니다. 한 상담에 불편이 여러 개 섞여 있어도 가장 핵심인 내용 1건만 우선 등록하고, 나머지는 상담 기록에 함께 남깁니다.

VOC 분류는 아래 5개 상위 카테고리로 나누고 한 건당 대표 카테고리 1개만 선택합니다.

| 카테고리 | 등록 대상 예시 |
|---|---|
| 결제 | 결제 실패, 결제 흐름 불편, 결제 화면 개선 요청 |
| 정산 | 정산 금액 확인 불편, 정산 내역 표시 방식 제안 |
| 예약 | 솔북 예약 접수, 변경, 취소 과정의 불만과 제안 |
| 요금제 | 과금 기준 문의 중 정책 개선이 필요한 불만, 요금 구조 제안 |
| 사용성 | 화면 구성, 문구, 버튼 위치, 입력 동선 등 전반적 사용 편의 |

분류를 고를 때는 원인보다 가맹점이 체감한 문제를 우선합니다. 예를 들어 솔북 예약 화면에서 결제 연동 단계가 불편하다는 의견은 예약 또는 결제 중 대표 불편이 더 큰 쪽으로 1개만 고릅니다.

## 응대 순서

1. 상담 내용을 확인합니다.  
   불만인지 제안인지, 단순 문의인지 구분합니다.

2. 반복 여부를 확인합니다.  
   같은 가맹점, 같은 주제, 최근 30일 내 문의 이력을 확인합니다.

3. VOC 등록 여부를 결정합니다.  
   반복 이슈이거나 제품 개선 필요성이 있으면 등록합니다. 30일 안 3회 조건에 해당하면 반드시 등록합니다.

4. 대표 카테고리 1개를 선택합니다.  
   결제, 정산, 예약, 요금제, 사용성 중 하나만 고릅니다.

5. 내용을 간단명료하게 작성합니다.  
   가맹점이 겪은 상황, 불편 지점, 원하는 변경 사항을 분리해서 적습니다. 추측성 표현은 줄이고 상담 중 확인된 사실만 씁니다.

6. 후속 전달이 필요한지 판단합니다.  
   제품 변경 검토가 필요한 건은 제품기획팀이 주간 검토 대상으로 확인할 수 있도록 누락 없이 등록합니다.

제품기획팀은 매주 화요일 오전 11시에 지난주 VOC 신규 건수를 검토하고 상위 10건을 릴리스 후보로 표시합니다. 고객지원팀은 주간 검토 전에 별도 요약을 만들 필요는 없지만, 제목과 본문만 보고도 이슈를 이해할 수 있게 작성합니다.

## 답변 예시

아래 예시는 가맹점에 직접 전달할 때 사용할 수 있는 기본 문구입니다.

- 불만 접수 시  
  현재 겪으신 불편 내용을 확인했습니다. 같은 유형의 의견과 함께 검토될 수 있도록 기록하겠습니다.

- 개선 제안 접수 시  
  요청하신 개선 의견을 확인했습니다. 사용 과정에서 불편하셨던 지점까지 함께 기록해 검토 대상으로 남기겠습니다.

- 반복 문의로 VOC 등록 시  
  같은 주제로 반복 문의가 확인되어 내부 검토용으로 기록하겠습니다. 당장 변경을 약속드리지는 않지만, 재발 여부와 개선 필요성을 함께 보겠습니다.

- 단순 문의로 종결 시  
  문의하신 내용은 사용 안내로 처리 가능한 항목입니다. 이번 건은 안내로 마무리하고, 같은 불편이 반복되면 추가로 검토하겠습니다.

## 에스컬레이션 기준

다음 경우에는 상담 종료로 두지 말고 등록 내용을 다시 확인합니다.

- 가맹점이 업무 중단 수준의 불편을 호소하며 개선 요청을 함께 한 경우
- 한 가맹점이 짧은 기간에 같은 주제로 반복 문의한 경우
- 여러 가맹점이 비슷한 표현으로 같은 불편을 제기한 경우
- 솔페이와 솔북이 연결된 흐름에서 불편이 발생해 분류 판단이 어려운 경우

분류가 애매하면 대표 불편 기준으로 1개를 선택하고, 본문에 다른 맥락을 짧게 보충합니다. 같은 내용을 카테고리별로 중복 등록하지 않습니다. 제품기획팀 확인이 필요한지 판단이 어려운 경우에도 우선 VOC로 남기고, 상담 기록만으로 끝내지 않습니다.
