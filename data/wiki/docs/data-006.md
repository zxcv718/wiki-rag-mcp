# 정산 분석 샌드박스 사용 기준

정산 분석 샌드박스는 정산 데이터 검토와 분석용으로 제공하는 개인 작업 공간입니다. 이 문서는 샌드박스에 반입할 수 있는 데이터 범위, 신청 시 확인 사항, 기본 조회 방법, 결과 반출 시 주의점을 정리합니다. 기준일은 2026-04-18입니다.

## 대상 데이터

정산 분석 샌드박스는 개인별로 1개만 발급합니다. 기본 보관 용량은 200GB입니다. 용량 한도 안에서 분석에 필요한 테이블 또는 추출 결과를 보관할 수 있습니다.

반입 가능한 데이터 기준은 아래와 같습니다.

| 구분 | 반입 가능 여부 | 비고 |
|---|---|---|
| 일반 정산 분석 데이터 | 가능 | 업무 목적 범위에서 사용합니다 |
| PII 등급 3등급 컬럼 | 가능 | 최소 범위로 반입합니다 |
| PII 등급 2등급 컬럼 | 승인 후 가능 | 사전 승인 없이 반입할 수 없습니다 |
| PII 등급 1등급 컬럼 | 불가 | 샌드박스로 반입할 수 없습니다 |

PII 등급은 개인정보 민감도를 1~3등급으로 나눈 사내 기준이며, 1등급이 가장 민감합니다. 분석 목적상 개인 식별이 꼭 필요하지 않은 경우에는 식별 가능 컬럼을 제외한 집계 형태로 반입합니다.

## 권한 신청

샌드박스 사용이 필요한 경우 데이터팀 담당자에게 신청합니다. 신청 시 아래 내용을 함께 전달합니다.

1. 신청자 소속과 이름
2. 사용 목적
3. 반입하려는 데이터 범위
4. PII 등급 포함 여부
5. 예상 보관 기간

PII 등급 2등급 컬럼이 포함되면 승인 완료 후에만 반입합니다. 승인 요청에는 해당 컬럼이 필요한 이유와 대체 가능한 비식별 집계 방식 검토 여부를 포함합니다. 승인 결과와 반입 범위는 추후 점검을 위해 문서 또는 메일로 남깁니다. 문의는 data-team@saesol.example로 보냅니다.

## 조회 방법

샌드박스에서는 필요한 컬럼만 조회하고, 중간 결과 테이블도 목적이 끝나면 정리합니다. 아래는 기본 조회 예시입니다.

```sql
SELECT
    settlement_date,
    merchant_id,
    SUM(amount) AS total_amount,
    COUNT(*) AS tx_count
FROM settlement_transactions
WHERE settlement_date >= DATE '2026-04-01'
  AND settlement_date < DATE '2026-05-01'
GROUP BY settlement_date, merchant_id
ORDER BY settlement_date, merchant_id;
```

개인 식별 가능성이 있는 컬럼이 포함된 원본성 조회는 필요한 기간과 범위로 제한합니다. 분석 결과를 재사용하려면 원본 전체를 반복 복사하기보다 집계 결과 테이블을 별도로 저장하는 방식을 우선 사용합니다.

## 보관과 자동 전환

샌드박스는 상시 보관 공간이 아니라 분석 작업용 임시 공간으로 사용합니다. 사용이 끝난 중간 산출물, 중복 적재 데이터, 재생성 가능한 결과는 직접 삭제합니다.

30일 동안 조회 이력이 없는 샌드박스는 자동으로 읽기 전용으로 전환됩니다. 읽기 전용 상태에서는 기존 데이터 조회만 가능하고 쓰기 작업은 할 수 없습니다. 다시 쓰기 권한이 필요하면 데이터팀에 전환 해제를 요청합니다. 장기간 미사용이 예상되면 필요한 결과만 별도 보관하고 샌드박스 내 데이터는 먼저 정리합니다.

기본 보관 용량 200GB를 초과할 가능성이 있으면 사전에 데이터팀과 적재 계획을 협의합니다. 불필요한 원본 복제는 용량 초과의 주요 원인이므로 피합니다.

## 주의점

샌드박스 결과를 전사 공유용으로 내보낼 때는 집계 기준 20건 미만 그룹을 제거해야 합니다. 이는 소수 집단이 드러나는 것을 막기 위한 최소 기준입니다. 전사 공유용 자료에는 개인 단위 레코드, 상세 식별 컬럼, 불필요한 원본 추출 파일을 포함하지 않습니다.

또한 아래 사항을 함께 지킵니다.

- 분석 목적과 무관한 컬럼은 반입하지 않습니다.
- 승인받은 범위를 넘는 추가 반입은 다시 검토받습니다.
- 파일로 내보낸 결과는 공유 대상에 맞는 최소 수준으로 가공합니다.
- 전 직원 대상 공유가 필요한 경우에는 집계 결과 중심으로 정리합니다.
- 외부 협력사와 공유가 필요한 경우에는 별도 승인 여부를 먼저 확인합니다.

기준 해석이 애매한 경우에는 임의로 반입하거나 공유하지 말고 데이터팀에 확인합니다.
