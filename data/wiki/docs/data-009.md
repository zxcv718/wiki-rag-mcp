# 정산 데이터 보존 기간 표

## 문서 개요
이 문서는 정산 관련 주요 데이터셋의 보존 기간과 삭제 주기를 표준화하기 위한 데이터 사전입니다. 데이터팀과 개발본부가 동일한 기준으로 조회, 적재, 삭제 작업을 수행할 수 있도록 현재 운영 기준을 표로 정리합니다.

적용 대상은 정산 처리와 연계된 원본 데이터, 실행 로그, 실험 연동 결과, 지급 파일 원본입니다. 본 문서의 기준일은 2026-09-22이며, 이후 변경 사항은 반영하지 않습니다.

## 용어
| 이름 | 뜻 |
|---|---|
| 정산 원장 | 누리가 만드는 가맹점별 정산 기준 테이블입니다. |
| 별빛 | A/B 실험 플랫폼입니다. |

## 데이터셋 기준 표
| 이름 | 뜻 | 갱신 주기 | 담당 | 보존 기간 | 삭제 주기 |
|---|---|---|---|---|---|
| 정산 원장 원본 테이블 | 정산 원장 원본 데이터입니다. | 일 단위 적재 | 데이터팀 | 25개월 | 월 단위 파티션 삭제 |
| 누리 실행 로그 | 누리 배치 실행 이력과 처리 로그입니다. | 배치 실행 시 생성 | 개발본부, 데이터팀 공동 확인 | 180일 | 일 단위 삭제 작업 |
| 별빛 실험 연동 결과 테이블 | 별빛 연동 결과를 저장하는 테이블입니다. | 일 단위 적재 | 데이터팀 | 13개월 | 월 단위 정리 |
| 정산 지급 파일 원본 | 지급 처리에 사용한 원본 파일입니다. | 지급 파일 생성 시 보관 | 데이터팀 | 5년 | 보존 기간 만료 후 삭제 |

## 운영 기준
1. 정산 원장 원본 테이블은 조회 빈도가 높고 재정산 검증에 사용되므로 25개월 동안 유지합니다. 삭제는 파티션 기준으로 수행하며, 반드시 "월 단위"로 처리합니다.
2. 누리 실행 로그는 장애 분석과 배치 추적에 필요한 범위만 유지합니다. 현재 기준 보존 기간은 "180일"입니다.
3. 별빛 실험 연동 결과 테이블은 실험 효과 분석과 정산 영향 검토에 필요한 기간만 보관합니다. 현재 기준 보존 기간은 "13개월"입니다.
4. 정산 지급 파일 원본은 지급 근거 확인과 사후 검증을 위해 장기 보관합니다. 현재 기준 보존 기간은 "5년"입니다.
5. 삭제 대상 판정은 데이터 생성 시각 또는 파일 생성 시각을 기준으로 합니다. 재적재가 발생한 경우에도 원본 생성 기준을 우선 적용합니다.
6. 보존 기간이 만료된 데이터는 복구 전제를 두지 않고 삭제합니다. 삭제 전 별도 백업이 필요한 경우에는 담당자가 사전에 검토합니다.

## 주의점
- 운영 DB에서 직접 삭제 작업을 수행할 때는 삭제 범위와 기준 시각을 먼저 확인합니다.
- 정산 원장 원본 테이블의 파티션 삭제는 월 경계가 맞는지 검증한 뒤 수행합니다.
- 누리 실행 로그는 분석용 추출본이 있더라도 원본 로그의 보존 기간을 임의로 늘리지 않습니다.
- 별빛 실험 연동 결과 테이블은 실험 종료 여부와 무관하게 동일한 보존 기준을 적용합니다.
- 정산 지급 파일 원본은 파일명 규칙이 바뀌어도 동일한 보존 기간을 적용합니다.
- 보존 기간 변경이 필요한 경우 데이터팀이 초안을 작성하고, 개발본부와 검토 후 본 문서를 갱신합니다.
