# 정산 데이터 조회 권한 신청 가이드

## 대상 데이터
이 문서는 운영 정산 스키마의 읽기 권한 신청과 첫 조회 기준을 안내합니다. 정산 데이터 조회 권한은 데이터팀과 개발본부 정규직 및 계약직만 신청할 수 있으며 외부 협력사는 직접 신청할 수 없습니다.

조회 대상은 운영 환경의 정산 관련 테이블과 뷰입니다. 쓰기, 수정, 삭제 권한은 이 문서의 범위에 포함하지 않습니다. 분석용 사본이나 별도 가공 데이터가 아닌 운영 정산 스키마를 조회하려는 경우에만 본 절차를 사용합니다.

## 권한 신청
신청 전에는 조회 목적과 필요한 범위를 정리합니다. 신청 내용이 불명확하면 승인 과정에서 보완 요청이 발생할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 신청 가능 대상 | 데이터팀, 개발본부 소속 정규직 및 계약직 |
| 신청 불가 대상 | 외부 협력사 |
| 신청 단위 | 개인별 신청 |
| 권한 범위 | 운영 정산 스키마 읽기 권한 |
| 표준 처리 시간 | 신규 권한 요청은 영업일 기준 2일 |

신청 시 아래 내용을 포함합니다.

1. 신청자 이름과 소속 팀
2. 조회 목적
3. 필요한 데이터 범위
4. 사용 기간 또는 지속 필요 여부
5. 팀장 확인 가능 여부

운영 정산 스키마 읽기 권한은 신청자 팀장과 데이터팀 DB 관리자 1명의 순차 승인을 받아야 합니다. 팀장 승인 후에 데이터팀 DB 관리자가 검토합니다. 승인자는 조회 목적, 범위의 적정성, 현재 업무와의 관련성을 확인합니다.

신청은 사내 메일로 접수합니다. 수신자는 신청자 팀장과 데이터팀 DB 관리자 1명을 함께 포함합니다. 문의가 필요한 경우 데이터팀 대표 메일 settlement-data@saesol.example로 연락합니다.

## 조회 방법
권한이 부여되면 다온 계정으로 데이터베이스에 접속하여 조회합니다. 다온은 사내 계정·SSO 시스템입니다. 권한 부여 후 첫 조회는 다온 계정 기준으로 90일 동안 유효하며 이후 접근 재인증 대상에 포함됩니다. 접근 재인증은 분기마다 권한 보유자가 계속 필요한지 확인하는 절차입니다.

아래는 읽기 전용 조회 예시입니다.

```sql
SELECT
    settlement_date,
    merchant_id,
    settlement_amount
FROM settlement.daily_settlement
WHERE settlement_date >= DATE '2026-08-01'
ORDER BY settlement_date DESC
LIMIT 100;
```

조회 시에는 필요한 컬럼과 기간만 지정합니다. 대량 조회가 필요한 경우에는 먼저 소량으로 검증한 뒤 범위를 넓혀 실행합니다.

## 주의점
운영 정산 스키마는 실제 정산 업무에 사용되는 데이터이므로 최소 권한 원칙에 따라 신청하고 사용합니다. 업무 목적이 종료되었거나 더 이상 조회가 필요하지 않으면 즉시 권한 해제를 요청합니다.

다음 경우에는 재신청 또는 추가 확인이 필요할 수 있습니다.

- 소속 팀이 변경된 경우
- 기존 신청 목적과 다른 범위의 조회가 필요한 경우
- 접근 재인증 과정에서 계속 필요 사유가 확인되지 않은 경우

권한을 다른 사람과 공유하거나 공용 계정으로 사용해서는 안 됩니다. 조회 결과를 별도 파일로 보관할 때에도 업무상 필요한 범위로만 다루어야 합니다. 승인 전 조회 시도, 승인 범위를 벗어난 조회, 타인 명의 사용은 허용하지 않습니다.
