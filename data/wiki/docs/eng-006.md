# 9월 누리 배치 마감 조정

## 배경
누리는 가맹점별 일 단위 정산 배치 시스템입니다. 개발본부에서는 누리 배치 완료 시각을 기준으로 후속 확인 작업과 장애 대응 우선순위를 판단합니다.

이번 달 변경으로 누리 배치 정상 마감 기준이 기존 03시 40분에서 03시 20분으로 앞당겨졌다. 이에 따라 완료 기준 시각과 경보 해석, 후속 검증 시점을 동일한 기준으로 맞춰야 합니다. 이 문서는 2026-09-12 기준으로 개발본부에서 확인해야 하는 최신 운영 기준만 정리합니다.

## 적용 규칙
아래 기준을 누리 배치 완료 판단의 기본값으로 사용합니다.

| 항목 | 기준 |
| --- | --- |
| 정상 완료 기준 | 누리 배치는 매일 03시 20분까지 완료되는 것을 정상으로 봅니다. |
| 경보 발생 조건 | 누리 배치가 03시 20분을 넘기면 NR-503 경보가 뜹니다. |
| 1차 대응 주체 | NR-503 발생 시 플랫폼·SRE팀 온콜이 먼저 대응합니다. |
| 후속 검증 실행 | 정산 원장 검증 쿼리는 배치 종료 직후 5분 안에 자동 실행됩니다. |

운영 시 해석은 다음과 같습니다.

1. 03시 20분 이전 또는 정각 완료는 정상으로 처리합니다.
2. 03시 20분을 초과한 완료는 지연으로 봅니다.
3. 지연이 확인되면 플랫폼·SRE팀 온콜이 먼저 상태를 확인하고, 필요 시 관련 담당자에게 전달합니다.
4. 정산 원장 검증 쿼리는 배치 종료 자체를 기준으로 이어서 실행되므로, 지연 완료인 경우에도 종료 직후 5분 안에 자동 실행되는지 함께 확인합니다.

## 운영 예시
아래는 완료 시각별 판단 예시입니다.

```text
예시 1
배치 완료: 03시 18분
판단: 정상 완료
후속 처리: 정산 원장 검증 쿼리 자동 실행 확인

예시 2
배치 완료: 03시 20분
판단: 정상 완료
후속 처리: 정산 원장 검증 쿼리 자동 실행 확인

예시 3
배치 완료: 03시 21분
판단: 지연 완료
경보: NR-503 발생
초기 대응: 플랫폼·SRE팀 온콜 확인
후속 처리: 정산 원장 검증 쿼리 5분 안 실행 여부 확인
```

## 체크리스트
누리 배치 관련 변경이나 점검 시 아래 항목을 함께 확인합니다.

- 배치 완료 기준 시각이 03시 20분으로 반영되어 있는지 확인합니다.
- 03시 20분 초과 시 NR-503 경보가 발생하도록 설정되어 있는지 확인합니다.
- NR-503의 1차 대응 주체가 플랫폼·SRE팀 온콜로 인식되고 있는지 확인합니다.
- 정산 원장 검증 쿼리가 배치 종료 직후 5분 안에 자동 실행되는지 확인합니다.
- 개발 문서, 운영 메모, 점검 절차서에 남아 있는 기존 03시 40분 기준이 있으면 함께 수정합니다.
