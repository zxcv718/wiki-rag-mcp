# 신규 개발자 온보딩 가이드

## 문서 목적과 대상
이 문서는 개발본부 신규 입사자가 입사 후 첫 2주 동안 무엇을 확인하고 어떤 순서로 적응하면 되는지 안내합니다. 대상은 개발본부 소속 입사자이며, 예시는 결제 스쿼드 페이코어 기준으로 적었습니다.

페이코어는 결제 기능을 담당하는 스쿼드입니다. 누리는 가맹점별 일 단위 정산 배치 시스템입니다. 스쿼드와 담당 업무에 따라 세부 일정은 다를 수 있으므로, 팀장과 버디 안내를 우선합니다.

## 첫날
첫날에는 업무를 바로 시작하기보다 기본 접근 권한과 커뮤니케이션 흐름을 확인합니다.

1. 팀장 또는 버디와 인사를 나누고 좌석, 장비, 기본 일정 안내를 받습니다.
2. 회사 계정으로 메일과 사내 메신저 로그인이 되는지 확인합니다.
3. 저장소 읽기 권한, 배포 로그 조회 권한, 개발용 데이터 조회 범위를 확인합니다.
4. 개발 환경에 필요한 프로그램을 설치합니다.
5. 전사 공지 스페이스와 개발 스페이스의 최근 공지를 읽습니다.
6. 페이코어 소속인 경우 정기 회의 시간을 캘린더에 등록합니다. 페이코어 스쿼드 스탠드업은 오전 10시 30분입니다.

첫날에 막히는 부분이 있으면 혼자 오래 해결하려 하지 말고 버디에게 바로 알립니다. 계정 발급이나 권한 누락은 플랫폼·SRE팀 또는 팀장을 통해 요청합니다.

## 첫 주
첫 주의 목표는 코드를 내려받아 실행하고, 작은 수정부터 배포 전 과정을 따라가 보는 것입니다.

가장 먼저 누리 로컬 환경을 구성합니다. 누리를 직접 담당하지 않더라도 정산 흐름을 이해하는 데 도움이 되므로 첫 주에 한 번은 실행해 봅니다. 환경 구성 중 데이터 연결이나 실행 순서가 막히면 버디와 함께 확인합니다.

첫 주 권장 순서는 아래와 같습니다.

| 항목 | 내용 |
|---|---|
| 코드 이해 | 저장소 구조, 주요 모듈, 실행 방법을 읽습니다. |
| 실행 확인 | 애플리케이션이 로컬에서 정상 기동하는지 확인합니다. |
| 테스트 | 단위 테스트와 기본 통합 테스트를 실행합니다. |
| 작은 수정 | 문구 수정, 로그 정리, 테스트 보강처럼 영향 범위가 작은 작업을 진행합니다. |
| 리뷰 경험 | PR 생성, 리뷰 반영, 병합까지 한 번 경험합니다. |

PR은 리뷰어 1명이 승인하면 병합할 수 있습니다. 다만 영향 범위가 크거나 DB 변경이 포함되면 팀장이나 담당자에게 한 번 더 확인받는 편이 좋습니다. 운영 DB 변경이 필요한 작업은 직접 적용하지 말고 DB 관리자와 사전 협의합니다.

## 둘째 주에 할 일
둘째 주에는 맡은 스쿼드의 실제 작업 방식에 맞춰 업무를 시작합니다.

1. 버디와 함께 최근 장애나 자주 수정되는 영역을 훑어봅니다.
2. 본인이 맡을 첫 작업을 정하고 예상 변경 범위를 정리합니다.
3. 제품기획팀 요구사항 문서나 이슈 설명을 읽고, 모호한 부분은 바로 질문합니다.
4. 테스트 작성 기준과 코드 리뷰에서 자주 지적되는 항목을 확인합니다.
5. 필요한 경우 데이터팀, 플랫폼·SRE팀, 정보보안팀과 협업 접점을 파악합니다.

둘째 주부터는 단순 수정 외에 작은 기능 개발이나 운영 이슈 대응 보조를 맡을 수 있습니다. 고객 영향이 있는 변경은 고객지원팀 문의 흐름을 함께 이해해 두면 도움이 됩니다. 정산 데이터 해석이 필요한 경우에는 데이터팀에 맥락을 설명하고 확인을 요청합니다.

## 도움받을 곳
문제가 생겼을 때는 주제에 맞는 담당 조직에 바로 연결하는 것이 가장 빠릅니다.

- 버디 또는 팀장: 우선순위, 업무 범위, 코드 구조, 리뷰 요청
- 플랫폼·SRE팀: 개발 실행 환경, 권한, 인프라 접근 문제
- DB 관리자: 스키마 변경, 조회 성능, 운영 DB 관련 확인
- 정보보안팀: 보안 정책 해석, 민감 정보 처리 기준
- 제품기획팀: 요구사항 의도, 릴리스 범위 확인
- 고객지원팀: 실제 가맹점 문의 사례와 재현 맥락 확인
- 인사팀: 입사 서류, 근태, 복리후생 일반 문의
- 재무팀: 비용 처리 문의

문의할 때는 아래 형식으로 정리하면 답변이 빨라집니다.

```text
제목: [온보딩 문의] 실행 오류 확인 요청
배경: 무엇을 하려는 중인지
시도한 내용: 어떤 명령 또는 절차를 수행했는지
현재 결과: 오류 메시지 또는 화면
원하는 도움: 권한 확인 / 실행 방법 / 담당자 연결
```

첫 2주에는 속도보다 맥락 이해가 중요합니다. 모르는 용어와 흐름은 메모해 두고, 같은 질문을 반복하지 않도록 정리하면서 적응합니다.
