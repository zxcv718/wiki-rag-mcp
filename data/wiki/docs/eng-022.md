# 사내 해커톤 운영 안내

## 대상

이 안내는 개발본부 구성원을 대상으로 합니다. 해커톤은 개발본부 내부 행사로 운영하며, 참가 신청과 팀 구성은 개발본부 인원을 기준으로 받습니다. 다만 발표 참관이나 결과 공유가 필요한 경우에는 제품기획팀, 플랫폼·SRE팀, 정보보안팀, 고객지원팀 등 관련 조직과 별도로 협의할 수 있습니다.

외부 협력사는 이번 운영 범위에 포함하지 않습니다. 개발본부 소속이 아닌 조직의 참여가 필요한 주제는 사전 검토 후 진행 여부를 정합니다.

## 일정과 운영 방식

해커톤은 11월 둘째 주 목요일부터 이틀 동안 엽니다. 진행 시간은 각 날짜의 일반 근무 시간 안에서 운영하는 것을 원칙으로 합니다. 행사 기간에는 참가자가 해커톤 과제에 집중할 수 있도록 소속 스쿼드의 일반 업무 일정을 미리 조정해 주시기 바랍니다.

운영은 아래 순서로 진행합니다.

1. 참가 신청 접수
2. 팀 확정
3. 주제 제출
4. 해커톤 진행
5. 결과 발표와 공유

세부 시간표와 발표 순서는 행사 시작 전에 개발 스페이스에 별도 공지합니다. 공지 이후 참가가 어려워진 경우에는 팀 일정에 영향이 없도록 가능한 빨리 알려 주시기 바랍니다.

## 팀 구성과 주제

팀은 3~5명으로 꾸립니다. 개인 참가나 2인 팀은 받지 않으며, 6인 이상 팀도 운영하지 않습니다. 한 사람은 하나의 팀에만 참여합니다. 팀 구성은 같은 스쿼드 내에서만 할 필요는 없으며, 개발본부 내에서 자유롭게 구성할 수 있습니다.

주제는 아래 범위 안에서 정합니다.

| 구분 | 내용 |
|---|---|
| 가능 | 제품 개선 아이디어 검증, 개발 생산성 개선, 운영 편의성 개선, 품질 향상 실험 |
| 제한 | 운영 중인 서비스 데이터에 직접 영향을 주는 변경, 보안 정책에 저촉될 수 있는 시도, 행사 기간 내 결과 확인이 어려운 과제 |

주제는 행사 전에 간단한 설명과 기대 결과를 함께 제출합니다. 제출 내용에는 해결하려는 문제, 구현 범위, 발표 시 보여 줄 결과를 포함해 주시기 바랍니다. 운영 DB 접근이나 정산 데이터 사용이 필요한 경우에는 사전에 관련 담당자와 협의해야 합니다.

## 신청 방법과 준비 사항

참가 신청은 개발 스페이스에 올라오는 신청 글에 댓글로 남기거나 안내된 메일로 제출합니다. 메일 제목은 아래 형식을 권장합니다.

```text
[해커톤 신청] 팀명 / 대표자명 / 인원
```

신청 시에는 다음 정보를 함께 적습니다.

1. 팀명
2. 팀원 이름과 소속
3. 대표자 연락처
4. 주제 한 줄 요약
5. 필요한 협조 사항

행사 전 준비는 각 팀이 직접 합니다. 개발 환경 구성, 테스트 데이터 준비, 발표 자료 초안 작성은 미리 진행해 주시기 바랍니다. 다만 운영 환경 변경, 공용 자원 사용, 보안 검토가 필요한 작업은 행사 시작 전에 확인을 받아야 합니다.

## 결과 공유와 문의

행사 종료 후 각 팀은 결과를 정리해 개발 스페이스에 공유합니다. 공유 내용은 문제 정의, 진행 내용, 결과, 후속 제안으로 간단히 정리하면 됩니다. 발표 자료나 시연 영상이 있으면 함께 첨부해 주시기 바랍니다.

운영 문의는 개발본부 행사 담당자에게 전달합니다. 일정, 참가 자격, 팀 구성 관련 문의는 메일 hackathon@saesol.example로 보내 주시기 바랍니다. 보안 검토가 필요한 내용은 정보보안팀과 별도 협의합니다. 데이터 사용이나 DB 관련 확인이 필요한 경우에는 해당 업무 담당자를 통해 사전 문의해 주시기 바랍니다.
