# 솔페이 API v1 지원 종료 연기 안내

## 개요

솔페이 API v1의 지원 종료일을 기존 계획보다 연기하여 "2026년 12월 31일"까지 운영합니다. 이번 변경은 대형 고객사의 전환 일정 조정에 따른 것으로, 현재 운영 중인 "가맹점 3곳"의 전환 완료 시점을 반영했습니다.

이번 연기는 기존 사용 중인 API v1 호출에만 적용합니다. API v1의 "신규 가입"은 더 받지 않습니다. 신규 연동이 필요한 경우에는 API v2를 사용해야 합니다.

개발본부에서는 API v1 관련 수정 요청을 받을 때 종료 일정이 연기되었다는 점을 안내하되, 신규 기능 추가나 확장 요구는 API v2 기준으로 검토합니다. 운영 안정성을 위한 필수 수정과 장애 대응은 종료일까지 계속 지원합니다.

## 적용 범위

이번 변경의 적용 범위는 다음과 같습니다.

1. 현재 솔페이 API v1을 사용 중인 기존 가맹점의 호출
2. 기존 연동의 유지보수, 장애 대응, 필수 보안 조치
3. 제품기획팀과 고객지원팀을 통한 종료 일정 안내

다음 항목은 이번 연기 대상에 포함하지 않습니다.

1. API v1 기반 신규 연동 개설
2. API v1 전용 신규 기능 개발
3. API v1을 기준으로 한 별도 확장 사양 제공

## 엔드포인트 안내

아래 엔드포인트는 종료 일정 안내를 위한 기준 예시입니다. 실제 호출 가능 여부는 현재 운영 중인 기존 연동에 한해 판단합니다.

| 구분 | 메서드 | 엔드포인트 | 상태 | 비고 |
|---|---|---|---|---|
| 결제 승인 | POST | /api/v1/payments | 유지 | 기존 연동만 지원합니다 |
| 결제 조회 | GET | /api/v1/payments/{paymentId} | 유지 | 기존 연동만 지원합니다 |
| 승인 취소 | POST | /api/v1/payments/{paymentId}/cancel | 유지 | 기존 연동만 지원합니다 |
| 신규 연동 신청 | POST | /api/v1/applications | 중단 | "신규 가입"을 받지 않습니다 |

## 요청·응답 예시

기존 연동 가맹점의 결제 조회 예시는 아래와 같습니다.

```http
GET /api/v1/payments/PMT-20260622-0001 HTTP/1.1
Host: saesol.example
Accept: application/json
Authorization: Bearer <토큰>
```

```json
{
  "paymentId": "PMT-20260622-0001",
  "status": "approved",
  "amount": 15000,
  "currency": "KRW"
}
```

신규 연동 신청 시도에 대한 응답 예시는 아래와 같습니다.

```http
POST /api/v1/applications HTTP/1.1
Host: saesol.example
Content-Type: application/json
Authorization: Bearer <토큰>

{
  "merchantName": "예시상점"
}
```

```json
{
  "message": "API v1 신규 연동은 지원하지 않습니다. API v2를 사용해 주시기 바랍니다."
}
```

## 오류 응답 및 안내 기준

API v1 관련 문의를 받을 때는 아래 기준으로 안내합니다.

| 상황 | 응답 원칙 |
|---|---|
| 기존 가맹점의 운영 문의 | 종료일까지 지원 대상임을 안내합니다 |
| 기존 연동 장애 | 원인 확인과 복구를 진행합니다 |
| 신규 연동 요청 | API v1은 불가하며 API v2 사용을 안내합니다 |
| 종료일 문의 | 지원 종료일은 "2026년 12월 31일"임을 안내합니다 |

고객지원팀 또는 제품기획팀에서 관련 문의를 전달할 경우, 개발본부는 연기 사유가 "가맹점 3곳"의 전환 일정 반영이라는 점을 동일하게 안내합니다. 외부 안내 문구가 필요한 경우 문구를 임의로 변경하지 말고 같은 의미로 유지합니다. 추가 확인이 필요한 사안은 제품기획팀을 통해 정리합니다.
