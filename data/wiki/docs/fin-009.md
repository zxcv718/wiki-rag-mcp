# 출장 중 숙박비 예외 승인 FAQ

## 적용 범위와 기본 원칙

### 어떤 경우에 이 FAQ를 보면 되나요?
출장 중 숙박비가 내부 기준을 넘기거나, 일정 변경과 장애 대응처럼 일반 청구 흐름으로 처리하기 어려운 상황에서 확인합니다. 이 문서는 예외 승인 판단과 제출 자료 중심으로 안내합니다. 실제 경비 청구 방법이나 마감 일정은 별도 안내를 따릅니다.

### 숙박비 예외 승인은 누가 보나요?
기본적으로 재무팀이 증빙과 사유를 확인합니다. 다만 같은 출장 건에서 숙박비 예외 요청이 2박을 넘으면 재무팀이 아니라 경영진·팀장 승인으로 상향됩니다. 상향 여부는 숙박 일수 기준으로 판단하며, 한 출장 안에서 나눠 올린 요청도 합산해서 봅니다.

## 자주 있는 예외 상황

### 행사장 지정 호텔만 사용해야 할 때는 어떻게 하나요?
행사 운영 측에서 지정한 숙소만 사용 가능한 경우에는 예약 확인서만 있으면 숙박비 기준 초과분에 대해 사전 예외 승인을 받을 수 있습니다. 이 경우에는 행사 안내문 전체가 없어도 되며, 숙소명과 일정이 확인되는 예약 확인서를 우선 제출하면 됩니다. 가능하면 출장 목적이 드러나는 일정 안내도 함께 첨부합니다.

### 급하게 출발해서 미리 승인을 못 받았으면 어떻게 하나요?
코드 프리즈 기간에 제품기획팀 릴리스 지원이나 핫픽스 창구 대응으로 급히 이동한 경우에는 출발 후 24시간 안에 예외 승인 요청을 올리면 됩니다. 사전 승인이 없었다는 이유만으로 바로 반려하지는 않습니다. 다만 요청서에는 급히 이동한 사유와 실제 출발 시각이 드러나야 하며, 관련 대화나 일정 변경 내역을 함께 첨부하는 것을 권장합니다.

### 장애 대응 때문에 현장에 하루 더 머문 경우도 인정되나요?
플랫폼·SRE팀이 NR-503 경보 대응을 위해 현장 체류를 연장한 경우에는 장애 대응 기록을 첨부하면 추가 1박까지 인정할 수 있습니다. 연장 사유가 단순 대기나 개인 일정 변경으로 보이지 않도록, 대응 시작 시각과 종료 시각이 포함된 기록을 제출해야 합니다. 추가 숙박이 필요했던 이유를 한두 문장으로 정리하면 검토가 빨라집니다.

## 제출 자료와 승인 흐름

### 어떤 자료를 같이 내면 되나요?
상황별로 아래 자료를 준비하면 됩니다.

| 상황 | 필수 자료 | 있으면 좋은 자료 |
|---|---|---|
| 행사장 지정 호텔 사용 | 예약 확인서 | 행사 일정 안내 |
| 급한 이동 후 사후 요청 | 이동 사유가 보이는 기록 | 일정 변경 내역 |
| NR-503 대응 연장 | 장애 대응 기록 | 체류 연장 사유 메모 |

증빙은 화면 캡처도 가능하지만, 날짜와 금액, 숙소명이 보이도록 제출합니다.

### 승인 요청은 어떤 순서로 올리면 되나요?
1. 출장 건 기준으로 예외 사유를 먼저 정리합니다.
2. 숙박 일수와 초과 사유를 적고 증빙을 첨부합니다.
3. 2박 이하이면 재무팀 검토를 기다립니다.
4. 2박 초과이면 경영진·팀장 승인으로 상향합니다.

같은 출장에 대해 여러 번 수정 요청이 생기면 기존 요청과 연결된다는 점을 본문에 적어 주는 것이 좋습니다.

## 자주 묻는 경계 사례

### 개인 사정으로 숙소를 바꿔 금액이 올라간 경우도 예외가 되나요?
원칙적으로는 어렵습니다. 교통 편의, 개인 선호, 동행자와의 합숙 회피 같은 사유만으로는 예외 승인 대상이 되지 않습니다. 다만 행사장 지정, 급한 릴리스 지원, 장애 대응처럼 업무상 불가피성이 확인되면 예외 검토가 가능합니다.

### 숙박비 예외와 다른 출장 비용도 한 번에 같이 물어봐도 되나요?
문의는 같이 할 수 있지만, 이 FAQ는 숙박비 예외 승인만 다룹니다. 교통비나 일비처럼 다른 항목은 각 기준에 따라 별도로 확인해야 합니다. 문서 범위를 벗어나는 항목은 재무팀 문의 메일로 분리해서 보내는 편이 처리에 유리합니다. 문의가 필요하면 재무팀 대표 메일을 사용합니다: finance@saesol.example
