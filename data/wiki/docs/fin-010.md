# 구매 요청 승인 권한표

## 목적
이 문서는 경비·구매 관련 요청 중 구매 항목에 대해 금액, 품목, 운영 영향에 따라 필요한 승인 권한과 검토 주체를 정리합니다. 팀별로 해석이 달라지는 일을 줄이고, 구매 요청자가 사전에 필요한 확인 절차를 준비할 수 있도록 하는 것을 목적으로 합니다.

## 적용 대상
이 문서는 전 직원의 구매 요청에 적용합니다. 정규직과 계약직이 업무 수행을 위해 요청하는 구매를 포함합니다. 외부 협력사의 자체 비용 집행에는 적용하지 않지만, 외부 협력사가 회사 비용으로 사용할 물품이나 서비스 구매를 요청하는 경우에는 동일하게 적용합니다.

다음 조직은 요청 성격에 따라 승인 또는 검토에 참여합니다.

- 경영진·팀장
- 재무팀
- 플랫폼·SRE팀
- 데이터팀
- 제품기획팀
- 정보보안팀

## 승인 기준
구매 요청은 아래 기준에 따라 승인합니다.

| 구분 | 기준 | 필수 승인·검토 |
|---|---|---|
| 일반 비품 | 총액 30만원 미만 | 소속 팀장 승인 |
| 일반 비품 | 총액 30만원 이상 | 소속 팀장 승인, 재무팀 확인 |
| 월 반복 비용 발생 구매 | 금액 무관 | 소속 팀장 승인, 플랫폼·SRE팀 검토 |
| 운영 변경 수반 구매 | 총액 200만원 이상 | 소속 팀장 승인, 관련 검토, CAB 검토 |
| 정산 데이터 파이프라인 관련 도구 | 금액과 무관 | 소속 팀장 승인, 데이터팀 승인 의견 |
| 보안 정책 영향 구매 | 금액과 무관 | 소속 팀장 승인, 정보보안팀 검토 |

기준 적용 시 아래 사항을 함께 봅니다.

1. 일반 비품은 소모품, 주변기기, 사무용 장비 등 반복 과금이 없는 항목을 말합니다. 일반 비품은 총액 기준으로 판단하며, 같은 목적의 구매를 나누어 요청해서는 안 됩니다.
2. 클라우드 크레딧이나 운영 인프라처럼 월 반복 비용이 생기는 구매는 금액과 무관하게 플랫폼·SRE팀 검토가 필요합니다.
3. 구매 결과로 운영 설정, 배포 구조, 접근 경로, 모니터링 방식 등 운영 변경이 함께 발생하면 운영 변경 수반 구매로 봅니다. 이번 달부터 CAB 검토 대상 기준은 300만원 이상이 아니라 200만원 이상입니다.
4. 정산 데이터 파이프라인에 쓰는 도구 구매는 데이터팀이 소속 본부와 별개로 정산 영향 여부를 확인한 뒤 승인 의견을 남겨야 합니다.
5. 솔페이·솔북의 출시 일정이나 고객 공지와 직접 연결되는 구매는 필요 시 제품기획팀이 일정 영향 의견을 남길 수 있습니다. 이 의견은 팀장 승인과 별도로 요청할 수 있습니다.

## 신청·처리 절차
1. 요청자는 구매 목적, 사용 부서, 총액, 반복 비용 여부, 운영 변경 여부를 정리해 제출합니다.
2. 소속 팀장은 업무 필요성과 예산 사용의 적절성을 먼저 확인합니다.
3. 아래 조건에 해당하면 추가 검토를 요청합니다.
   - 총액 30만원 이상인 일반 비품: 재무팀 확인
   - 월 반복 비용 발생: 플랫폼·SRE팀 검토
   - 운영 변경 수반 및 200만원 이상: CAB 검토
   - 정산 데이터 파이프라인 관련: 데이터팀 승인 의견
   - 보안 정책 영향 가능성 있음: 정보보안팀 검토
4. 모든 필수 승인·검토가 끝난 뒤 구매를 진행합니다.
5. 반려된 경우 요청자는 사유를 확인하고 내용을 보완해 다시 요청할 수 있습니다.

요청 내용에는 최소한 아래 항목을 포함합니다.

- 구매 품목과 수량
- 총액과 과금 방식
- 사용 목적
- 운영 변경 여부
- 사용 조직
- 납품 또는 사용 시작 희망 시점

## 예외 및 문의처
긴급 장애 대응 등 즉시 조치가 필요한 경우에도 사후 승인으로 대체할 수 있는 범위는 팀장이 먼저 판단합니다. 다만 월 반복 비용이 생기거나 운영 변경이 수반되는 경우에는 구매 후라도 반드시 관련 검토 이력을 남겨야 합니다.

승인 기준 해석이 애매한 경우에는 아래 순서로 문의합니다.

- 금액 및 경비 처리: 재무팀, finance@saesol.example
- 운영 영향 및 반복 비용: 플랫폼·SRE팀, sre@saesol.example
- 정산 영향: 데이터팀, data@saesol.example
- 보안 정책 영향: 정보보안팀, security@saesol.example
