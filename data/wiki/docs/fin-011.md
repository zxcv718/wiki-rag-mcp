# 법인카드 한도 예외 승인 기준

## 목적
이 문서는 법인카드의 월 사용 한도를 초과해야 하는 경우에 적용하는 예외 승인 기준을 정합니다. 예외 사용을 사전에 통제하고, 부서별 집행의 예측 가능성을 높이며, 사후 정산 과정에서 확인 기준을 일관되게 적용하는 것이 목적입니다. 본 기준은 통상적인 경비 사용을 장려하기 위한 문서가 아니라, 불가피한 상황에서만 한도 초과를 허용하기 위한 규정입니다.

## 적용 대상
이 기준은 전 직원에게 적용합니다. 법인카드를 업무상 사용하는 정규직과 계약직이 대상이며, 카드 명의자 본인이 신청해야 합니다. 외부 협력사는 적용 대상이 아닙니다.  
부서장, 팀장, 프로젝트 리더 여부와 관계없이 동일한 기준을 적용합니다. 다만 승인 권한과 사후 확인 책임은 재무팀과 해당 사용자의 소속 조직 관리자에게 있습니다.

## 기준
법인카드의 월 한도는 원칙적으로 카드별 설정값을 따르며, 월 한도를 넘는 사용은 예외로만 처리합니다.  
월 한도 500만 원을 넘는 사용은 재무팀장이 미리 승인합니다. 사후 보고나 사용 후 정산 요청만으로는 예외 승인으로 인정하지 않습니다.

예외 승인은 아래 기준을 모두 충족해야 합니다.

| 구분 | 기준 |
|---|---|
| 승인 시점 | 결제 전에 승인받아야 합니다 |
| 승인 권한 | 재무팀장이 승인합니다 |
| 허용 범위 | 업무 수행상 불가피하고 다른 결제 수단으로 대체하기 어려운 경우에 한합니다 |
| 빈도 제한 | 한도 예외 승인은 분기당 2회까지다 |
| 증빙 원칙 | 사용 목적, 예상 금액, 사용 일자, 관련 부서 확인 내용을 함께 제출해야 합니다 |

다음과 같은 경우는 원칙적으로 승인하지 않습니다.

- 개인 편의를 위한 선결제 또는 임의 결제
- 예산 검토 없이 반복적으로 발생하는 동일 성격의 초과 사용
- 사전 승인 없이 이미 결제가 완료된 건의 사후 추인 요청
- 카드 분할 사용 등으로 실질적인 한도 초과를 우회하려는 경우

## 신청·처리 절차
1. 신청자는 결제 전에 재무팀 공용 메일(finance@saesol.example)로 예외 승인을 요청합니다.
2. 메일에는 다음 내용을 포함합니다.
   - 신청자 이름과 소속
   - 사용 목적
   - 예상 사용 금액
   - 결제 예정일
   - 월 한도 초과가 필요한 사유
   - 소속 조직 관리자의 확인 내용
3. 재무팀은 제출 내용을 검토하고 필요 시 보완을 요청합니다.
4. 재무팀장이 승인 여부를 회신합니다.
5. 승인된 범위 안에서만 결제합니다.
6. 사용 후에는 일반 경비 처리 절차에 따라 증빙을 제출합니다.

승인 메일은 해당 월의 정산 근거로 보관합니다. 승인받은 금액이나 목적이 실제 사용과 다를 경우 재무팀은 추가 소명을 요청할 수 있습니다. 승인 내역은 월말에 재무팀이 카드 사용 내역과 전수 대사합니다.

## 예외
긴급한 운영 이슈, 대외 계약 일정, 행사 집행 등으로 당일 결제가 불가피한 경우에도 사전 승인 원칙은 유지합니다. 다만 결제 직전에라도 재무팀에 요청해 재무팀장의 승인을 먼저 받아야 합니다.  
재무팀 부재 등으로 즉시 확인이 어려운 경우에는 소속 조직 관리자가 필요성을 먼저 확인할 수 있으나, 이는 사용 판단을 보조하는 절차일 뿐 승인 자체를 대체하지 않습니다. 최종 승인 권한은 재무팀장에게 있습니다.

## 문의처
기준 해석이나 신청 가능 여부가 불명확한 경우 재무팀에 문의합니다.  
- 메일: finance@saesol.example
- 대상: 재무팀

정책 위반이 반복되거나 고의성이 있다고 판단되는 경우, 재무팀은 해당 건을 소속 조직 관리자와 함께 검토할 수 있습니다.
