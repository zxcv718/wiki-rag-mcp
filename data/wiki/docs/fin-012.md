# 외부 회계 감사 대응 자료 목록

## 대상
이 문서는 외부 회계 감사 시 자료를 준비하거나 제출 요청을 받는 전 직원을 대상으로 합니다. 실제 제출 창구는 재무팀이 맡고, 자료 원천을 보유한 부서는 요청에 따라 초안을 준비합니다.

주요 참여 부서는 다음과 같습니다.

| 구분 | 역할 |
| --- | --- |
| 재무팀 | 감사 대응 총괄, 요청 접수, 제출본 취합 및 이력 관리 |
| 개발본부 | 매출 인식 근거 자료, 운영 로그성 보조 자료 확인 |
| 플랫폼·SRE팀 | 인프라 관련 사실 확인 자료 제공 |
| DB 관리자 | 운영 DB 기준 조회, 추출 결과 검증 |
| 데이터팀 | 정산 관련 집계 검토, 수치 대사 지원 |
| 제품기획팀 | 계약 변경, 릴리스 이력 등 사실 확인 |
| 고객지원팀 | 환불, 취소, 고객 문의 이력 확인 |

감사 대응 기간은 3월 첫째 주부터 2주입니다. 이 기간에는 자료 요청과 제출이 집중되므로, 관련 부서는 담당자를 비워 두지 않도록 준비합니다.

## 준비할 것
외부 회계 감사에서 반복적으로 요청되는 자료는 아래와 같습니다.

- 전년도 월별 매출 집계표
- 매출 인식 기준 설명서
- 계약서, 변경 합의서, 청구 내역
- 환불, 취소, 조정 내역
- 계정별 원장 및 전표 사본
- 표본 거래의 근거 자료
- 접근 권한 또는 변경 이력 확인 자료
- 감사 질의에 대한 회신 초안

매출 인식 자료는 누리의 정산 원장에서 뽑습니다. 정산 원장을 기준으로 월별 합계와 표본 거래를 함께 준비하고, 재무팀 집계표와 차이가 없는지 먼저 대사합니다.

자료 파일은 다음 원칙으로 정리합니다.

- 파일명에 연도, 월, 자료명, 작성 부서를 넣습니다.
- 스캔본은 누락 페이지가 없도록 하나의 PDF로 합칩니다.
- 엑셀 추출본은 필터나 수식이 깨지지 않았는지 확인합니다.
- 제출용과 작업용을 구분해 보관합니다.
- 개인정보나 불필요한 내부 메모는 제출 전에 제거합니다.

## 단계별 절차
1. 재무팀은 감사 시작 전 주에 예상 요청 목록과 담당 부서를 정리해 공유합니다. 공유는 전사 공지 스페이스 또는 사내 메신저 공지로 진행합니다.

2. 감사인의 자료 요청은 재무팀 공용 메일로만 받습니다. 개별 직원이 메일, 전화, 대면으로 직접 요청을 받아도 접수로 보지 않으며, 즉시 재무팀 공용 메일로 전달해 달라고 안내합니다.

3. 재무팀은 요청 건별로 담당 부서, 제출 기한, 요청 범위를 기록하고 자료 번호를 부여합니다.

4. 담당 부서는 원천 자료를 추출하거나 수집합니다. 매출 관련 자료는 정산 원장을 기준으로 준비하고, 계약 및 환불 자료는 원본과 사본의 일치 여부를 확인합니다.

5. 자료 작성자는 수치 대사와 누락 여부를 자체 점검합니다. 합계, 기간, 표본 건수, 파일 열림 여부를 확인한 뒤 재무팀에 초안을 전달합니다.

6. 재무팀은 제출 형식, 마스킹 필요 여부, 설명 문구를 검토합니다. 보완이 필요하면 같은 자료 번호로 재요청합니다.

7. 최종본은 재무팀이 제출하고, 제출 일시와 제출 파일명을 남깁니다. 감사 중 추가 질문이 오면 기존 자료 번호에 연결해 관리합니다.

## 자주 하는 실수
- 감사인의 요청을 개인 메일로 받아 바로 회신합니다.
- 정산 원장이 아닌 임의 집계 파일을 기준으로 매출 자료를 만듭니다.
- 월별 합계는 맞지만 표본 거래의 세부 금액이 다릅니다.
- 계약 변경분이 반영되지 않은 구버전 계약서를 제출합니다.
- 스캔본 일부 페이지가 빠졌는데 검토 없이 전달합니다.
- 제출본에 내부 검토 의견이나 담당자 개인 연락처를 남깁니다.
- 같은 요청에 대해 여러 부서가 각각 다른 수치를 전달합니다.

위 사례를 막기 위해, 모든 자료는 재무팀 제출 전 최종 확인을 거쳐야 합니다.

## 문의처
- 총괄 문의: 재무팀 공용 메일 finance@saesol.example
- 매출 인식 자료 확인: 재무팀 담당자 또는 데이터팀 협조 창구
- 운영 DB 조회 사실 확인: 해당 DB 관리자
- 보안 검토가 필요한 경우: 정보보안팀

긴급 문의가 있어도 감사인에게 직접 회신하지 말고, 먼저 재무팀 공용 메일로 요청 내용을 모아 전달합니다. 재무팀이 접수 기준과 제출 순서를 정리해 안내합니다.
