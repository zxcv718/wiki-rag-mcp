# 택시·야간 귀가비 청구 안내

## 대상
이 문서는 전 직원을 대상으로 합니다. 야간 근무나 이른 출근으로 실제 택시 이용이 발생한 경우에만 청구할 수 있습니다.

다음 조건을 모두 만족해야 합니다.

| 구분 | 청구 가능 조건 |
| --- | --- |
| 퇴근 귀가 | 업무로 인해 오후 11시 이후 퇴근한 경우 |
| 출근 이동 | 업무로 인해 오전 6시 이전 출근한 경우 |
| 증빙 | 택시 이용 내역과 업무 사유를 함께 제출한 경우 |

다음 경우는 청구 대상이 아닙니다.

- 개인 사유로 늦게 퇴근하거나 일찍 출근한 경우
- 대중교통 이용이 가능한 시간대인데 개인 판단으로 택시를 이용한 경우
- 딥워크 데이에 개인 일정으로 늦게 퇴근한 경우
- 외부 협력사 인력의 비용을 대신 청구하는 경우

딥워크 데이에 청구하려면 개인 일정이 아니라 업무 지시 또는 장애 대응 기록이 있어야 합니다.

## 준비할 것
청구 전에 아래 자료를 준비합니다.

- 택시 이용 영수증 또는 호출 내역 캡처
- 출발 시각과 도착 시각이 보이는 화면
- 출발지와 도착지가 확인되는 자료
- 업무 사유를 설명하는 짧은 메모
- 팀장 사전 승인 메시지 사본. 편도 금액이 4만원을 넘는 경우에만 필요합니다
- 장애 대응 귀가비인 경우 대응 기록

장애 대응으로 청구할 때는 PIR이 열리는 사고가 아니어도 DRI 이름과 대응 시작 시각을 반드시 적어야 합니다. 별도 회의나 문서가 없는 경우에도 이 항목은 생략할 수 없습니다.

## 단계별 절차
1. 청구 가능 여부를 먼저 확인합니다. 퇴근은 오후 11시 이후, 출근은 오전 6시 이전인 경우만 대상입니다.
2. 택시 이용 직후 영수증이나 호출 내역을 저장합니다. 금액, 이용 시각, 이동 구간이 보이도록 준비합니다.
3. 업무 사유를 정리합니다. 야간 배포, 긴급 수정, 장애 대응, 고객 이슈 처리 등 실제 업무 내용만 적습니다.
4. 편도 금액을 확인합니다. 편도 기준 4만원 이하면 일반 증빙만 제출합니다. 4만원을 넘으면 팀장 사전 승인 메시지를 증빙에 첨부합니다.
5. 장애 대응 건이면 추가 정보를 적습니다. PIR 여부와 관계없이 DRI 이름, 대응 시작 시각, 본인 역할을 함께 적습니다.
6. 경비 청구 화면에 항목을 입력하고 증빙 파일을 첨부합니다. 메모에는 날짜, 택시 이용 사유, 퇴근 또는 출근 여부를 간단히 적습니다.
7. 제출 후 반려 여부를 확인합니다. 누락된 증빙이 있으면 재무팀 요청에 따라 보완합니다.

메모 예시는 아래 형식으로 작성하면 됩니다.

```text
2025-11-27 퇴근 귀가비 청구
사유: 장애 대응 후 귀가
DRI: 김하린
대응 시작 시각: 22:05
비고: 팀장 사전 승인 메시지 첨부
```

## 자주 하는 실수
- 퇴근 시각이 오후 11시 이전인데 청구하는 경우
- 출근 시각이 오전 6시 이후인데 청구하는 경우
- 편도 금액이 4만원을 넘는데 팀장 사전 승인 메시지를 첨부하지 않는 경우
- 딥워크 데이에 개인 일정으로 늦게 퇴근했는데 업무 건으로 잘못 제출하는 경우
- 장애 대응이라고만 적고 DRI 이름과 대응 시작 시각을 빠뜨리는 경우
- 택시 영수증 없이 카드 승인 문자만 제출하는 경우
- 왕복 금액을 한 건으로 합쳐 편도 기준 판단이 어렵게 제출하는 경우

## 문의처
제출 방법이나 반려 사유는 재무팀에 문의합니다. 업무 사유 인정 범위가 애매한 경우에는 제출 전에 팀장에게 확인합니다. 장애 대응 기록 정리가 필요한 경우에는 소속 팀장과 먼저 정리한 뒤 제출합니다.

- 재무팀: finance@saesol.example
- 일반 문의: 전사 공지 스페이스의 경비 관련 문의 게시판 이용
- 보안이나 개인정보가 포함된 증빙 정리가 필요한 경우: 정보보안팀에 별도 문의합니다.
