# 솔마켓 구매 요청 작성 가이드

## 대상
이 문서는 전 직원이 비품과 소프트웨어를 구매 요청할 때 참고하는 절차 안내입니다.  
솔마켓은 사내 비품·소프트웨어 구매 요청 포털입니다.

다음 대상이 이 문서의 직접 사용자입니다.

- 전 직원
- 팀 단위 예산을 사용하는 요청 작성자
- 소프트웨어 사용 부서의 대표 요청자

다만 외부 협력사인 레드브릭소프트 인력은 솔마켓 요청자가 될 수 없고 내부 담당 직원이 대신 신청해야 합니다. 협력 개발자가 실제 사용자이더라도, 요청 등록과 이후 확인은 내부 담당 직원이 진행합니다.

## 준비할 것
요청을 등록하기 전에 아래 정보를 먼저 정리합니다.

| 구분 | 준비 항목 |
|---|---|
| 공통 | 품목명, 수량, 사용 부서, 필요한 시점 |
| 분류 선택 | 하드웨어·소프트웨어·소모품 중 하나 |
| 고가 품목 | 사용 목적, 예상 사용자 수 |
| 소프트웨어 | 라이선스 수량, 사용 시작일, 갱신 여부 |
| 구독형 도구 | 종료 예정일, 계속 사용 여부 확인 담당자 |

요청자는 품목 분류를 하드웨어·소프트웨어·소모품 중 하나로 선택해야 합니다. 분류가 잘못되면 검토 부서가 달라져 처리 시간이 길어질 수 있습니다.

또한 솔마켓에서 단가 10만원 이상 품목을 요청할 때는 사용 목적과 예상 사용자 수를 필수로 입력해야 합니다. 이 정보가 없으면 요청이 반려되거나 보완 요청으로 돌아올 수 있습니다.

## 단계별 절차
1. 솔마켓에 접속해 새 구매 요청을 생성합니다.
2. 품목명을 입력하고 품목 분류를 선택합니다. 분류는 하드웨어, 소프트웨어, 소모품 중 하나만 선택합니다.
3. 수량과 필요한 시점을 입력합니다.
4. 단가가 10만원 이상인 경우 사용 목적과 예상 사용자 수를 입력합니다.
5. 소프트웨어인 경우 아래 항목을 추가로 입력합니다.
   - 라이선스 수량
   - 사용 시작일
   - 갱신 여부
6. 월 구독형 도구인 경우 종료 예정일을 확인 가능한 형태로 남깁니다. 최초 요청자는 종료 예정일 15일 전에 계속 사용 여부를 재확인해야 합니다.
7. 내용을 검토한 뒤 요청을 제출합니다.
8. 소프트웨어 구매 요청은 정보보안팀 검토가 끝나야 발주됩니다. 보안 검토 중 보완 요청이 오면 요청자가 내용을 수정해 다시 제출합니다.
9. 발주 이후 변경이 필요하면 기존 요청에 사유를 남기고 재무팀 또는 담당 검토자에게 문의합니다.

소프트웨어 요청 시에는 실제 사용자와 결제 요청자가 다를 수 있습니다. 이 경우에도 요청 본문에는 실제 사용 범위와 사용자 수를 기준으로 적습니다.

## 자주 하는 실수
- 품목 분류를 비워 두거나 잘못 선택합니다.
- 10만원 이상 품목인데 사용 목적과 예상 사용자 수를 적지 않습니다.
- 소프트웨어 요청인데 라이선스 수량, 사용 시작일, 갱신 여부 중 일부를 누락합니다.
- 월 구독형 도구를 요청한 뒤 종료 예정일 15일 전 재확인을 하지 않습니다.
- 레드브릭소프트 인력이 직접 요청하려고 합니다. 이 경우 내부 담당 직원이 대신 신청해야 합니다.
- 보안 검토가 필요한 소프트웨어를 일반 비품처럼 작성해 정보보안팀 검토가 지연됩니다.

## 문의처
- 작성 방법 문의: 재무팀, finance@saesol.example
- 소프트웨어 보안 검토 문의: 정보보안팀, security@saesol.example
- 협력 인력 관련 요청 주체 확인: 소속 부서 내부 담당 직원 또는 팀장
- 긴급한 보완 요청 확인: 사내 메신저로 재무팀 구매 담당자에게 문의합니다.

문의할 때는 요청 번호, 품목명, 요청 사유를 함께 전달하면 확인이 빠릅니다.
