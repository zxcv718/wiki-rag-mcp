# 재택근무 운영 지침 (2024)

## 목적
이 문서는 2024년 재택근무 운영 기준을 정리한 규정입니다. 전 직원이 동일한 기준으로 재택근무를 신청하고 수행할 수 있도록 신청 방법, 근무 방식, 예외 처리 원칙을 안내합니다. 본 지침은 근무 장소가 달라져도 업무 연속성과 협업 가능 상태를 유지하는 것을 전제로 합니다.

## 적용 대상
본 지침은 전 직원에게 적용합니다. 정규직과 계약직은 모두 포함합니다. 외부 협력사는 적용 대상에 포함하지 않습니다.

조직 특성상 팀별 운영 방식에 차이가 있을 수 있으나, 재택근무 가능 횟수와 기본 신청 방식은 본 지침을 우선합니다. 다만 고객 대응, 인프라 운영, 현장 확인, 대면 협업이 필요한 업무는 팀장이 출근 근무를 요청할 수 있습니다.

## 기준
재택근무 운영 기준은 아래와 같습니다.

| 항목 | 기준 |
| --- | --- |
| 사용 가능 횟수 | 주 2회까지 사용합니다 |
| 신청 마감 | 전날 오후 6시까지 팀장에게 신청합니다 |
| 신청 수단 | 사내 메신저로 신청합니다 |
| 필수 응답 시간 | 재택 중에도 오전 10시~오후 4시에는 메신저에 응답할 수 있어야 합니다 |

추가 기준은 다음과 같습니다.

1. 재택근무일에도 소속 팀의 업무 시작, 회의 참석, 일정 공유 방식은 출근일과 동일하게 유지합니다.
2. 재택근무 중에는 안정적으로 업무를 수행할 수 있는 환경을 스스로 확보해야 합니다.
3. 보안이 필요한 자료는 회사의 보안 정책을 준수하여 처리합니다.
4. 메신저 응답 가능 상태를 유지하되, 회의 중이거나 집중 업무로 즉시 응답이 어려운 경우에는 상태 표시나 짧은 안내 메시지로 상황을 공유합니다.
5. 재택근무는 승인된 날에만 적용하며, 승인 없이 임의로 근무 장소를 변경하지 않습니다.

## 신청·처리 절차
재택근무 신청과 처리는 아래 순서로 진행합니다.

1. 신청자는 재택근무 예정일의 전날 오후 6시까지 팀장에게 사내 메신저로 신청합니다.
2. 신청 메시지에는 재택근무 일자와 업무 예정 내용을 함께 적습니다.
3. 팀장은 팀 일정, 회의, 대면 업무 필요 여부를 확인한 뒤 승인 또는 조정 의견을 회신합니다.
4. 승인된 경우 신청자는 해당 일정에 맞춰 근무를 진행합니다.
5. 팀장이 부재 중인 경우에는 팀장이 사전에 지정한 업무 대행 관리자에게 동일한 방식으로 신청합니다.

신청 예시는 아래와 같습니다.

- 3월 12일 재택근무 신청합니다. 오전에는 정산 화면 기획 검토, 오후에는 개발 협업 회의 참석 예정입니다.
- 3월 14일 재택근무 신청합니다. 고객 문의 반영 사항 정리와 문서 작업 예정입니다.

## 예외
다음 경우에는 재택근무 신청이 제한되거나 조정될 수 있습니다.

1. 팀 단위 대면 회의, 교육, 면접 지원, 장비 점검 등 출근이 필요한 일정이 있는 경우
2. 고객지원, 인프라 운영 등 즉시 대응과 현장 확인이 필요한 업무를 수행하는 경우
3. 최근 근태 문제나 연락 두절 등으로 정상적인 재택근무 수행이 어렵다고 판단되는 경우
4. 회사 또는 부서의 긴급 운영 사정으로 일시적으로 출근 전환이 필요한 경우

불가피하게 재택근무 당일에 근무가 어려워지거나 응답 가능 상태를 유지할 수 없게 된 경우에는 즉시 팀장에게 알리고 안내를 받아야 합니다.

## 문의처
본 지침의 해석이나 운영 문의는 인사팀으로 전달합니다. 팀별 세부 운영과 일정 조정은 소속 팀장에게 먼저 문의합니다.
