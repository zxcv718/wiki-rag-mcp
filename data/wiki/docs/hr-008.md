# 신규 입사자 온보딩 체크리스트

## 대상

이 문서는 새솔소프트 전 직원 중 신규 입사자를 대상으로 합니다. 입사 첫 주에 공통으로 확인해야 할 항목만 정리합니다. 직무별 세부 설정, 팀별 개발 환경, 개별 장비 추가 신청은 소속 팀 안내를 따릅니다.

외부 협력사는 적용 대상이 아닙니다. 협력 개발자는 소속 회사와 계약 범위에 따라 별도 안내를 받습니다.

## 준비할 것

출근 전과 첫 출근 시 아래 사항을 준비합니다.

| 구분 | 준비 내용 |
| --- | --- |
| 출근 전 | 개인 연락 가능한 이메일 확인 |
| 출근 전 | 인사팀에서 보낸 안내 메일 확인 |
| 첫 출근 시 | 본인 확인이 가능한 신분 확인 수단 |
| 첫 출근 시 | 개인 이어폰, 충전기 등 업무에 필요한 개인 소지품 |
| 첫 주 내 | 교육 수강이 가능한 시간 확보 |

다온 계정은 입사 전날 발급됩니다. 계정 안내 메일을 받으면 이름, 이메일 주소, 초기 로그인 안내가 맞는지 먼저 확인합니다. 이상이 있으면 바로 인사팀에 회신합니다.

## 단계별 절차

1. 출근 전 안내 메일을 확인합니다.  
   인사팀에서 보낸 메일의 입사 일정, 첫 출근 시간, 준비물 안내를 읽습니다. 메일을 받지 못했으면 스팸함을 확인한 뒤 인사팀에 문의합니다.

2. 다온 계정으로 첫 로그인을 시도합니다.  
   다온 계정은 입사 전날 발급됩니다. 첫 로그인에 실패하면 여러 번 반복 시도하지 말고, 안내 메일의 회신 또는 인사팀 메일로 오류 내용을 전달합니다. 비밀번호는 개인 기기 메모장이나 종이에 적어 두지 않습니다.

3. 첫날 장비를 수령합니다.  
   입사 첫날 기본 업무 장비로 맥북 에어 13을 지급합니다. 수령 시 외관 이상, 전원 동작, 충전기 포함 여부를 바로 확인합니다. 이상이 있으면 당일에 담당자에게 알립니다.

4. 기본 업무 접속을 확인합니다.  
   장비 수령 후 다온 로그인, 이메일 수신, 사내 메신저 접속 가능 여부를 확인합니다. 접속이 되더라도 본인 이름, 부서, 직책 표시가 실제와 다르면 바로 수정 요청을 합니다.

5. 소속 팀 온보딩을 진행합니다.  
   팀장이 지정한 안내자와 함께 업무 시간, 협업 방식, 일정 관리 방식, 문서 위치를 확인합니다. 개발 직군은 팀 저장소 접근 권한, 실행 환경, 필수 프로그램 설치 여부를 점검합니다. 비개발 직군도 공용 문서와 업무 폴더 접근 권한을 확인합니다.

6. 필수 교육을 이수합니다.  
   첫 주 안에 보안 교육 1시간을 이수합니다. 교육 일정이 이미 지정되어 있으면 해당 시간에 참석하고, 별도 수강 방식이면 첫 주 안에 완료합니다. 수강 완료 기록이 필요한 경우 안내된 방식으로 제출합니다.

7. 문의 채널을 정리합니다.  
   인사 관련 문의, 장비 이슈, 업무 권한 요청, 보안 문의의 담당 부서를 구분해 둡니다. 첫 주에는 모르는 상태로 오래 두지 말고 바로 질문하는 것이 좋습니다.

## 자주 하는 실수

- 다온 계정 발급 메일을 개인 메일함에서 놓칩니다. 입사 전날 저녁까지 메일이 없으면 바로 확인 요청을 합니다.
- 장비 수령 후 충전기나 구성품 확인을 미룹니다. 누락은 당일 확인이 가장 빠릅니다.
- 첫 로그인 후 표시 정보가 잘못되어도 그냥 사용합니다. 이름이나 소속 정보 오류는 권한 처리 지연으로 이어질 수 있습니다.
- 보안 교육을 첫 주 후반으로만 미룹니다. 일정이 겹치면 누락되기 쉬우므로 초반에 시간을 확보합니다.
- 비밀번호를 메신저나 이메일로 전달받으려 합니다. 비밀번호는 안내된 절차 외 방식으로 요청하거나 공유하지 않습니다.

## 문의처

| 문의 내용 | 문의처 |
| --- | --- |
| 입사 일정, 서류, 계정 안내 메일 미수신 | 인사팀, hr@saesol.example |
| 장비 수령, 초기 장비 이상 | 소속 팀 안내자 또는 장비 전달 담당자 |
| 로그인 불가, 계정 정보 오류 | 인사팀, hr@saesol.example |
| 보안 교육 일정, 보안 정책 문의 | 정보보안팀, security@saesol.example |
| 업무 우선순위, 팀별 온보딩 일정 | 소속 팀장 또는 지정 안내자 |

문의할 때는 이름, 입사일, 소속 팀, 현재 발생한 문제를 함께 적어 전달합니다. 화면 오류가 있으면 민감한 정보가 보이지 않도록 확인한 뒤 캡처를 첨부합니다.
