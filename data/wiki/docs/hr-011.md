# 평가 이의신청 절차

## 대상

이 문서는 전 직원의 정기 평가 결과에 대한 이의신청 절차를 안내합니다. 협력사 인력은 대상에 포함하지 않습니다.

평가 결과에 이견이 있는 경우, 평가 결과 공지 후 5영업일 안에 인사팀 양식으로 이의신청할 수 있습니다. 이의신청은 평가 결과 전반에 대한 불만 제기 방식이 아니라, 본인 평가서에 포함된 사실 확인과 절차 준수 여부를 다시 검토받는 절차로 이해합니다.

다음 경우에 해당하면 이 문서를 기준으로 신청합니다.

- 평가서에 기재된 업무 사실, 역할, 성과 내용이 실제와 다르다고 판단하는 경우
- 평가 과정에서 확인되어야 할 의견 청취, 자료 반영, 검토 단계가 누락되었다고 판단하는 경우

다만 캘리브레이션에서 조정된 등급 자체만을 이유로 한 재심 요청은 접수하지 않습니다.

## 준비할 것

이의신청은 본인 평가서의 사실관계 오류와 절차상 누락을 중심으로 작성해야 합니다. 표현이 감정적이거나 포괄적이면 검토가 지연될 수 있으므로, 아래 자료를 먼저 정리합니다.

- 본인 평가서 사본
- 평가 결과 공지일 확인 자료
- 이의신청 사유 요약
- 사실관계 오류를 뒷받침하는 자료
- 절차상 누락을 설명할 수 있는 자료

권장 작성 방식은 다음과 같습니다.

| 항목 | 작성 기준 |
| --- | --- |
| 사실관계 오류 | 어떤 문장이 실제와 다른지, 무엇이 다르게 기록되었는지 구체적으로 적습니다. |
| 절차상 누락 | 어떤 절차가 빠졌는지, 본인이 언제 어떻게 인지했는지 적습니다. |
| 근거 자료 | 메일, 문서, 업무 기록 등 확인 가능한 자료만 첨부합니다. |
| 요청 사항 | 정정 요청인지, 재검토 요청인지 구분해서 적습니다. |

## 단계별 절차

1. 평가 결과 공지일을 확인합니다.  
   이의신청 가능 기간은 평가 결과 공지 후 5영업일입니다. 마감일이 지나면 접수하지 않습니다.

2. 인사팀 양식을 받습니다.  
   양식은 인사팀에 요청해 받습니다. 최신 양식 여부를 확인한 뒤 작성합니다.

3. 신청 사유를 정리합니다.  
   이의신청은 사실관계 오류와 절차상 누락을 중심으로 작성합니다. 단순히 등급이 기대와 다르다는 이유만으로는 접수 대상이 아닙니다.

4. 근거 자료를 첨부해 제출합니다.  
   작성한 양식과 첨부 자료를 인사팀 메일 hr@saesol.example로 제출합니다. 메일 제목에는 평가 이의신청임을 알 수 있게 적습니다.

5. 접수 여부를 확인합니다.  
   인사팀은 제출 서류의 누락 여부를 확인합니다. 보완이 필요한 경우 신청자에게 회신합니다. 다만 보완 요청이 있더라도 최초 신청 기한은 연장되지 않습니다.

6. 검토 결과를 받습니다.  
   이의신청 접수 후 10영업일 안에 팀장, 인사팀, 상위 조직장이 검토 결과를 회신합니다. 회신에는 인정 여부와 반영 내용 또는 반영하지 않는 사유가 포함됩니다.

## 자주 하는 실수

- 평가 등급이 아쉽다는 사유만 적는 경우  
  캘리브레이션에서 조정된 등급 자체만을 이유로 한 재심 요청은 접수하지 않습니다.

- 사실과 의견을 구분하지 않는 경우  
  “과소평가되었다고 느낀다”는 표현만으로는 검토가 어렵습니다. 어떤 항목의 어떤 내용이 실제와 다른지 적습니다.

- 근거 자료 없이 제출하는 경우  
  기억에 의존한 설명만 제출하면 판단이 지연될 수 있습니다.

- 여러 사안을 한 번에 섞어 쓰는 경우  
  사실관계 오류와 절차상 누락은 구분해서 작성합니다.

- 기한을 넘겨 제출하는 경우  
  결과 공지 후 5영업일이 지나면 접수하지 않습니다.

## 문의처

절차와 양식 문의는 인사팀에 합니다.

- 메일: hr@saesol.example
- 문의 내용 예시: 신청 가능 여부, 양식 요청, 제출 서류 확인, 접수 상태 확인

평가 내용 자체에 대한 설명이 먼저 필요한 경우에는 본인 팀장과 우선 확인한 뒤, 이의신청 필요 여부를 판단합니다. 다만 팀장과의 설명 과정이 이의신청 기한을 자동으로 연장하지는 않습니다.
