# 리프레시 휴가 운영 기준

## 목적
이 문서는 리프레시 휴가의 부여 대상, 사용 원칙, 신청 및 처리 절차를 정해 근속자 휴가 운영 기준을 일관되게 적용하기 위해 작성합니다.

리프레시 휴가는 근속 3년마다 주는 유급 휴가를 말합니다. 본 문서는 전 직원이 공통으로 확인해야 하는 운영 기준만 다루며, 급여 반영이나 근태 처리의 세부 입력 방식은 관련 담당 부서의 안내를 따릅니다.

## 적용 대상
리프레시 휴가 적용 대상은 다음과 같습니다.

- 전 직원
- 정규직과 계약직

다음 인력은 본 문서의 적용 대상에 포함하지 않습니다.

- 외부 협력사

휴직, 복직, 근속 산정 방식 등 개별 인사 이력에 따라 실제 부여일은 달라질 수 있으며, 최종 확인은 인사팀 기준을 따릅니다.

## 운영 기준
리프레시 휴가 운영 기준은 아래와 같습니다.

| 항목 | 기준 |
|---|---|
| 부여 단위 | 근속 3년마다 |
| 부여 일수 | 5영업일 유급 휴가 |
| 사용 기한 | 부여일로부터 12개월 이내 |
| 사용 방식 | 전일 단위 사용, 분할 사용 가능 |

세부 원칙은 다음과 같습니다.

1. 리프레시 휴가는 근속 3년마다 5영업일의 유급 휴가로 부여합니다.
2. 리프레시 휴가는 부여일로부터 12개월 안에 모두 사용해야 하며 분할 사용이 가능합니다.
3. 사용 기한 내에 사용하지 않은 잔여 일수는 별도 사유가 없는 한 자동 연장하지 않습니다.
4. 리프레시 휴가는 개인 사정, 휴식, 재충전, 가족 돌봄 등 용도로 사용할 수 있으며 사용 사유를 상세히 제출할 필요는 없습니다.
5. 팀 운영상 일정 조정이 필요한 경우에도 사용 기한 내 소진 원칙은 유지합니다.

## 신청·처리 절차
리프레시 휴가 신청과 승인 절차는 다음 순서로 진행합니다.

1. 신청자는 사용 희망 일정을 검토한 뒤 팀장과 사전 협의합니다.
2. 팀장은 리프레시 휴가 사용 계획이 팀 OKR 마감 주간과 겹치는지 먼저 확인합니다.
3. 3영업일 이상 연속 사용하려면 시작 15영업일 전에 신청하는 것을 원칙으로 합니다.
4. 1영업일 또는 2영업일 사용은 팀 일정에 지장이 없도록 가능한 한 미리 신청합니다.
5. 팀장 승인 후 인사팀이 최종 반영합니다.

운영상 유의사항은 다음과 같습니다.

- 팀장은 특정 시기에 업무 공백이 집중되지 않도록 팀 내 사용 일정을 조정할 수 있습니다.
- 고객 대응, 정산 마감, 대외 약속 등으로 팀 운영에 중대한 영향이 예상되면 팀장은 대체 일정을 협의할 수 있습니다.
- 신청자는 승인 전 교통, 숙박 등 비용이 발생하는 예약을 진행할 때 유의합니다.

## 예외
다음 경우에는 일반 원칙과 다르게 처리할 수 있습니다.

- 본인 또는 가족의 긴급한 사유로 사전 신청 기한을 지키기 어려운 경우
- 회사가 인정하는 불가피한 업무 사정으로 사용 일정 재조정이 필요한 경우
- 휴직, 복직, 퇴직 예정 등으로 사용 가능 기간 판단이 필요한 경우

예외 적용이 필요한 경우 신청자, 팀장, 인사팀이 함께 일정을 협의합니다. 다만 예외가 있더라도 리프레시 휴가의 기본 부여 단위와 사용 기한 원칙은 임의로 변경하지 않습니다.

## 문의처
제도 해석, 부여 대상, 근속 산정, 잔여 일수 확인이 필요한 경우 인사팀에 문의합니다.

- 문의 메일: hr@saesol.example
- 문의 방법: 사내 메신저 또는 메일
- 팀 일정 조정 관련 1차 문의: 소속 팀장

문서 내용과 실제 적용 사례가 다를 수 있다고 판단되면 개인 추정으로 처리하지 말고 인사팀 확인을 먼저 진행합니다.
