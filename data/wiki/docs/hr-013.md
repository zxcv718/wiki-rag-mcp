# 병가와 진단서 제출 기준

## 목적
이 문서는 질병이나 부상으로 정상 근무가 어려운 경우 병가를 사용하는 기준과 진단서 제출 기준을 정리하기 위해 작성합니다. 병가 사용 시 필요한 승인, 증빙 제출 시점, 감염성 질환 발생 시 처리 원칙을 함께 안내합니다. 본 문서는 전 직원이 공통으로 따르며, 병가 사용과 관련한 기본 판단 기준으로 활용합니다.

## 적용 대상
본 기준은 전 직원에게 적용합니다. 정규직과 계약직이 포함되며, 외부 협력사는 적용 대상이 아닙니다. 외부 협력사의 결근, 휴무, 증빙 제출은 해당 소속 회사 기준을 따릅니다.

## 기준
병가는 본인의 질병 또는 부상으로 근무 수행이 어렵다고 판단되는 경우 신청합니다. 단순 개인 일정 조정이나 사적 용무에는 사용할 수 없습니다.

병가 사용 기준은 아래와 같습니다.

| 항목 | 기준 |
| --- | --- |
| 연간 사용 한도 | 연간 최대 30일까지 신청할 수 있습니다. |
| 최초 증빙 면제 | 최초 3일은 진단서 없이도 사용할 수 있습니다. |
| 진단서 제출 기준 | 4일 이상 연속 병가를 쓰는 경우에는 의료기관 진단서 또는 소견서를 제출해야 합니다. |
| 감염성 질환 | 감염성 질환으로 재택근무가 불가능한 경우 팀장 승인 후 병가로 전환합니다. |
| 증빙 제출 기한 | 병가 증빙은 복귀일 다음 영업일을 포함해 7일 이내에 인사팀에 제출합니다. |

연간 한도는 해당 연도 내 사용 일수를 기준으로 관리합니다. 병가 일수 산정은 실제 근무일 기준으로 처리합니다. 반일 또는 일부 시간만 근무가 어려운 경우에도 병가 사용이 필요한지 먼저 팀장과 협의합니다.

진단서 대신 제출하는 소견서는 의료기관에서 발급한 문서여야 하며, 근무가 어렵다는 판단 근거와 기간이 확인 가능해야 합니다. 제출 서류의 판독이 어렵거나 기간이 확인되지 않는 경우 인사팀이 보완을 요청할 수 있습니다.

## 신청·처리 절차
1. 근무가 어렵다고 판단되면 가능한 한 빠르게 팀장에게 병가 사용 의사를 알립니다.
2. 연속 사용 예정 기간을 함께 전달합니다. 연장 가능성이 있으면 예상 기간도 공유합니다.
3. 최초 3일 이내 사용은 우선 병가로 신청하고, 4일 이상 연속 사용이 예상되면 의료기관 진단서 또는 소견서를 준비합니다.
4. 복귀 후 병가 증빙은 복귀일 다음 영업일을 포함해 7일 이내에 인사팀에 제출합니다.
5. 인사팀은 제출 서류와 사용 기간을 확인해 병가를 최종 반영합니다.

부득이하게 복귀 직후 바로 제출이 어려운 경우에는 기한 내에 인사팀에 사유를 먼저 알리고 제출 예정일을 안내합니다. 다만 사전 연락이 있더라도 증빙 제출 의무가 면제되지는 않습니다.

## 예외
감염성 질환으로 출근이 어렵고 재택근무도 불가능한 경우에는 팀장 승인 후 병가로 전환합니다. 이 경우에도 연속 사용 기간이 4일 이상이면 의료기관 진단서 또는 소견서를 제출해야 합니다.

응급 상황 등으로 당일 즉시 서류 확보가 어려운 경우가 있을 수 있습니다. 이런 경우에도 병가 사용 사실은 먼저 팀장에게 알리고, 증빙은 복귀 후 정해진 기한 안에 제출합니다. 제출 기한을 넘기거나 증빙이 확인되지 않으면 병가 인정이 제한될 수 있습니다.

## 문의처
병가 사용 가능 여부, 증빙 서류 형식, 제출 기한 확인이 필요하면 인사팀에 문의합니다. 팀 내 업무 인수인계나 복귀 일정 조정은 팀장과 협의합니다. 감염성 질환으로 근무 형태 판단이 필요한 경우에도 먼저 팀장에게 알린 뒤 인사팀과 추가로 확인합니다.
