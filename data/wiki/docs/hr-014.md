# 연차 사용과 승인 기준

## 목적
이 문서는 전 직원이 연차를 신청하고 승인받을 때 따르는 기본 기준을 정리합니다.  
연차 사용 시 업무 공백을 줄이고, 팀 단위 일정 조율 기준을 동일하게 적용하는 것을 목적으로 합니다.  
이 문서는 연차의 신청 시점, 승인 확인 항목, 예외 처리 원칙만 다룹니다.

## 적용 대상
이 기준은 전 직원에게 적용합니다. 정규직과 계약직을 포함하며, 외부 협력사는 포함하지 않습니다.  
팀별 운영 방식이 있더라도 본 문서의 기준을 우선 적용합니다. 다만 법령, 근로계약, 별도 인사 규정에 따라 더 우선하는 기준이 있으면 그 기준을 따릅니다.

## 기준
연차는 1일 단위 외에 반차와 반반차로 나누어 사용할 수 있습니다. 반반차는 2시간 단위 휴가를 뜻합니다. 반반차는 근태 기록에도 "2시간" 단위로 입력하고 승인받아야 합니다.

연차 신청과 승인 시 기본 기준은 아래와 같습니다.

| 구분 | 기준 |
| --- | --- |
| 일반 연차 | 신청 사유를 간단히 적고 팀장 승인을 받습니다. |
| 반차 | 오전 또는 오후 단위로 사용합니다. |
| 반반차 | 업무 인수인계가 필요한 경우 사용 전 전달 사항을 남깁니다. |
| 장기 연차 | 연속 5영업일을 초과하는 연차는 시작일 기준 최소 10영업일 전에 신청해야 합니다. |
| 동시 사용 | 같은 팀에서 같은 날짜에 3명 이상이 동시에 연차를 쓰려면 팀장이 업무 공백 계획을 함께 확인합니다. |
| 코드 프리즈 기간 | 코드 프리즈 기간에 페이코어와 그로스 스쿼드 구성원이 연차를 쓰려면 DRI 지정 여부를 승인 전에 확인해야 합니다. |

팀장은 승인 여부를 판단할 때 개인 사유의 상세 내용을 요구하지 않습니다. 다만 고객 대응, 배포 일정, 정산 마감, 장애 대응 등 당일 공백 영향이 큰 업무는 인수인계 여부를 확인할 수 있습니다.

## 신청·처리 절차
1. 연차 사용자는 사용 일자와 단위를 정해 연차를 신청합니다.  
2. 반차 또는 반반차를 사용하는 경우, 당일 업무 영향이 있으면 필요한 전달 사항을 팀 내에 공유합니다.  
3. 연속 사용 기간이 길거나 같은 날짜에 팀 내 사용자가 많은 경우, 팀장은 업무 공백 계획을 확인합니다.  
4. 승인권자는 아래 항목을 확인한 뒤 승인하거나 조정을 요청합니다.  
   1. 신청 일자와 단위가 맞는지  
   2. 인수인계가 필요한 업무가 있는지  
   3. 같은 팀의 동시 부재 인원이 과도하지 않은지  
   4. 코드 프리즈 기간이면 해당 스쿼드의 DRI 지정 여부가 확인되었는지  
5. 승인 후 일정 변경이 생기면 사용자가 다시 신청 내용을 수정하거나 취소 요청합니다.

긴급한 개인 사정으로 사전 신청이 어려운 경우에는 우선 팀장에게 알리고, 가능한 시점에 신청 내용을 보완합니다.

## 예외
예외 승인은 업무 연속성과 개인 사정을 함께 고려해 판단합니다.  
다음 경우에는 팀장이 관련 부서와 확인 후 예외 승인할 수 있습니다.

- 갑작스러운 질병, 가족 돌봄 등으로 사전 신청이 어려운 경우
- 고객지원 대응, 정산 처리, 배포 대응 등으로 대체 담당자 지정이 필요한 경우
- 코드 프리즈 기간 중이지만 DRI 지정과 인수인계가 완료된 경우

예외를 승인하더라도 근태 기록은 실제 사용 단위에 맞게 남겨야 합니다. 반반차를 여러 번 나누어 쓰는 경우에도 각각 "2시간" 단위로 기록합니다.

## 문의처
제도 해석이나 적용 기준 문의는 인사팀에 합니다.  
팀 일정과 승인 판단 기준 문의는 소속 팀장에게 먼저 확인합니다.  
코드 프리즈 기간의 업무 공백 확인이 필요한 경우에는 소속 팀장과 제품기획팀의 릴리스 일정 담당자에게 함께 확인합니다.  
문의가 문서 개정이 필요한 수준이면 인사팀이 전사 공지 스페이스 공지 여부를 검토합니다.
