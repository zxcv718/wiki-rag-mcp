# 시간외근무 승인 절차

## 대상
이 문서는 전 직원의 평일 시간외근무 신청과 사후 정산 절차를 안내합니다. 협력사 인력은 적용 대상이 아니며, 외부 협력사는 각 소속 회사 기준을 따릅니다.

적용 범위는 업무상 필요로 평일 소정 근무시간 이후 추가 근무가 발생하는 경우입니다. 장애 대응, 배포 후 확인, 고객 이슈 처리, 마감 대응 등 사유는 다를 수 있으나, 신청과 확인 방식은 이 문서를 따릅니다.

## 준비할 것
신청 전에 아래 내용을 정리합니다.

- 시간외근무 사유
- 예정 시작 시각과 종료 시각
- 수행할 업무 내용
- 확인 가능한 근거 자료
  - 일반 업무는 일정, 요청 내용, 산출물 등
  - 장애 대응은 장애 티켓
  - PIR 대상 장애 대응은 장애 티켓과 모아 기록

월 누적 시간이 많은 경우에는 사유를 더 구체적으로 적는 것이 좋습니다. 월 누적 시간외근무가 20시간을 넘으면 팀장과 경영진·팀장에게 사유가 자동 공유됩니다.

## 단계별 절차
1. 근무 필요성을 먼저 확인합니다.  
   같은 날 안에 처리해야 하는 업무인지, 다음 영업일로 조정 가능한지 검토합니다. 조정이 가능하면 시간외근무 신청 대신 일정 변경을 우선합니다.

2. 시작 전까지 신청합니다.  
   평일 시간외근무는 시작 전까지 근태 시스템에서 사전 승인을 받아야 합니다. 신청서에는 사유, 예상 시간, 업무 내용을 빠짐없이 적습니다. 팀장은 업무 필요성과 시간 적정성을 확인한 뒤 승인합니다.

3. 실제 근무를 수행하고 근거를 남깁니다.  
   업무 수행 사실이 사후에 확인될 수 있어야 합니다. 장애 대응인 경우 관련 기록을 남기고, PIR 대상 장애 대응 시간은 장애 티켓과 모아 기록으로 근무 사실을 확인합니다.

4. 긴급 상황이면 소급 신청합니다.  
   긴급 장애 대응으로 사전 승인이 어려운 경우 종료 후 1영업일 안에 소급 신청할 수 있습니다. 이때 신청 사유에 사전 신청이 어려웠던 이유와 실제 대응 시간을 함께 적습니다.

5. 근무 시간을 정산합니다.  
   승인된 신청과 실제 수행 시간을 기준으로 정산합니다. 예정 시간과 실제 시간이 다르면 실제 수행 내역에 맞게 수정합니다. 증빙이 부족하면 반려되거나 추가 확인이 필요할 수 있습니다.

6. 반려 또는 보완 요청이 오면 즉시 수정합니다.  
   팀장 확인만으로 판단이 어려운 경우 인사팀이 보완을 요청할 수 있습니다. 보완 요청을 받으면 같은 신청 건에서 사유와 근거를 정리해 다시 제출합니다.

## 자주 하는 실수
| 실수 | 문제점 | 올바른 처리 |
|---|---|---|
| 근무를 시작한 뒤 신청함 | 사전 요건을 충족하지 못합니다 | 시작 전까지 신청하고 승인 상태를 확인합니다 |
| 사유를 짧게만 적음 | 업무 필요성 판단이 어렵습니다 | 왜 당일 추가 근무가 필요한지 구체적으로 적습니다 |
| 예상 시간보다 길게 일했지만 수정하지 않음 | 정산 기록이 실제와 달라집니다 | 종료 후 실제 시간으로 수정합니다 |
| 장애 대응 근거를 남기지 않음 | 사후 확인이 어렵습니다 | 장애 티켓과 필요한 기록을 남깁니다 |
| 긴급 대응인데 며칠 뒤 소급 신청함 | 소급 허용 기한을 넘깁니다 | 종료 후 1영업일 안에 신청합니다 |

## 문의처
- 제도와 정산 기준 문의: 인사팀, hr@saesol.example
- 장애 대응 근거 확인 문의: 팀장에게 먼저 확인한 뒤 필요 시 플랫폼·SRE팀 또는 DB 관리자에게 문의합니다
- 신청 반려 사유 확인: 신청을 확인한 팀장에게 문의합니다

제도 해석이 애매한 경우에는 먼저 팀장과 상의한 뒤 인사팀에 문의합니다. 문서에 없는 예외 처리는 구두 합의로 진행하지 말고, 신청 기록에 남겨 확인 가능하게 처리합니다.
