# 후보자 개인정보 보관·파기 절차

## 대상
이 문서는 인사팀이 채용 과정에서 수집한 후보자 개인정보를 보관하고 파기할 때 따르는 기준을 안내합니다. 적용 대상은 이력서, 경력기술서, 포트폴리오, 면접 기록, 평판 확인 메모, 채용 보류 관련 동의 기록 등 후보자 식별이 가능한 자료 전체입니다.

후보자 자료에 PII 등급 1 정보가 포함되면 출력본 보관을 금지하고 열람 기록을 남긴 전자 파일만 유지합니다. 전자 파일은 접근 권한이 제한된 저장 위치에 두고, 열람 또는 전달이 필요한 경우에도 사본을 추가로 만들지 않습니다.

## 준비할 것
파기 작업 전 아래 사항을 확인합니다.

- 대상 후보자의 전형 상태
- 전형 종료일 또는 재검토 동의일
- 보관 중인 자료의 위치와 형태
- PII 등급 1 포함 여부
- 파기 완료 기록 작성자와 검토자 지정

보관 기준은 아래 표를 따릅니다.

| 구분 | 보관 기준 | 비고 |
|---|---|---|
| 불합격 후보자 | 전형 종료 후 180일 보관 | 기간 만료 다음 주 수요일 일괄 파기 |
| 채용 보류 후보자 | 재검토 동의가 있으면 동의일로부터 1년 보관 가능 | 동의 기록이 없는 경우 장기 보관하지 않음 |
| PII 등급 1 포함 자료 | 출력본 보관 금지 | 전자 파일만 유지 |

## 단계별 절차
1. 채용 건별로 후보자 목록을 확인합니다. 불합격, 채용 보류, 진행 중 상태를 구분하고, 진행 중인 건은 파기 대상에서 제외합니다.

2. 불합격 후보자의 자료는 전형 종료일을 기준으로 보관 만료일을 계산합니다. 전형 종료 후 180일 동안만 보관하고, 기간이 끝나면 다음 주 수요일에 일괄 파기 대상으로 묶습니다.

3. 채용 보류 후보자는 재검토 동의 여부를 확인합니다. 후보자가 재검토 동의를 남긴 경우에만 인사팀은 동의일로부터 1년 동안 자료를 유지할 수 있습니다. 동의가 없거나 철회된 경우에는 일반 보관 기준에 따라 정리합니다.

4. 자료 형태를 점검합니다. PII 등급 1 정보가 포함된 자료는 출력본이 있으면 즉시 회수하여 파기 대상에 포함하고, 열람 기록을 남긴 전자 파일만 유지합니다.

5. 파기를 실행합니다. 전자 파일은 복구가 어렵도록 삭제하고, 종이 문서는 내용 식별이 불가능하도록 파쇄합니다. 여러 저장 위치에 같은 자료가 있는 경우 모두 같은 날 처리했는지 확인합니다.

6. 파기 완료 기록을 남깁니다. 기록에는 담당자 1명과 검토자 1명의 이름, 파기 일시, 파기 방식 3가지를 반드시 적습니다. 예시는 아래와 같습니다.

| 항목 | 예시 |
|---|---|
| 담당자 | 김하나 |
| 검토자 | 이도윤 |
| 파기 일시 | 2026-03-11 14:00 |
| 파기 방식 | 전자 파일 삭제, 종이 문서 파쇄, 출력본 회수 후 폐기 |

## 자주 하는 실수
- 전형 종료일이 아니라 마지막 면접일을 기준으로 보관 기간을 계산합니다.
- 채용 보류 상태라는 이유만으로 동의 없이 자료를 계속 보관합니다.
- PII 등급 1 자료를 검토 편의를 위해 출력하여 보관합니다.
- 전자 파일만 삭제하고 메모나 인쇄본을 남깁니다.
- 파기 완료 기록에 검토자 이름 또는 파기 방식 작성을 누락합니다.

## 문의처
해석이 애매한 사례, 보관 기간 산정이 어려운 사례, 민감 정보 포함 여부 판단이 필요한 사례는 인사팀 내 채용 담당자에게 먼저 문의합니다. 보안 기준 확인이 필요한 경우에는 정보보안팀에 별도 문의합니다. 문의 메일은 hr@saesol.example로 접수합니다.
