# 징계 조사 착수와 소명 절차

## 대상
이 문서는 인사팀이 전 직원을 대상으로 징계 사안을 접수했을 때 조사 착수, 사실관계 통지, 소명 기회 부여, 최종안 정리까지의 기본 절차를 안내합니다. 협력사 인력은 대상에 포함하지 않으며, 외부 협력사 관련 사안은 계약 주관 부서와 별도 협의합니다.  
징계 사안은 근무 태도, 회사 자산의 부적정 사용, 직장 내 질서 위반, 보안 정책 위반 의심 등 인사팀 검토가 필요한 사안을 말합니다.

## 준비할 것
조사를 시작하기 전에 아래 자료를 가능한 범위에서 확보합니다.

| 항목 | 내용 |
| --- | --- |
| 접수 내용 | 신고 또는 전달된 사실관계 요약 |
| 접수 시각 | 인사팀이 최초로 확인한 일시 |
| 관련자 | 조사 대상자, 제보자, 참고인 |
| 증빙 | 메일, 문서, 로그, 녹취록, 이미지 등 |
| 부서 정보 | 소속 부서와 사건 관련 부서 |
| 보관 위치 | 조사 메모와 원본 자료의 분리 보관 여부 |

타 부서에서 전달된 사안은 전달 경로를 함께 적습니다. 특히 정보보안팀, 고객지원팀 등 타 부서 제보가 포함된 사건은 조사 메모에 제보 출처와 최초 접수 시각을 함께 남깁니다.

## 단계별 절차
1. 인사팀은 징계 사안을 접수하면 접수 내용을 검토하고 중복 여부를 확인합니다. 같은 사안을 여러 경로로 받은 경우에는 하나의 건으로 묶고 추가 제보만 연결합니다.

2. 인사팀은 접수 후 2영업일 안에 조사 착수 여부를 결정하고 접수 번호를 부여합니다. 조사에 착수하지 않는 경우에는 사유를 간단히 남기고 종결 처리합니다.

3. 조사 착수로 결정한 경우 조사 메모를 만들고 현재까지 확인된 사실, 확보한 자료, 추가 확인이 필요한 항목을 구분해 적습니다. 다른 부서 자료를 인계받은 경우에는 원본 수정 없이 사본으로 검토합니다.

4. 조사 대상자에게 사실관계 통지서를 보냅니다. 통지서에는 접수 번호, 확인 중인 사실의 범위, 소명 제출 방법, 제출 기한을 포함합니다. 통지서를 보낸 뒤에는 최소 48시간의 소명 준비 시간을 줍니다.

5. 소명은 서면을 원칙으로 받고, 필요한 경우 대면 또는 화상 면담을 진행합니다. 면담을 진행하면 참석자, 시작 시각, 종료 시각, 주요 진술을 조사 메모에 남깁니다. 조사 대상자가 추가 자료 제출 의사를 밝히면 접수 사실을 기록합니다.

6. 사실관계와 소명 내용을 함께 검토한 뒤 최종 징계안을 정리합니다. 최종 징계안은 경고, 감봉, 정직 가운데 하나로 정리해 인사팀장 결재선에 올리고 원본은 hr-internal에만 보관합니다.

7. 결재 완료 후에는 통지 대상과 통지 일시를 기록합니다. 조사 과정에서 확보한 불필요한 사본은 정리하고, 보관이 필요한 문서만 남깁니다.

## 자주 하는 실수
- 접수는 했지만 접수 번호를 바로 부여하지 않아 이후 자료 연결이 어려워지는 경우가 있습니다.
- 조사 메모에 최초 접수 시각을 빼먹어 경과 확인이 불명확해지는 경우가 있습니다.
- 사실관계 통지서 발송 직후 바로 면담 일정을 잡아 48시간 준비 시간을 보장하지 못하는 경우가 있습니다.
- 제보 부서와 조사 수행 부서를 혼동해 기록하는 경우가 있습니다.
- 최종 징계안 초안과 원본 문서를 같은 위치에 두어 보관 통제가 흐려지는 경우가 있습니다.

## 문의처
절차 운영 기준이나 문서 보관 방식이 애매한 경우 인사팀 내부 메일 hr@saesol.example로 문의합니다.  
보안 위반 의심 정황이 포함된 사건은 사실 확인 단계에서 정보보안팀과 협의하되, 조사 주관과 기록 관리는 인사팀이 맡습니다.
