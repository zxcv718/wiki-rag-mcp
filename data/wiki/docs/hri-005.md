# 채용 요청 접수와 승인 기준

## 대상
이 문서는 인사팀이 전 직원 대상 채용 요청을 접수하고, 승인 충족 여부를 확인할 때 사용하는 기준을 정리한 절차 안내입니다. 정규직과 계약직 채용 요청을 대상으로 하며, 외부 협력사인 레드브릭소프트 인력 요청은 전 직원 채용 절차와 분리해 관리하므로 이 문서의 채용 승인 대상에 포함하지 않습니다.

채용 요청을 올리는 부서는 요청 전에 내부 검토를 마친 상태여야 하며, 인사팀은 접수된 내용의 형식과 승인 상태를 확인한 뒤 후속 작업을 진행합니다.

## 준비할 것
채용 요청 접수 전 아래 항목을 준비합니다.

| 항목 | 내용 |
|---|---|
| 요청 시점 | 채용 시작 예정일 기준 최소 15영업일 전에 접수합니다. |
| 접수 위치 | 인사팀 스페이스인 hr-internal의 지정 양식을 사용합니다. |
| 기본 정보 | 채용 구분, 소속 조직, 채용 사유, 인원, 희망 시작 시점, 고용 형태를 적습니다. |
| 승인 정보 | 정규직 채용은 소속 팀장과 해당 본부장의 승인 여부를 확인합니다. |
| 직무 기술서 | 담당 업무, 필요 역량, 우대 사항을 포함해 작성합니다. |
| 개발본부 추가 기재 | 개발본부 포지션은 직무 기술서에 솔페이, 솔북, 페이코어 중 지원 조직과 관련된 서비스 또는 스쿼드명을 1개 이상 명시합니다. |

직무 기술서는 공고 작성의 기준 문서로 사용하므로, 실제 충원 목적과 다르게 넓게 쓰지 않도록 합니다.

## 단계별 절차
1. 요청 부서는 채용 필요 내용을 정리하고 hr-internal의 지정 양식에 초안을 작성합니다.

2. 인사팀은 접수 시점이 채용 시작 예정일 기준 최소 15영업일 이전인지 먼저 확인합니다. 기준에 미달하면 보완 요청 후 재접수로 처리합니다.

3. 인사팀은 요청 대상이 전 직원 채용 절차에 포함되는지 확인합니다. 레드브릭소프트 인력 요청은 별도 관리 대상이므로 본 절차의 승인 검토로 진행하지 않습니다.

4. 정규직 채용 요청인 경우, 소속 팀장과 해당 본부장의 승인이 모두 있는지 확인합니다. 두 승인 중 하나라도 누락되면 인사팀은 공고 작성을 시작하지 않습니다.

5. 인사팀은 직무 기술서의 필수 항목 기재 여부를 검토합니다. 특히 개발본부 포지션은 솔페이, 솔북, 페이코어 중 최소 1개가 지원 조직과 맞게 명시되어 있는지 확인합니다.

6. 누락이나 표현 수정이 필요한 경우 인사팀은 요청 부서에 보완을 요청합니다. 보완본이 접수되면 동일 기준으로 다시 확인합니다.

7. 승인과 서류 요건이 모두 충족되면 인사팀이 공고 작성을 시작합니다. 이후 공고 문안 정리는 요청 부서와 인사팀이 함께 맞춥니다.

## 자주 하는 실수
- 채용 시작 예정일만 적고 접수 시점을 늦게 잡는 경우가 있습니다. 최소 15영업일 기준을 먼저 확인합니다.
- 정규직 요청인데 팀장 승인만 받고 올리는 경우가 있습니다. 본부장 승인까지 모두 있어야 합니다.
- 개발본부 포지션의 직무 기술서에 조직 맥락이 빠지는 경우가 있습니다. 솔페이, 솔북, 페이코어 중 해당되는 이름을 반드시 넣습니다.
- 외부 협력사 요청을 일반 채용 요청과 같은 양식으로 보내는 경우가 있습니다. 레드브릭소프트 요청은 이 문서의 승인 대상이 아닙니다.
- 채용 사유를 지나치게 짧게 적어 충원 배경이 확인되지 않는 경우가 있습니다. 결원 보충인지 신규 역할인지 구분되게 작성합니다.

## 문의처
접수 양식 작성이나 승인 확인 기준이 불명확한 경우 인사팀에 문의합니다.

- 이메일: hr@saesol.example
- 사내 메신저: 인사팀 공용 문의 채널
- 문서 보완 요청 회신: 채용 요청을 올린 담당자가 직접 회신합니다.

인사팀은 접수 순서대로 확인하며, 승인 누락이나 필수 정보 미기재가 있으면 공고 작성 전에 먼저 보완을 요청합니다.
