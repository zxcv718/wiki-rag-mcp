# 채용 면접관 교육 운영 기준

## 목적

이 문서는 면접관으로 참여하는 구성원에게 적용하는 사전 교육 이수 기준과 운영 절차를 정리합니다. 채용 과정의 공정성, 지원자 경험의 일관성, 평가 기록의 품질을 유지하는 것을 목적으로 합니다.

본 기준은 인사팀이 주관하는 모든 정규 채용 면접에 적용합니다. 실무 면접, 협업 면접, 최종 면접 등 면접 형식과 관계없이 면접관으로 이름을 올리는 구성원은 동일한 기준을 따릅니다. 외부 협력사는 원칙적으로 면접관으로 참여하지 않으며, 내부 구성원만 면접관 대상에 포함합니다.

## 적용 대상과 기본 기준

면접관은 참여 전 6개월 이내에 인사팀 면접관 교육을 1회 이상 이수해야 합니다. 이수 기준을 충족하지 않은 경우에는 원칙적으로 면접관으로 배정하지 않습니다.

| 구분 | 기준 | 비고 |
|---|---|---|
| 적용 대상 | 전 직원 중 면접관으로 참여하는 구성원 | 정규직, 계약직 포함 |
| 이수 기한 | 면접 참여 전 6개월 이내 | 최근 이수 이력 기준 |
| 최소 이수 횟수 | 1회 이상 | 동일 기간 내 재수강 가능 |
| 교육 주관 | 인사팀 | 일정 공지와 이수 확인 담당 |
| 예외 처리 | 인사팀장 승인 시에만 가능 | 사유 기록 필요 |

교육은 채용 윤리, 질문 금지 항목, 평가표 작성 실습의 3개 세션으로 구성됩니다. 세션 중 일부만 참석한 경우에는 이수로 인정하지 않습니다. 교육 참석과 이수 여부는 인사팀이 확인 가능한 형태로 남겨 관리합니다.

## 교육 구성과 운영 방식

교육은 면접관 역할에 공통으로 필요한 기준을 중심으로 운영합니다.

1. 채용 윤리  
   지원자에 대한 존중, 직무 관련 정보만을 기준으로 평가하는 원칙, 면접 중 알게 된 정보의 취급 기준을 안내합니다.

2. 질문 금지 항목  
   직무 수행과 직접 관련이 없는 질문, 차별로 해석될 수 있는 질문, 사생활을 과도하게 확인하는 질문을 금지 항목으로 설명합니다. 면접관은 실제 면접에서 금지 항목을 우회하거나 반복 확인해서는 안 됩니다.

3. 평가표 작성 실습  
   관찰 사실과 해석을 구분하여 기록하는 방법, 근거가 드러나는 문장으로 평가를 남기는 방법을 실습합니다. 추상적 표현만 남기거나 개인적 호불호를 평가 근거로 쓰지 않도록 안내합니다.

개발 직무 면접관 교육 예시에는 허용 질문 사례를 포함합니다. 예를 들어 솔페이 장애 대응 경험에서 본인의 판단과 협업 방식을 묻는 질문, 구조 변경 전에 작성한 RFC 리뷰 경험에서 검토 관점과 의사결정 과정을 묻는 질문은 직무 관련 질문으로 다룹니다. 반대로 개인 배경을 추정하거나 사적인 생활 조건을 확인하는 방향의 질문은 허용하지 않습니다.

## 운영 절차와 예외 승인

1. 채용 일정이 확정되면 인사팀은 예정 면접관의 최근 교육 이수 여부를 확인합니다.
2. 이수 기준을 충족한 구성원만 면접관으로 확정합니다.
3. 미이수자가 포함된 경우 인사팀은 대체 면접관을 우선 검토합니다.
4. 대체가 어려운 경우에 한해 소속 팀장과 협의 후 인사팀장에게 예외 승인을 요청할 수 있습니다.
5. 교육 불참자가 불가피하게 면접에 들어가야 할 경우 인사팀장은 예외 승인 사유를 1회성으로만 남길 수 있다 는 원칙에 따라 해당 건에 한정해 기록합니다.
6. 예외 승인 후에는 가능한 가장 가까운 차수의 교육에 참석하도록 안내합니다.

예외 승인은 상시 허용이나 포괄 승인으로 운영하지 않습니다. 동일인이 반복적으로 예외 대상으로 지정되는 경우 인사팀은 해당 조직과 면접관 운영 방식을 다시 협의합니다.

## 기록 관리와 검토 주기

인사팀은 교육 일정, 참석자, 이수 여부, 예외 승인 내역을 문서로 관리합니다. 문의는 인사팀 대표 메일 hr@saesol.example로 받습니다.

본 기준은 반기마다 운영 사례를 기준으로 검토합니다. 다만 법령 변경, 채용 운영상의 중대한 이슈, 평가 기록 품질 저하가 확인되는 경우에는 반기 검토 이전에도 문구와 절차를 보완할 수 있습니다. 검토 시에는 교육 내용의 적정성, 질문 사례의 최신성, 예외 승인 빈도를 함께 확인합니다.
