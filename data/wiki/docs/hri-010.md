# 채용 오퍼 승인선과 예외 처리

## 목적
이 문서는 인사팀이 연봉 오퍼를 작성하고 검토할 때 적용하는 승인선과 예외 처리 기준을 정리합니다. 대상은 정규직과 계약직 채용 오퍼이며, 외부 협력사 인력 전환 제안은 포함하지 않습니다. 채용 부서가 개발본부, 제품기획팀, 고객지원팀 등 어디이든 동일한 기준을 적용합니다. 다만 직무 특성상 예외 검토가 필요한 경우에는 본 문서의 예외 절차를 따릅니다.

## 승인 기준
아래 기준은 후보자에게 조건을 안내하기 전에 모두 확인합니다.

| 항목 | 기본 기준 | 추가 승인 또는 처리 |
|---|---|---|
| 기본 연봉 | 해당 직급 밴드 내에서 작성합니다 | 기본 연봉이 해당 직급 밴드 중앙값의 110%를 넘는 오퍼는 인사팀장과 재무팀장의 사전 승인을 모두 받아야 합니다 |
| 입사 보너스 | 필요 시 제안할 수 있습니다 | 입사 보너스는 최대 500만원까지 제안할 수 있고 이를 초과하면 경영진·팀장 검토 안건으로 올립니다 |
| 후보자 안내 방식 | 승인 완료 후 서면으로 안내합니다 | 승인 전 조건 확정 안내는 하지 않습니다 |
| 제안서 유효기간 | 승인 완료 후 발송합니다 | 오퍼 승인 완료 후 후보자에게 발송하는 제안서 유효기간은 발송 시각부터 5일입니다 |

추가 승인 대상 여부는 인사팀 담당자가 1차 확인하고, 기준 초과 항목이 있으면 채용 부서 요청 사유를 함께 정리해 결재 전에 첨부합니다. 채용 부서가 예상 연봉 범위를 먼저 전달했더라도, 최종 오퍼 문안은 승인 완료 전까지 확정본으로 취급하지 않습니다.

## 예외 처리
예외는 채용 경쟁 상황이나 핵심 인력 확보 필요성이 있더라도 자동 승인되지 않습니다. 다음 경우를 특히 주의합니다.

1. 개발본부 긴급 채용에서 솔페이 또는 솔북 핵심 포지션으로 분류된 경우에도 구두 오퍼는 금지하고 승인 완료 문서를 먼저 남겨야 합니다.
2. 채용 부서가 후보자 일정 등을 이유로 당일 확답을 요청하더라도, 승인 전에는 검토 중이라는 사실만 안내합니다.
3. 기본 연봉과 입사 보너스가 동시에 기준을 넘는 경우에는 각각의 승인 요건을 모두 충족해야 합니다.
4. 예외 요청 사유에는 채용 난이도, 대체 가능 인력 여부, 입사 희망일, 사업 영향도를 포함해 기록합니다.

예외 검토 시 인사팀은 요청 부서의 필요성만 보지 않고 내부 형평성과 기존 재직자 보상 체계에 미치는 영향도 함께 확인합니다.

## 적용 절차
1. 인사팀 담당자는 채용 부서가 전달한 희망 조건을 기준표에 따라 검토합니다.
2. 기본 연봉, 입사 보너스, 기타 부가 조건 중 추가 승인이 필요한 항목을 표시합니다.
3. 추가 승인이 필요한 경우 인사팀장, 재무팀장 또는 경영진·팀장 검토 순서에 맞춰 사전 승인을 받습니다.
4. 승인 완료 문서를 남긴 뒤 후보자 제안서를 작성합니다.
5. 후보자에게 제안서를 발송하고, 발송 시각을 기준으로 유효기간을 계산합니다.
6. 후보자 회신이 유효기간을 넘긴 경우에는 기존 제안서를 그대로 연장하지 말고 채용 부서와 재검토합니다.

후보자와의 통화나 면담에서 조건을 설명할 때도 승인 여부가 불명확한 항목은 확정 표현을 쓰지 않습니다. 제안서 발송 후 조건 변경이 필요해지면 기존 제안의 효력을 종료한 뒤 수정본을 다시 승인받아 발송합니다.

## 검토 주기
이 문서는 인사팀이 반기별로 검토합니다. 직급 밴드 운영 방식, 재무 승인 기준, 채용 시장 상황에 변화가 있으면 정기 검토 전이라도 개정 여부를 확인합니다. 개정이 필요한 경우 인사팀이 초안을 작성하고 재무팀과 협의한 뒤 확정본을 인사팀 스페이스에 반영합니다.  
최종 수정일 기준으로 해석이 애매한 사례가 있으면 인사팀장이 우선 판단하고, 반복 발생 시 다음 개정안에 반영합니다.
