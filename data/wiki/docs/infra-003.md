# 2026년 8월 결제 지연 장애 PIR

## 요약
2026년 8월 결제 승인 처리 중 PRJ-204가 급증해 결제 승인이 47분 동안 지연됐습니다. 이번 장애는 솔게이트가 PG사 응답을 오래 기다리는 동안 시간 초과가 누적됐고, 그 결과 재시도 큐가 가득 차면서 정상 요청까지 대기열 뒤로 밀린 것이 직접 원인입니다.

영향받은 가맹점은 1,284곳입니다. 승인 실패가 대량으로 발생한 장애는 아니었지만, 승인 완료까지의 체감 시간이 길어져 매장 결제 흐름에 영향을 주었습니다. PIR에서는 탐지와 대응 과정, 구조적 원인, 재발 방지 작업을 정리합니다.

## 영향
이번 장애의 주요 영향은 다음과 같습니다.

- 결제 승인 응답이 평시 대비 크게 지연됐습니다.
- PRJ-204가 짧은 시간 안에 집중 발생했습니다.
- 솔페이를 사용하는 일부 가맹점에서 결제 대기와 재시도 문의가 증가했습니다.
- 고객지원팀으로 결제 지연 관련 문의가 유입됐습니다.

영향 범위는 승인 지연이 발생한 가맹점 기준 1,284곳으로 집계했습니다. 장애 시간 동안 요청 자체는 유입됐으나, 솔게이트 내부 대기열이 길어지면서 승인 완료 시점이 늦어졌습니다.

## 원인
원인은 PG사 응답 지연으로 재시도 큐가 가득 찬 것입니다. 솔게이트는 카드사·PG사와 연동하는 결제 게이트웨이 서비스인데, 당시 일부 요청에서 PG사 응답 시간이 길어졌습니다. 솔게이트는 응답을 기다리다 시간 초과되면 PRJ-204를 기록하고 재처리 대기열로 넘겼습니다.

문제는 시간 초과 자체보다, 같은 시점에 유입된 재시도 대상이 빠르게 쌓였다는 점입니다. 재시도 큐가 포화 상태에 가까워지면서 새 요청과 재시도 요청이 같은 처리 자원을 두고 경쟁했고, 그 결과 정상적으로 끝날 수 있는 요청도 뒤로 밀렸습니다. 즉, 외부 응답 지연이 시작점이었고 내부 대기열 설계가 지연 시간을 키웠습니다.

## 잘한 점과 아쉬운 점
잘한 점은 다음과 같습니다.

- PRJ-204 급증을 비교적 이른 시점에 확인했습니다.
- 플랫폼·SRE팀과 페이코어가 함께 원인 범위를 빠르게 좁혔습니다.
- 고객지원팀에 장애 성격을 정리해 전달해 현장 안내 혼선을 줄였습니다.

아쉬운 점은 다음과 같습니다.

- PG사 응답 지연이 시작됐을 때 재시도 큐 포화 위험을 더 빨리 경고하지 못했습니다.
- 시간 초과가 늘어날 때 승인 지연으로 번질 가능성을 운영 관점에서 즉시 드러내는 기준이 부족했습니다.
- 임시 조치 전까지 신규 요청 보호보다 재시도 누적 해소에 대응이 늦었습니다.

## 재발 방지 작업
재발 방지의 핵심은 솔게이트가 오래 대기하는 요청을 더 빨리 정리해 대기열 적체를 줄이는 것입니다. 이에 따라 솔게이트 타임아웃을 3초에서 2초로 줄였습니다. 이 변경은 느린 외부 응답이 내부 적체로 확대되는 시간을 줄이기 위한 조치입니다.
