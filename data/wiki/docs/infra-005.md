# 온콜 운영 가이드

## 목적
이 문서는 플랫폼·SRE팀과 개발본부가 함께 따르는 온콜 운영 기준을 정리한 문서입니다. 온콜은 운영 중 발생하는 긴급 이슈에 대해 담당자가 정해진 시간 동안 대응 책임을 갖는 방식으로 운영합니다. 목적은 호출 누락을 줄이고, 교대 기준과 응답 기준을 명확히 하며, 업무 시간 외 대응에 대한 최소한의 보상 기준을 통일하는 데 있습니다.

이 문서는 온콜 교대, 호출 응답, 인수인계, 주말 수당, 예외 처리만 다룹니다. 장애 등급의 정의나 원격 접속 방법, 보안 정책 세부 내용은 각 담당 문서를 따릅니다.

## 운영 규칙
온콜은 1주 단위로 교대합니다. 교대 시각은 월요일 오전 10시입니다. 교대 시점부터 다음 교대 시점 전까지의 운영 책임은 새 담당자에게 있습니다.

호출을 받으면 담당자는 15분 안에 응답합니다. 응답은 호출을 인지했고 대응을 시작했음을 분명하게 남기는 것을 의미합니다. 응답 후에는 상황을 확인하고, 단독 처리 가능 여부를 판단합니다. 즉시 해결이 어렵거나 영향 범위가 넓다고 판단되면 관련 담당자에게 지원을 요청합니다.

주말 온콜 수당은 하루 5만 원입니다. 주말에 실제 호출이 없더라도 해당 기간의 온콜 담당을 정상 수행했다면 지급 대상입니다. 수당 정산에 필요한 증빙은 호출 이력과 교대 기록을 기준으로 확인합니다.

운영 중에는 다음 원칙을 지킵니다.

1. 교대 전 담당자는 진행 중인 이슈와 주의 사항을 다음 담당자에게 전달합니다.
2. 교대 후 담당자는 호출 수단과 연락 가능 상태를 직접 확인합니다.
3. 응답 이후의 조치 내용은 다른 담당자가 이어받을 수 있도록 간단히 기록합니다.
4. 개발본부에서 발생시킨 변경으로 보이는 문제라도, 최초 대응 책임은 해당 주의 온콜 담당자에게 있습니다.
5. 고객 문의로 시작된 이슈는 고객지원팀 경로를 통해 공유되더라도 온콜 기준은 동일하게 적용합니다.

## 역할과 책임
| 구분 | 책임 |
|---|---|
| 플랫폼·SRE팀 온콜 담당자 | 교대 기간 중 호출 수신, 1차 확인, 초기 대응, 필요 시 관련 담당자 호출 |
| 플랫폼·SRE팀 팀장 | 교대표 확정, 공백 방지, 예외 승인, 분쟁 시 판단 |
| 개발본부 담당자 | 서비스 변경 사항 공유, 원인 파악 지원, 필요한 수정 수행 |
| DB 관리자 | 운영 DB 관련 이슈 확인 및 조치 지원 |
| 정보보안팀 | 보안 사고로 판단되는 사안에 대한 대응 방향 제공 |
| 고객지원팀 | 가맹점 문의 접수 시 운영 이슈 여부를 전달하고 진행 상황을 공유받음 |

교대 일정은 플랫폼·SRE팀이 관리합니다. 개발본부는 자신이 배포하거나 변경한 내용으로 인해 운영 영향이 발생할 가능성이 있으면 사전에 공유해야 합니다. DB 관리자와 정보보안팀은 각 전문 영역에 해당하는 이슈에서 지원 요청을 받으면 우선 확인합니다.

## 인수인계와 기록
인수인계는 월요일 오전 10시 교대 직전까지 마무리합니다. 전달 내용에는 최소한 다음이 포함되어야 합니다.

- 아직 종료되지 않은 이슈
- 반복 호출이 발생한 항목
- 주의가 필요한 작업이나 설정 변경
- 추가 확인이 필요한 로그 또는 데이터 상태

기록은 짧아도 되지만, 다음 담당자가 같은 상황을 다시 파악하는 데 필요한 수준은 남겨야 합니다. 기록에는 발생 시각, 최초 증상, 현재 상태, 다음 조치 예정 사항을 포함합니다. 민감한 값은 적지 않고 필요한 경우 <비밀번호> 같은 자리표시자를 사용합니다.

## 예외
불가피하게 교대가 어려운 경우에는 당사자끼리 임의로 바꾸지 말고 플랫폼·SRE팀 팀장 확인을 받아 조정합니다. 갑작스러운 병가, 경조사, 장시간 이동 등으로 정상 대응이 어렵다고 판단되면 가능한 한 빨리 알려야 합니다.

호출을 받았지만 통신 장애 등으로 즉시 접속이 어려운 경우에도 15분 안에 응답한다는 원칙은 유지합니다. 이때는 현재 대응이 지연되는 사유와 예상 가능한 다음 조치를 먼저 알립니다.

주말 온콜 수행 중 장시간 대응이 발생해 다음 근무일 업무 조정이 필요하면 팀장과 협의합니다. 다만 이 문서는 근무시간 조정 기준 자체를 정하지는 않습니다. 추가 보상이나 별도 처리 기준이 필요한 경우에는 재무팀과 인사팀의 관련 절차를 따릅니다.
