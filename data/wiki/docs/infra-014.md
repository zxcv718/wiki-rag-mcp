# 온콜 인수인계 메시지 템플릿

## 목적
이 문서는 플랫폼·SRE팀의 온콜 교대 시 운영 채널에 남기는 인수인계 메시지의 형식과 최소 전달 항목을 정의합니다. 교대 직후 확인 누락을 줄이고, 진행 중인 장애 대응과 변경 작업의 맥락이 끊기지 않도록 하는 것이 목적입니다.

온콜 인수인계 메시지는 교대 시작 30분 전까지 운영 채널에 올려야 합니다. 메시지는 다음 담당자가 추가 질문 없이 현재 상태를 파악할 수 있을 정도로 간결하고 구체적으로 작성합니다. 장문의 경과 보고보다 현재 상태, 남은 위험, 다음 확인 시점을 우선합니다.

## 메시지 형식
인수인계 메시지에는 아래 5개 항목을 반드시 포함합니다.

1. 활성 경보
2. 진행 중 변경
3. 미해결 티켓
4. 주의 서비스
5. 다음 점검 시각

NR-503나 PRJ-204가 열려 있으면 DRI 이름과 마지막 조치 시각을 인수인계 첫 줄에 적어야 합니다. DRI는 작업이나 장애의 직접 책임자 한 명을 뜻합니다.

하늘 배포가 남아 있는 경우 롤백 가능 시점과 모아 대시보드 링크를 함께 남깁니다. 하늘은 사내 배포 도구로 카나리 배포와 롤백을 지원합니다. 모아는 로그·지표·트레이스를 모으는 사내 관측 플랫폼입니다. NR-503은 누리 배치가 제시간에 끝나지 않을 때 뜨는 경보입니다.

권장 예시는 아래와 같습니다.

```text
[온콜 인수인계] 2026-09-26 야간 / 2026-09-27 주간
DRI: 김가온 / 마지막 조치 시각: 08:35

1) 활성 경보
- PRJ-204 1건 열림. 영향 범위와 현재 증상 1줄 요약
- NR-503 없음

2) 진행 중 변경
- 하늘 배포 진행 중: 대상, 현재 단계, 롤백 가능 시점 09:10
- 모아 대시보드: https://moa.saesol.example/<경로>

3) 미해결 티켓
- 티켓 번호, 현재 상태, 다음 담당 액션

4) 주의 서비스
- 지연, 오류율 상승, 외부 의존성 이슈 등 관찰 포인트

5) 다음 점검 시각
- 09:30
```

해당 사항이 없는 항목도 "없음"으로 적습니다. 같은 내용을 여러 곳에 나누어 남기지 말고, 운영 채널의 인수인계 메시지 한 건에 모아 적습니다.

## 역할과 책임
교대 종료 예정자는 인수인계 메시지를 작성하고 제때 게시할 책임이 있습니다. 교대 시작 예정자는 게시된 메시지를 확인하고, 이해가 되지 않는 항목이 있으면 교대 시작 전에 질문합니다.

개발본부에서 변경 작업을 진행 중인 경우에는 작업 담당자가 온콜 담당자에게 현재 상태와 위험 요소를 먼저 공유합니다. 운영 DB 관련 이슈가 포함된 경우에는 DB 관리자와의 최근 조치 내용을 미해결 티켓 또는 주의 서비스 항목에 반영합니다. 상세 쿼리, 비밀번호, 토큰 등 민감 정보는 남기지 않습니다.

## 예외
긴급 대응으로 인해 정해진 시각까지 전체 내용을 정리하기 어려운 경우에도, 최소한 첫 줄 상태 요약과 활성 경보, 다음 점검 시각은 먼저 올리고 나머지 항목을 바로 보완합니다. 교대 직전 새 장애가 발생한 경우에는 추정이나 미확인 내용을 늘리기보다 현재까지 확인된 사실만 적습니다.

운영 채널 접근 장애가 있는 경우에는 사내 메신저로 다음 온콜 담당자와 팀 공용 연락선에 동일 내용을 전달한 뒤, 채널 복구 후 운영 채널에 다시 남깁니다. 통화나 구두 전달만으로 인수인계를 끝내지 않습니다.
