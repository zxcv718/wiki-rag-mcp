# 장애 등급과 대응 절차

## 목적
이 문서는 서비스 장애를 같은 기준으로 판단하고, 등급별로 필요한 대응과 공유 절차를 맞추기 위해 작성합니다. 대상 서비스는 솔페이와 솔북이며, 플랫폼·SRE팀과 개발본부가 공통으로 따릅니다. 장애 등급은 고객 영향도와 서비스 핵심 기능 저하 범위를 기준으로 정합니다. 등급 판단은 최초 대응자가 임시로 시작할 수 있으나, 상황이 확인되면 관련 팀이 즉시 재판단합니다.

## 장애 등급 기준
장애 등급은 아래 기준으로 분류합니다.

| 등급 | 기준 | 예시 |
| --- | --- | --- |
| S1 | 핵심 기능이 광범위하게 중단되거나, 고객 피해가 빠르게 커지는 경우입니다. 특히 결제 실패율 5% 이상이 5분 넘게 이어질 때는 S1으로 분류합니다. | 결제가 대량 실패하거나, 예약 생성이 전면 불가한 경우 |
| S2 | 핵심 기능 저하가 뚜렷하고 다수 고객이 영향을 받지만, 전면 중단까지는 아닌 경우입니다. | 일부 결제 승인 지연, 특정 예약 흐름 실패가 지속되는 경우 |
| S3 | 영향 범위가 제한적이고 우회가 가능하며, 운영으로 통제가 가능한 경우입니다. | 일부 관리자 화면 오류, 특정 조건에서만 발생하는 성능 저하 |
| S4 | 장애로 분류하되 긴급 대응이 필요하지 않은 경미한 이상입니다. | 일시적 경고 증가, 고객 영향이 없는 내부 배치 실패 |

등급은 최초 인지 시점의 정보로 정하되, 고객 영향이 확대되면 상향합니다. 반대로 원인이 확인되어 영향이 제한적임이 분명해지면 하향할 수 있습니다. 다만 이미 대외 공유가 시작된 S1, S2는 하향 사유를 함께 남깁니다.

## 대응 절차
1. 장애를 인지한 사람은 즉시 관련 개발자와 플랫폼·SRE팀에 알립니다.
2. 최초 대응자는 고객 영향, 시작 시각, 현재 증상, 추정 범위를 확인하고 임시 등급을 정합니다.
3. S1 또는 S2로 판단되면 대응 책임자를 정하고, 복구 작업과 현황 기록을 병행합니다.
4. 고객지원팀 문의가 늘어날 가능성이 있으면 제품기획팀과 고객지원팀에 현재 상태와 고객 안내 문구 초안을 전달합니다.
5. 복구 후에는 원인, 영향 범위, 재발 방지 항목을 정리합니다.

공유 원칙은 다음과 같습니다.

- S1이면 30분마다 상황을 공유합니다.
- S2는 주요 변화가 있을 때마다 공유하고, 장기화가 예상되면 정기 공유 주기를 별도로 정합니다.
- S3와 S4는 관련 팀 중심으로 공유하되, 고객 영향이 확인되면 범위를 넓힙니다.

S1 공유 대상은 경영진·팀장, 플랫폼·SRE팀, 해당 스쿼드, 제품기획팀, 고객지원팀입니다. 필요하면 정보보안팀과 DB 관리자도 포함합니다. 공유 내용에는 현재 증상, 영향 범위, 임시 조치, 다음 확인 시점을 포함합니다.

## 역할과 책임
플랫폼·SRE팀은 장애 등급 판단 지원, 공용 인프라 확인, 복구 조치 조율을 맡습니다. 개발본부의 해당 스쿼드는 애플리케이션 원인 분석과 기능 복구를 담당합니다. DB 관리자는 데이터베이스 상태 확인, 성능 저하 분석, 긴급 조치를 수행합니다. 제품기획팀은 고객 공지 필요 여부와 릴리스 연계 영향을 판단합니다. 고객지원팀은 가맹점 문의 대응과 현장 정보 수집을 맡습니다. 정보보안팀은 보안 사고 가능성이 있거나 접근 통제가 필요한 경우 참여합니다.

S1과 S2 장애는 PIR을 엽니다. PIR은 장애 사후 검토 회의와 그 문서를 뜻합니다. 회의에서는 시간대별 경과, 직접 원인과 배경 요인, 대응 중 잘된 점과 미흡한 점, 재발 방지 항목을 정리합니다. 문서는 관련 팀이 다시 참고할 수 있도록 같은 내용으로 남깁니다.

## 예외와 보완
외부 협력사가 먼저 이상을 발견한 경우에도 내부 직원이 등급 판단과 공유 책임을 집니다. 단일 고객 환경 문제로 보이더라도 원인이 공통 구성에 있을 가능성이 있으면 낮은 등급으로 고정하지 않습니다. 정기 점검 중 발생한 문제라도 고객 영향이 실제로 발생하면 이 문서의 등급 기준을 그대로 적용합니다.

장애 종료 시점은 단순히 화면이 열리는 시점이 아니라, 핵심 기능이 안정적으로 동작하고 추가 확산 가능성이 낮다고 판단되는 시점으로 봅니다. 종료 선언 후에도 후속 오류가 이어지면 같은 건으로 다시 상향할 수 있습니다.
