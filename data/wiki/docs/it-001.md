# 다온 MFA 기기 등록 가이드

## 개요
다온은 사내 계정·SSO 시스템입니다. 이 문서는 다온에서 다중 인증 기기를 처음 등록할 때와 휴대전화를 교체할 때의 절차를 안내합니다.

다온은 전 직원에게 최소 1개의 기본 인증 기기와 1개의 예비 인증 기기 등록을 요구합니다. 예비 인증 기기는 기본 기기를 분실하거나 사용할 수 없을 때 본인 확인을 이어가기 위한 수단으로 사용합니다. 기본 기기만 등록한 상태로 두지 말고 같은 날 예비 기기까지 등록합니다.

경영진·팀장은 기기 등록을 마친 뒤 다온의 복구 코드 8개를 추가로 발급받아야 합니다. 복구 코드는 회사 승인 저장소가 아닌 개인 오프라인 매체에 보관해야 합니다.

## 지원 환경
| 항목 | 기준 |
|---|---|
| 대상 | 전 직원 |
| 등록 가능한 기기 | 휴대전화의 인증 앱이 설치된 기기 |
| 권장 구성 | 기본 인증 기기 1대, 예비 인증 기기 1대 |
| 사전 준비 | 다온 로그인 가능 상태, 인증 앱 설치 완료 |

다온에서 인증 앱 등록용 QR 코드를 발급하면 화면에 즉시 표시됩니다. 이 QR 코드는 발급 후 5분이 지나면 만료되어 다시 생성해야 합니다. 등록 중 시간이 지나 만료되면 이전 코드를 계속 사용하지 말고 새 코드를 발급받습니다.

## 설치 단계
1. 다온에 로그인합니다.
2. 계정 보안 설정 화면에서 다중 인증 기기 등록 메뉴를 엽니다.
3. 기본 인증 기기 추가를 선택합니다.
4. 화면에 표시된 QR 코드를 휴대전화의 인증 앱으로 스캔합니다.
5. 인증 앱에 표시된 일회용 인증번호를 입력해 기본 기기 등록을 완료합니다.
6. 같은 화면에서 예비 인증 기기 추가를 선택합니다.
7. 새로 발급된 QR 코드를 예비 기기의 인증 앱으로 스캔합니다.
8. 예비 기기의 인증번호를 입력해 예비 인증 등록을 완료합니다.
9. 경영진·팀장은 복구 코드 발급 메뉴에서 복구 코드 8개를 내려받거나 기록합니다.
10. 경영진·팀장은 복구 코드를 개인 오프라인 매체에 보관합니다.

휴대전화를 새 기기로 바꾸는 경우에는 아래 순서로 진행합니다.

1. 기존 휴대전화로 다온 로그인 승인 또는 기기 변경 승인을 먼저 완료합니다.
2. 다온의 기기 관리 화면에서 기존 기본 기기를 새 휴대전화로 교체합니다.
3. 새 휴대전화의 인증 앱으로 QR 코드를 스캔하고 인증번호를 입력합니다.
4. 교체가 끝나면 기존 예비 기기 상태를 확인합니다.
5. 예비 기기가 없거나 함께 교체해야 하는 경우, 기존 기기로 먼저 승인한 뒤 24시간 안에 예비 기기 등록까지 마쳐야 합니다.

## 접속 확인
기기 등록 또는 교체 후 아래 항목을 확인합니다.

- 다온 로그아웃 후 다시 로그인했을 때 기본 인증 기기로 인증이 완료됩니다.
- 기본 기기를 일시적으로 사용할 수 없는 상황을 가정해 예비 인증 기기로도 인증이 가능합니다.
- 기기 관리 화면에서 기본 인증 기기와 예비 인증 기기가 각각 1개 이상 표시됩니다.
- 경영진·팀장은 복구 코드 보관 위치를 본인만 확인 가능한 오프라인 매체로 유지합니다.

등록 확인 중 QR 코드가 다시 필요하면 새로 발급받아 사용합니다. 이전에 만료된 코드는 사용할 수 없습니다.

## 문제 해결
### QR 코드가 스캔되지 않는 경우
- 화면 밝기를 높인 뒤 다시 시도합니다.
- 인증 앱의 카메라 권한을 확인합니다.
- QR 코드 발급 후 5분이 지났다면 새 코드를 생성합니다.

### 휴대전화 교체 중 기존 기기를 사용할 수 없는 경우
기존 기기로 먼저 승인해야 하는 절차를 진행할 수 없으면 임의로 새 기기만 등록하지 않습니다. 소속 팀장에게 상황을 알리고, IT 헬프데스크로 문의합니다.

### 예비 기기를 등록하지 못한 경우
기본 기기 등록만 완료된 상태로 종료하지 않습니다. 가능한 즉시 예비 인증 기기를 추가합니다. 휴대전화 교체 직후라면 24시간 안에 등록을 마칩니다.

### 문의
진행 중 막히는 경우 IT 헬프데스크로 문의합니다. 문의 시 아래 내용을 함께 전달하면 확인이 빠릅니다.

- 사번
- 이름
- 등록 단계
- 사용 중인 기기 상태
- 화면에 표시된 안내 문구 또는 증상
