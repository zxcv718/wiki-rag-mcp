# 계정 비밀번호 정책 (2024)

## 목적

이 문서는 다온의 비밀번호 설정과 변경 기준을 정리합니다. 다온은 사내 계정·SSO 시스템입니다. 전 직원이 동일한 기준으로 계정을 사용하도록 하여 계정 탈취, 무단 접근, 단순 추측 공격의 위험을 줄이는 것을 목적으로 합니다.

## 적용 범위

이 정책은 전 직원이 사용하는 다온 계정에 적용합니다. 정규직과 계약직 모두 포함합니다. 외부 협력사는 이 문서의 직접 적용 대상이 아니며, 별도 계약이나 보안 안내에 따릅니다.

다온 계정을 통해 접근하는 업무용 서비스가 있더라도, 이 문서는 비밀번호 자체의 기준만 다룹니다. 접속 위치, 원격 접속 방법, 장비 설정, 기타 보안 통제는 이 문서 범위에 포함하지 않습니다.

## 규칙

다온 비밀번호는 아래 기준을 따라야 합니다.

| 항목 | 기준 |
| --- | --- |
| 변경 주기 | 비밀번호는 90일마다 변경합니다 |
| 길이 | 비밀번호는 최소 10자 이상으로 설정합니다 |
| 구성 | 비밀번호에는 특수문자를 포함합니다 |
| 로그인 실패 | 비밀번호를 5회 틀리면 30분 동안 잠긴다 |

추가로 아래 사항을 함께 지켜야 합니다.

1. 이름, 이메일 주소, 사번처럼 쉽게 추정할 수 있는 문자열은 비밀번호에 넣지 않습니다.
2. 다른 개인 서비스나 외부 사이트에서 사용한 비밀번호를 재사용하지 않습니다.
3. 종이에 적어 모니터에 붙이거나, 메모 파일 이름만 바꿔 저장하는 방식으로 보관하지 않습니다.
4. 본인 계정을 다른 사람과 공유하지 않습니다. 업무 편의를 이유로 전달하는 것도 허용하지 않습니다.
5. 비밀번호 변경 시 이전과 지나치게 유사한 조합은 피합니다.

비밀번호 예시는 아래처럼 이해합니다.

- 가능: 영문, 숫자, 특수문자를 조합한 문자열
- 불가: 사번이나 이름 기반의 단순 조합
- 불가: 특수문자가 없는 문자열
- 불가: 길이가 최소 기준보다 짧은 문자열

## 예외

원칙적으로 전 직원 계정에는 예외를 두지 않습니다. 다만 아래와 같은 경우에는 관리 목적의 별도 처리가 있을 수 있습니다.

1. 신규 계정 발급이나 초기화가 필요한 경우
2. 잠금 상태 해제가 필요한 경우
3. 계정 이상 징후가 확인되어 즉시 변경이 필요한 경우

이 경우 담당 부서는 상황에 따라 본인 확인 후 필요한 조치를 진행합니다. 본인 확인이 되지 않으면 해제나 초기화 요청을 처리하지 않습니다. 요청이 필요한 경우 정보보안팀 또는 계정 관리 담당 안내에 따라 접수합니다.

## 위반 시 조치

정책을 지키지 않아 계정 보안 위험이 발생하거나 반복적으로 기준을 위반한 경우, 계정 보호를 위해 비밀번호 초기화 또는 일시적인 사용 제한이 적용될 수 있습니다. 타인과 비밀번호를 공유했거나, 추정이 쉬운 비밀번호를 사용해 보안 사고 우려가 확인된 경우에는 추가 확인을 요청할 수 있습니다.

비밀번호를 잊었거나 계정이 잠긴 경우에는 임의로 반복 로그인하지 말고 정식 절차로 도움을 요청합니다. 문의가 필요한 경우 IT 헬프데스크 또는 정보보안팀 안내 채널을 이용합니다. 보안 사고가 의심되면 즉시 신고합니다.
