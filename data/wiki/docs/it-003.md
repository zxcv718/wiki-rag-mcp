# 솔넷 VPN 종료 후 클라이언트 정리

## 목적
이 문서는 솔넷 VPN 클라이언트를 장비에서 제거하는 기준과 예외 장비 관리 방법을 정리합니다. 솔넷 VPN은 2026년 6월까지 쓰던 옛 VPN이며, 현재는 솔패스가 이를 대체합니다. 솔패스는 제로트러스트 원격 접속 서비스로 운영합니다.

운영 중인 장비에 구형 접속 프로그램이 남아 있으면 보안 점검, 장애 분석, 사용자 지원 과정에서 혼선이 생길 수 있습니다. 따라서 솔패스 전환이 끝난 장비는 정해진 기한 안에 솔넷 VPN 클라이언트를 정리해야 합니다.

## 적용 범위
이 문서는 전 직원이 사용하는 회사 소유 장비에 적용합니다. 데스크톱, 노트북, 테스트용 예비 장비, 오프라인 보관 장비를 포함합니다.

외부 협력사가 사용하는 장비도 회사가 관리하는 장비이면 동일 기준을 적용합니다. 다만 실제 제거 작업 요청과 확인 책임은 해당 장비를 관리하는 내부 담당 조직이 집니다.

다음 조직은 본 문서와 관련된 역할이 있습니다.

| 조직 | 역할 |
|---|---|
| 정보보안팀 | 탐지 기준 운영, 제거 티켓 발행, 예외 승인 검토 |
| 플랫폼·SRE팀 | 공용 장비 정리 지원, 점검 협조 |
| DB 관리자 | 운영 DB 접근용 장비 점검 및 예외 사유 제출 |
| 개발본부 | 개발용 장비 자체 점검 및 제거 수행 |
| 데이터팀 | 데이터 처리 장비 점검 및 오프라인 장비 관리 |
| 고객지원팀 | 사용자 문의 접수 및 담당 조직 안내 |

## 규칙
1. 솔패스 등록이 완료된 장비는 솔넷 VPN 클라이언트를 제거해야 합니다. 2026년 9월부터 제거 기한은 솔패스 등록 후 "14일 이내"입니다.

2. 솔넷 VPN은 "2026년 6월"까지 쓰던 옛 VPN이므로 신규 설치는 어떤 예외 사유로도 허용되지 않습니다. 설치 파일 보관, 재설치 요청, 이미지 복원으로 인한 재설치도 모두 금지합니다.

3. 솔패스 전환이 끝난 장비에서 솔넷 VPN 프로세스가 탐지되면 정보보안팀이 "자동으로" 제거 티켓을 발행합니다. 티켓이 발행되면 장비 사용자와 관리 조직은 우선순위를 높여 조치해야 합니다.

4. 제거 완료 기준은 다음과 같습니다.
   - 장비에 솔넷 VPN 응용프로그램이 설치되어 있지 않습니다.
   - 부팅 후 솔넷 VPN 관련 프로세스가 실행되지 않습니다.
   - 자동 시작 항목에 솔넷 VPN이 남아 있지 않습니다.

5. 오프라인 보관 중인 예비 장비는 반기 점검 때 솔넷 VPN 잔존 여부를 확인하고 결과를 "6개월간" 보관합니다. 점검 결과에는 장비 식별 정보, 점검일, 확인자, 잔존 여부를 포함합니다.

## 예외
원칙적으로 사용 중 장비의 예외는 최소화합니다. 다만 다음 경우에는 제거 기한 유예를 요청할 수 있습니다.

- 장비가 오프라인 상태로 봉인 또는 보관 중이라 즉시 점검이 어려운 경우
- 운영상 중단이 어려운 장비로서 점검 창구가 별도로 필요한 경우
- 포렌식, 감사 대응 등으로 현재 상태 보존이 필요한 경우

예외 요청은 장비 소속 조직의 관리자 승인 후 정보보안팀에 메일로 제출합니다. 메일 제목은 `[예외 요청] 솔넷 VPN 클라이언트 정리` 형식을 사용합니다. 본문에는 장비 식별 정보, 보유 사유, 제거 예정일, 담당자 연락처를 포함합니다. 예외가 승인되더라도 신규 설치는 허용되지 않으며, 승인 기간이 끝나면 즉시 제거해야 합니다.

## 위반 시 조치
제거 기한을 넘기거나 승인 없이 솔넷 VPN을 유지한 경우 정보보안팀은 제거 티켓 발행, 장비 사용자 통지, 소속 조직 관리자 통보를 진행합니다. 반복 위반 장비는 업무 영향도를 검토한 뒤 네트워크 접근 제한 또는 추가 점검 대상으로 분류할 수 있습니다.

오프라인 예비 장비의 반기 점검 기록이 없거나 보관 기간을 지키지 않은 경우에도 관리 미흡으로 간주합니다. 장비를 관리하는 조직은 요청 시 점검 기록을 제출해야 합니다.
