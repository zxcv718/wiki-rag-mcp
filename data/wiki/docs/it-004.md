# 계정 인증 정책

## 목적
이 문서는 다온의 계정 인증 기준을 정리합니다. 다온은 사내 계정과 SSO를 제공하는 시스템입니다. 전 직원이 동일한 기준으로 비밀번호와 추가 인증을 관리하도록 하여 계정 탈취, 무단 접속, 자격 증명 재사용 위험을 줄이는 것을 목적으로 합니다.

## 적용 범위
이 정책은 전 직원이 사용하는 모든 다온 계정에 적용합니다. 정규직과 계약직을 포함하며, 협력사 인력은 각 계약과 별도 보안 지침을 따릅니다. 다만 사내 서비스에 접속하기 위해 다온 계정을 발급받아 사용하는 경우에는 이 문서의 인증 기준을 준수해야 합니다.

## 규칙
다온 계정의 기본 인증 규칙은 아래와 같습니다.

| 항목 | 기준 |
|---|---|
| 비밀번호 길이 | 최소 12자 |
| 비밀번호 변경 주기 | 정기 변경 요구하지 않음 |
| 추가 인증 | 모든 다온 계정에 MFA 필수 |
| 즉시 변경 조건 | 유출이 의심될 때 즉시 변경 |

세부 기준은 다음과 같습니다.

1. 비밀번호는 최소 12자 이상으로 설정합니다.
2. 비밀번호는 다른 개인 계정이나 외부 서비스에서 사용한 값과 동일하게 설정하지 않습니다.
3. 추측하기 쉬운 문자열, 개인 정보 기반 문자열, 단순 반복 문자열은 사용하지 않습니다.
4. 비밀번호는 메모지, 문서, 브라우저 자동완성 공유 환경 등에 평문으로 남기지 않습니다.
5. 비밀번호의 정기 변경은 요구하지 않습니다. 다만 계정 보호 필요성이 확인되면 즉시 변경합니다.
6. 모든 다온 계정에 MFA를 반드시 켜야 합니다.
7. MFA 수단을 변경하거나 재등록할 때에는 본인 확인 절차를 거칩니다.
8. 유출이 의심될 때는 지체 없이 비밀번호를 바로 바꾸고, 필요한 경우 정보보안팀에 알립니다.

비밀번호 변경이 필요한 대표 사례는 다음과 같습니다.

- 피싱 의심 페이지에 비밀번호를 입력한 경우
- 동일한 비밀번호를 사용한 외부 서비스의 침해 사실을 인지한 경우
- 본인 계정으로 기억하지 못하는 로그인 흔적을 확인한 경우
- 타인에게 비밀번호가 노출되었거나 공유되었다고 판단한 경우

## 예외
원칙적으로 모든 다온 계정은 동일한 기준을 적용합니다. 다만 아래와 같은 경우에는 운영상 예외 처리가 필요할 수 있습니다.

1. MFA 등록 수단의 분실, 교체, 고장으로 본인 인증이 불가능한 경우
2. 입사, 복직, 부서 이동 등으로 계정 재설정이 필요한 경우
3. 퇴사 처리, 장기 미사용 계정 정리, 보안 사고 대응 등으로 관리자가 인증 수단을 초기화해야 하는 경우

예외 처리는 임의로 진행하지 않으며, 정보보안팀 또는 계정 관리 담당자의 확인 후 처리합니다. 예외가 승인되더라도 비밀번호 기준과 MFA 적용 원칙 자체가 면제되는 것은 아닙니다.

## 위반 시 조치
이 정책을 지키지 않으면 계정 보호를 위해 다음 조치를 할 수 있습니다.

1. MFA 미설정 계정의 로그인 제한 또는 사용 중지
2. 유출 가능성이 있는 계정의 강제 비밀번호 변경
3. 본인 확인 전까지 계정 잠금 또는 인증 수단 초기화
4. 반복 위반 또는 고의 위반 건의 정보보안팀 검토

계정 이상이나 인증 문제를 발견하면 정보보안팀 또는 사내 헬프데스크로 문의합니다. 문의 시 비밀번호 자체는 전달하지 않으며, 필요한 경우 <비밀번호>와 같은 형태로만 표기합니다.
