# 솔넷 VPN 접속 가이드

사외에서 사내망에 접속할 때 사용하는 솔넷 VPN 설정 방법을 안내합니다. 솔넷 VPN은 사외 네트워크에서 사내 자원에 접속하기 위한 기존 VPN입니다. 로그인에는 다온을 사용합니다. 다온은 사내 계정과 SSO를 관리하는 시스템입니다.

## 지원 환경

다음 환경에서 사용합니다.

| 구분 | 내용 |
| --- | --- |
| 접속 방식 | OpenVPN 클라이언트 사용 |
| 접속 주소 | vpn.saesol.example |
| 사용 대상 | 전 직원 |
| 사용 위치 | 자택, 외부 업무 공간, 이동 중 네트워크 |
| 필요 정보 | 다온 계정, 다온 비밀번호, VPN 설정 파일 |

개인 PC와 회사 지급 장비 모두 사용할 수 있으나, 운영체제 보안 업데이트가 적용된 상태에서 접속하는 것을 권장합니다. 공용 PC에서는 사용하지 않습니다. 공용 네트워크를 사용할 때는 접속 후 업무가 끝나면 바로 연결을 종료합니다.

## 설치 및 접속

1. 사용하는 운영체제에 맞는 OpenVPN 클라이언트를 설치합니다.
2. 사내 메신저 공지나 IT 헬프데스크 안내에 따라 VPN 설정 파일을 내려받습니다.
3. OpenVPN 클라이언트를 실행합니다.
4. 프로필 가져오기 또는 설정 불러오기 메뉴에서 내려받은 설정 파일을 추가합니다.
5. 서버 주소가 `vpn.saesol.example`로 표시되는지 확인합니다.
6. 연결 버튼을 누릅니다.
7. 로그인 화면이 나오면 다온 계정 정보를 입력합니다.
8. 비밀번호 입력란에 `다온 비밀번호`를 입력하고 접속을 완료합니다.

설정 파일을 여러 번 가져와 중복 프로필이 생기면 오래된 항목을 삭제하고 하나만 남겨 두는 것이 좋습니다. 접속 중에는 OpenVPN 클라이언트를 종료하지 않습니다. 운영체제 시작 시 자동 실행을 켜 두면 외부 근무 시 재접속이 편합니다.

## 접속 확인

접속이 완료되면 다음 항목을 확인합니다.

1. OpenVPN 클라이언트 상태가 연결됨으로 표시됩니다.
2. 사내에서만 열리는 웹 페이지나 업무용 서버 주소가 정상적으로 열립니다.
3. 사내망 자원 접속 시 추가 로그인 없이 기존 권한 범위 내에서 접근됩니다.

연결은 되었지만 사내 자원이 열리지 않으면 브라우저를 완전히 종료한 뒤 다시 실행해 봅니다. 그래도 동일하면 VPN을 한 번 끊고 다시 연결합니다.

## 문제 해결

### 접속이 바로 실패하는 경우

- 인터넷 연결이 정상인지 먼저 확인합니다.
- 서버 주소가 `vpn.saesol.example`인지 확인합니다.
- 가져온 설정 파일이 손상되었을 수 있으므로 다시 내려받아 등록합니다.
- OpenVPN 클라이언트를 최신 버전으로 다시 설치합니다.

### 로그인 후 곧바로 끊기는 경우

세션이 만료되었거나 인증 정보가 맞지 않을 수 있습니다. 접속이 끊기면 `다온 비밀번호`를 다시 입력합니다. 저장된 비밀번호가 있더라도 다시 입력한 뒤 재접속합니다.

### 연결은 되었지만 사내망이 느린 경우

- 사용 중인 외부 네트워크 품질을 확인합니다.
- 대용량 업로드나 스트리밍을 중지합니다.
- 무선 네트워크 대신 유선 네트워크로 바꿔 봅니다.

### 계속 해결되지 않는 경우

아래 정보를 정리해 IT 헬프데스크로 문의합니다.

- 사용 중인 운영체제
- OpenVPN 클라이언트 버전
- 접속 시각
- 보이는 오류 문구
- 설정 파일 재등록 여부
- 다른 네트워크에서 동일한지 여부

문의 시 비밀번호는 보내지 않습니다. 화면 캡처를 전달할 때도 계정 정보와 비밀번호 입력 영역은 가린 뒤 공유합니다.
