# 업무용 노트북 분실 신고 절차

## 목적
이 문서는 업무용 노트북 분실을 인지한 직후의 신고 순서와 후속 조치를 정하기 위한 정책입니다. 분실 장비를 통한 계정 오남용, 개인정보 노출, 업무 중단을 최소화하는 것이 목적입니다. 특히 다온은 사내 계정·SSO 시스템이므로, 로그인 상태의 장비 분실은 일반 분실보다 우선순위를 높게 다룹니다.

## 적용 범위
이 절차는 전 직원이 회사에서 지급한 업무용 노트북을 분실한 경우에 적용합니다. 사내, 외부 미팅 장소, 자택, 이동 중 등 분실 위치와 관계없이 동일하게 적용합니다. 외부 협력사가 사용하는 장비는 이 문서의 직접 적용 대상은 아니지만, 회사 자산이나 회사 계정이 포함된 경우 정보보안팀과 IT 헬프데스크에 즉시 알려야 합니다.

## 규칙
업무용 노트북 분실을 인지하면 즉시 아래 순서로 조치합니다.

1. 본인은 분실 사실을 확인한 시점부터 "30분 안"에 정보보안팀과 IT 헬프데스크에 동시에 신고해야 합니다.
2. 신고는 사내 메신저, 전화, 이메일 중 가능한 수단으로 진행합니다. 한쪽에만 먼저 알리고 다른 쪽 신고를 미루면 안 됩니다.
3. 신고 내용에는 최소한 아래 항목을 포함합니다.
   - 소속 부서
   - 성명
   - 연락 가능한 전화번호
   - 분실 인지 시각
   - 마지막 사용 장소 또는 추정 위치
   - 다온 로그인 여부 추정
   - 장비에 저장되었을 가능성이 있는 업무 자료 종류
4. 다온 계정이 로그인된 상태에서 분실한 경우 IT 헬프데스크는 신고 접수 후 "10분" 안에 해당 세션을 강제 종료합니다.
5. 장비가 개인정보에 접근 가능한 용도로 사용되었는지 확인합니다. "PII 등급 1" 데이터에 접근 가능한 사용자 장비를 분실한 경우 정보보안팀은 24시간 안에 사고 예비 평가를 완료해야 합니다.
6. 팀장은 신고 사실을 인지하면 업무 연속성 확보를 위해 대체 장비 요청 여부를 확인하고, 필요한 경우 제품기획팀이나 고객지원팀 등 관련 협업 부서에 일정 영향만 공유합니다. 세부 사고 내용은 최소한으로 공유합니다.

대체 장비 지급 기준은 아래와 같습니다.

| 구분 | 처리 기준 |
|---|---|
| 재고 있음 | 다음 영업일 지급합니다 |
| 재고 없음 | 임시 공용 장비를 최대 "7일" 동안 대여합니다 |

신고 접수 창구 예시는 아래와 같습니다.

```text
정보보안팀: security@saesol.example
IT 헬프데스크: helpdesk@saesol.example
제목: [긴급] 업무용 노트북 분실 신고 / 홍길동 / 개발본부
```

## 예외
통신 불가, 해외 체류, 사고 직후 병원 이송 등으로 본인이 즉시 신고할 수 없는 경우에는 동행한 동료, 팀장, 또는 현장에서 연락 가능한 직원이 대리 신고할 수 있습니다. 이 경우에도 최초 인지 시각 기준으로 신고 의무는 유지합니다. 장비를 잠시 찾지 못한 상태라도 분실 가능성을 배제할 수 없으면 먼저 신고하고, 이후 회수되면 즉시 정정합니다. 회수된 장비는 임의로 다시 사용하지 말고 IT 헬프데스크 확인 후 사용합니다.

## 위반 시 조치
정당한 사유 없이 신고를 지연하거나, 분실 사실을 알고도 축소 보고하거나, 장비 회수 후 무단 사용한 경우 정보보안팀의 검토와 소속 조직장의 확인을 거쳐 보안 위반으로 처리할 수 있습니다. 필요 시 추가 보안 교육, 접근 권한 재검토, 장비 교체 지연, 인사팀 통보가 이뤄질 수 있습니다. 고객 정보나 회사 자산에 영향이 확인되면 관련 부서가 후속 조치를 별도로 진행합니다.
