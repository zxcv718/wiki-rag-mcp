# 솔패스 원격 접속 승인 기준

## 목적
이 문서는 솔패스 사용 대상, 승인권자, 운영 환경 세션 제한을 정리합니다. 솔패스는 솔넷 VPN을 대체하는 제로트러스트 원격 접속 서비스이며 전 직원의 사내 웹 시스템 접속 기본 수단입니다. 본 기준은 원격 접속 권한 부여와 유지 과정에서 필요한 최소 통제를 명확히 하여 운영 환경 접근을 일관되게 관리하는 데 목적이 있습니다.

## 적용 범위
본 문서는 전 직원에게 적용합니다. 외부 협력사는 본 문서의 기본 적용 대상이 아니며, 별도 계약이나 보안 검토가 있는 경우에만 제한적으로 검토합니다.

적용 대상은 다음과 같습니다.

| 구분 | 적용 내용 |
| --- | --- |
| 전 직원 | 사내 웹 시스템 접속 시 솔패스 사용을 기본으로 합니다. |
| 개발본부 | 업무상 필요한 범위에서 운영 환경 접근 권한 신청 대상이 될 수 있습니다. |
| 플랫폼·SRE팀 | 업무상 필요한 범위에서 운영 환경 접근 권한 신청 대상이 될 수 있습니다. |
| DB 관리자 | 운영 DB 관리가 필요한 경우 운영 환경 접근 권한 신청 대상이 될 수 있습니다. |
| 데이터팀 | 정산 데이터 파이프라인 운영에 필요한 범위에서 권한 신청 대상이 될 수 있습니다. |
| 외부 협력사 | 원칙적으로 제외하며, 필요 시 정보보안팀 검토 후 별도 승인합니다. |

## 승인 및 운영 기준
1. 전 직원은 원격으로 사내 웹 시스템에 접속할 때 솔패스를 사용합니다. 기존 "솔넷 VPN"은 대체 대상이며, 신규 기본 수단으로 사용하지 않습니다.
2. 운영 환경 접근이 포함되지 않은 일반 접속 권한은 소속 팀의 업무 필요를 확인한 뒤 부여합니다. 확인 주체는 해당 조직의 관리 책임자입니다.
3. 운영 환경 접근이 포함된 솔패스 권한은 소속 팀장과 정보보안팀의 이중 승인을 받아야 합니다.
4. 운영 환경 접근 권한 신청 시에는 신청 목적, 대상 업무, 필요 기간, 접근 범위를 함께 제출합니다. 범위가 불명확한 신청은 반려할 수 있습니다.
5. 운영 환경 세션은 최소 권한 원칙으로 부여합니다. 공용 계정 공유를 전제로 한 권한 부여는 허용하지 않습니다.
6. 솔패스의 운영 환경 세션은 마지막 활동 후 30분이 지나면 자동 종료됩니다. 자동 종료 후에는 다시 인증해야 합니다.
7. 개발본부와 플랫폼·SRE팀의 운영 접근 권한은 분기마다 접근 재인증 대상으로 검토됩니다. 접근 재인증은 현재 담당 업무와 권한 필요성이 계속 유효한지 확인하는 절차입니다.
8. DB 관리자와 데이터팀의 운영 접근 권한도 업무 변경, 조직 이동, 장기 미사용이 확인되면 재검토할 수 있습니다.

## 예외
다음 경우에 한해 예외를 검토할 수 있습니다.

1. 장애 대응이나 긴급 점검으로 즉시 운영 환경 접근이 필요한 경우
2. 인사 이동 직후 업무 인수인계로 단기간 추가 접근이 필요한 경우
3. 외부 협력사가 불가피하게 제한된 범위의 원격 접근이 필요한 경우

예외 승인 원칙은 다음과 같습니다.

- 운영 환경 접근이 포함되면 예외 상황에서도 소속 팀장과 정보보안팀의 승인 원칙을 유지합니다.
- 예외 권한은 필요한 범위와 기간으로 한정합니다.
- 예외 사유가 종료되면 즉시 회수합니다.
- 정보보안팀은 예외 승인 내역을 별도로 기록할 수 있습니다.

## 위반 시 조치
본 기준을 위반한 경우 회사는 다음 조치를 할 수 있습니다.

1. 승인 없이 운영 환경에 접근을 시도한 경우 해당 솔패스 권한을 즉시 중지합니다.
2. 타인 계정 사용, 공용 계정 우회 사용, 승인 범위를 벗어난 접근이 확인되면 정보보안팀이 사실관계를 확인합니다.
3. 위반 내용이 중대하거나 반복되는 경우 소속 조직장에게 통보하며, 추가 보안 교육 또는 권한 회수를 진행할 수 있습니다.
4. 외부 협력사의 위반은 내부 요청 부서와 함께 검토하며, 필요 시 접근을 종료합니다.

문의가 필요한 경우 정보보안팀 또는 IT 헬프데스크 스페이스 담당자에게 요청합니다. 정책 해석이 충돌할 때에는 정보보안팀 판단을 우선합니다.
