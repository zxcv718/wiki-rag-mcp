# 표준 소프트웨어 설치 요청 안내

## 지원 환경
업무용 노트북에서 사용하는 표준 소프트웨어 설치 절차를 안내합니다. 이 문서는 전 직원을 기준으로 작성합니다. 협력사 인력은 기본적으로 별도 기준을 따르며, 아래에 예외 사항을 함께 적습니다.

전 직원이 자주 쓰는 표준 소프트웨어 12종은 회사 포털에서 셀프서비스로 설치할 수 있습니다. 이 경우 별도 설치 요청 없이 본인이 직접 진행합니다. 셀프서비스 목록에 없는 프로그램, 유료 프로그램, 관리자 권한이 필요한 개발 도구는 IT 헬프데스크로 요청합니다.

외부 협력사 중 레드브릭소프트에서 파견 온 협력 개발자는 라이선스가 사용자 기준인 도구를 요청할 수 없고 장비 귀속 라이선스만 설치할 수 있습니다. 요청 전에 본인에게 필요한 도구가 장비 기준으로 배정 가능한지 먼저 확인합니다.

## 설치 요청이 필요한 경우
아래에 해당하면 IT 헬프데스크로 설치를 요청합니다.

| 구분 | 요청 필요 여부 | 비고 |
|---|---|---|
| 회사 포털의 셀프서비스 목록에 있는 표준 소프트웨어 | 불필요 | 본인이 직접 설치합니다 |
| 셀프서비스 목록에 없는 무료 소프트웨어 | 필요 | 업무 목적을 함께 적습니다 |
| 유료 소프트웨어 | 필요 | 구매 요청 완료 후 접수합니다 |
| 관리자 권한이 필요한 개발 도구 | 필요 | 팀장 승인 후 진행합니다 |
| 레드브릭소프트 협력 개발자 요청 | 필요 | 장비 귀속 라이선스만 가능합니다 |

유료 소프트웨어는 솔마켓 구매 요청 번호를 설치 티켓에 함께 적어야 작업이 시작됩니다. 번호가 없으면 접수는 가능하지만 설치 일정이 잡히지 않습니다.

## 설치 단계
1. 먼저 회사 포털에서 필요한 프로그램이 셀프서비스 대상인지 확인합니다.
2. 셀프서비스 대상이면 안내에 따라 직접 설치합니다.
3. 셀프서비스 대상이 아니면 IT 헬프데스크에 설치 요청을 등록합니다.
4. 요청 내용에는 소프트웨어 이름, 버전이 필요한 경우 해당 버전, 사용 목적, 설치가 필요한 장비를 적습니다.
5. 유료 소프트웨어는 솔마켓 구매 요청 번호를 함께 적습니다.
6. 개발 도구 중 관리자 권한이 필요한 설치는 팀장 승인 후 IT 헬프데스크 원격 지원으로 1회성 승격을 받아 진행합니다.
7. 설치가 끝나면 실행 여부와 로그인 여부를 확인하고, 이상이 있으면 같은 요청에 댓글로 증상을 남깁니다.

팀장 승인이 필요한 경우에는 승인 사실이 확인되어야 원격 지원 일정이 잡힙니다. 승인 방식은 팀에서 평소 사용하는 문서나 메시지 형태면 충분하지만, 요청 내용에서 확인 가능해야 합니다.

## 접속 확인
설치 후에는 아래 항목을 확인합니다.

- 프로그램이 정상 실행되는지 확인합니다.
- 업무 계정으로 로그인하는 프로그램이면 회사 계정으로 로그인되는지 확인합니다.
- 파일 열기, 저장, 인쇄, 네트워크 연결 등 기본 기능이 동작하는지 확인합니다.
- 개발 도구라면 필요한 런타임이나 확장 기능이 함께 필요한지 확인합니다.

문제가 없으면 추가 조치는 필요하지 않습니다. 설치 직후 재부팅이 필요한 경우에는 저장 중인 작업을 마친 뒤 재부팅합니다.

## 문제 해결
설치 중 또는 설치 후 문제가 있으면 IT 헬프데스크에 다시 남깁니다. 아래 내용을 함께 적으면 처리 시간이 줄어듭니다.

- 설치하려던 소프트웨어 이름
- 발생 시점과 증상
- 화면에 표시된 문구
- 재부팅 후에도 같은 문제가 나는지 여부
- 관리자 권한 요청이 있었는지 여부

개발 도구 설치 중 권한 부족으로 중단되면 임의로 우회 설치를 시도하지 않습니다. 팀장 승인 후 원격 지원으로 1회성 승격 절차를 다시 진행합니다. 레드브릭소프트 협력 개발자의 경우 사용자 기준 라이선스 도구는 설치할 수 없으므로, 같은 종류의 장비 귀속 도구가 있는지 확인 후 대체 요청을 합니다.

문의가 필요한 경우 IT 헬프데스크로 요청을 남기거나 helpdesk@saesol.example로 문의합니다.
