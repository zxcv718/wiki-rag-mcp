# 원격 접속 가이드 (솔패스)

사외에서 사내 시스템에 접속할 때는 "솔패스 앱"을 사용합니다. 솔패스는 제로트러스트 원격 접속 서비스로, 기존 솔넷 VPN을 대체합니다. 솔넷 VPN은 2026년 6월 30일에 종료했으므로 더 이상 설치하거나 사용할 수 없습니다.

이 문서는 전 직원이 사외에서 원격 접속을 시작할 때 필요한 설치와 확인 절차를 안내합니다.

## 지원 환경

다음 환경에서 설치와 사용을 권장합니다.

| 구분 | 지원 내용 |
| --- | --- |
| 사용자 | 전 직원 |
| 기기 | 회사 지급 기기, 개인 기기 |
| 네트워크 | 가정, 이동통신, 공용 인터넷 환경 |
| 인증 | 다온 계정 로그인 |
| 등록 가능 기기 수 | 1인당 2대까지 |

다온은 사내 계정·SSO 시스템입니다. 원격 접속을 시작하기 전에 다온 계정으로 정상 로그인할 수 있어야 합니다.

기기 등록은 1인당 2대까지 가능합니다. 이미 등록된 기기가 2대인 상태에서는 새 기기를 추가할 수 없으므로, 기존 기기 변경이 필요하면 헬프데스크에 먼저 요청합니다.

## 설치 단계

1. 사외 네트워크에 연결된 상태에서 사내 메신저 공지 또는 헬프데스크 안내에 따라 "솔패스 앱" 설치 파일을 받습니다.
2. 설치 파일을 실행하고 화면 안내에 따라 설치를 완료합니다.
3. 설치가 끝나면 "솔패스 앱"을 실행합니다.
4. 로그인 화면에서 회사 메일 주소 형식의 계정을 입력하고 다온 로그인 화면으로 이동합니다.
5. 다온에서 계정과 <비밀번호>를 입력해 로그인합니다.
6. 추가 인증 화면이 나오면 안내에 따라 인증을 완료합니다.
7. 기기 등록 화면이 표시되면 현재 사용 중인 기기를 등록합니다.
8. 접속 대상 목록이 보이면 필요한 사내 시스템을 선택해 접속합니다.

설치 중 운영체제의 권한 허용 창이 나타나면 네트워크 사용 또는 보안 확장 권한을 허용해야 정상 동작할 수 있습니다. 권한을 거부한 경우 앱을 종료한 뒤 다시 실행하고, 계속 실패하면 헬프데스크에 문의합니다.

## 접속 확인

설치와 로그인이 끝나면 아래 항목으로 정상 여부를 확인합니다.

- "솔패스 앱"이 로그인 상태로 표시됩니다.
- 접속 대상 목록이 정상적으로 보입니다.
- 사내 시스템 첫 화면이 열립니다.
- 사내 시스템 사용 중 연결이 바로 끊기지 않습니다.

최초 접속 후에는 자주 사용하는 기기에서 한 번 더 로그아웃 후 재로그인해 두는 것을 권장합니다. 이렇게 하면 다온 인증과 기기 등록이 정상 저장되었는지 확인할 수 있습니다.

## 문제 해결

다음은 자주 발생하는 상황과 처리 방법입니다.

| 증상 | 확인 사항 | 조치 |
| --- | --- | --- |
| 로그인 화면이 열리지 않음 | 인터넷 연결 여부 | 브라우저를 다시 열고 재시도합니다. |
| 다온 로그인 실패 | 계정 정보 입력 오류 여부 | <비밀번호>를 다시 확인하고 재시도합니다. |
| 기기 등록 불가 | 기존 등록 기기 수 | 이미 2대까지 등록된 경우 헬프데스크에 해제 요청합니다. |
| 접속 후 화면이 열리지 않음 | 앱 로그인 상태 유지 여부 | 앱을 완전히 종료한 뒤 다시 로그인합니다. |
| 기존 VPN 사용 문의 | 설치 방식 혼동 | 솔넷 VPN은 2026년 6월 30일에 종료했으므로 사용하지 않습니다. |

문제가 계속되면 아래 정보를 함께 전달하면 확인이 빠릅니다.

- 사용 중인 운영체제
- 회사 지급 기기인지 개인 기기인지 여부
- 문제가 발생한 시각
- 로그인 단계에서 실패했는지, 접속 후 실패했는지
- 화면에 표시된 안내 문구
- 연락 가능한 회사 메일 주소

문의는 헬프데스크 메일 helpdesk@saesol.example로 접수합니다. 긴급한 업무 영향이 있으면 메일 접수 후 사내 메신저로 추가 알림을 남깁니다.
