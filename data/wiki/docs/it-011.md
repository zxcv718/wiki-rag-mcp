# 다온 계정 잠금 해제 안내

## 개요
다온은 사내 계정·SSO 시스템입니다. 이 문서는 다온 로그인 실패, 의심 로그인 차단, 휴면 전환으로 계정이 잠긴 경우에 확인할 내용과 해제 요청 방법을 안내합니다.

계정이 잠긴 경우에는 본인이 직접 해제를 시도하지 말고, 아래 절차에 따라 신청합니다. 전 직원은 IT 헬프데스크 스페이스의 계정 요청 양식으로 잠금 해제를 신청해야 하며 처리 목표 시간은 영업시간 기준 2시간입니다.

## 먼저 확인할 내용
잠금 사유는 받은 "잠금 알림 메일"에서 먼저 확인합니다. 메일에는 아래 두 사유 중 하나가 표시됩니다.

| 표시되는 사유 | 의미 | 확인할 내용 |
| --- | --- | --- |
| 비밀번호 오입력 | 로그인 시 입력한 정보가 일치하지 않아 잠금된 경우입니다. | 입력한 계정, 저장된 자동완성 값, 키보드 입력 상태를 확인합니다. |
| 의심 로그인 차단 | 평소와 다른 접속으로 판단되어 차단된 경우입니다. | 본인이 시도한 로그인인지 확인하고, 본인 시도가 아니라면 즉시 해제 요청 시 함께 알립니다. |

추가로, "잠금 알림 메일"이 없더라도 최근 다온 사용 이력이 없었다면 휴면 상태일 수 있습니다. 90일 동안 다온 로그인 기록이 없으면 휴면 상태로 전환되어 본인 확인 후에만 복구할 수 있습니다.

## 증상별 조치

### 로그인 화면에서 잠금 안내가 보이는 경우
원인은 비밀번호 오입력 또는 의심 로그인 차단일 수 있습니다.

조치:
1. 받은 "잠금 알림 메일"의 사유를 확인합니다.
2. 마지막으로 정상 로그인한 시점과 현재 시도가 본인 행동인지 정리합니다.
3. IT 헬프데스크 스페이스의 계정 요청 양식으로 잠금 해제를 신청합니다.
4. 의심 로그인 차단인데 본인 시도가 아니라면, 신청 내용에 해당 사실을 반드시 적습니다.

### 비밀번호를 맞게 입력해도 로그인되지 않는 경우
원인은 잠금 상태가 이미 적용되었거나, 장기간 미사용으로 휴면 전환되었을 수 있습니다.

조치:
1. 최근 90일 내 다온 로그인 기록이 있었는지 확인합니다.
2. 휴면으로 보이면 본인 확인이 가능한 연락처를 함께 적어 계정 요청 양식으로 신청합니다.
3. 여러 번 다시 시도하지 말고 접수를 기다립니다.

### 잠금 알림 메일을 받지 못한 경우
원인은 메일 확인 지연, 메일함 분류, 또는 휴면 전환일 수 있습니다.

조치:
1. 사내 메일함의 받은편지함과 스팸함을 확인합니다.
2. 메일이 없더라도 증상과 최근 사용 여부를 적어 계정 요청 양식으로 신청합니다.
3. 고객 문의 대응 중인 급한 업무가 있으면 소속 팀장에게 먼저 공유합니다.

## 신청 방법
계정 요청 양식에는 아래 내용을 적습니다.

1. 이름
2. 소속
3. 연락 가능한 사내 메일 주소
4. 증상 발생 시각
5. "잠금 알림 메일"의 사유 또는 메일 미수신 여부
6. 최근 본인 로그인 시도 여부
7. 휴면 의심 여부

외부 협력사는 레드브릭소프트 현장 관리자 확인이 포함되어야 하며 확인 누락 건은 반려됩니다. 확인 문구는 자유 형식이지만, 현장 관리자가 신청 내용을 확인했다는 뜻이 분명해야 합니다.

## 처리와 유의사항
접수 후 해제 가능 여부를 확인해 순차 처리합니다. 처리 목표 시간은 영업시간 기준 2시간입니다. 다만 본인 확인이 필요한 휴면 복구나, 의심 로그인 차단으로 추가 확인이 필요한 경우에는 더 걸릴 수 있습니다.

유의사항은 다음과 같습니다.

- 같은 증상으로 중복 신청하지 않습니다.
- 다른 사람 계정으로 대신 신청하지 않습니다.
- 화면 캡처를 첨부할 때 비밀번호 입력값은 포함하지 않습니다.
- 본인 시도가 아닌 로그인 흔적이 의심되면 신청 내용에 반드시 적습니다.

처리 결과는 신청에 남긴 연락처 기준으로 안내합니다.
