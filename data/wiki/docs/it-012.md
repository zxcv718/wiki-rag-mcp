# 업무용 노트북 지급 기준

## 목적
이 문서는 전 직원에게 지급하는 업무용 노트북의 기본 기종, 직군별 사양, 교체 원칙을 정리하기 위한 정책입니다. 지급 기준을 통일해 입사, 교체, 예외 승인 과정에서 해석 차이를 줄이는 것을 목적으로 합니다. 본 문서는 업무 수행에 필요한 회사 자산의 지급 기준만 다루며, 개인 장비 사용 허용 여부나 사외 반출 절차 등 다른 주제는 포함하지 않습니다.

## 적용 범위
이 문서는 전 직원에게 적용합니다. 정규직과 계약직은 모두 포함합니다. 외부 협력사는 이 문서의 기본 지급 대상이 아니며, 협력 계약이나 별도 합의에 따라 처리합니다.

조직별 운영 역할은 다음과 같습니다.

| 구분 | 역할 |
|---|---|
| 인사팀 | 신규 입사자 정보 확정 및 지급 요청 전달 |
| 플랫폼·SRE팀 | 장비 조달, 초기 설정, 자산 관리 |
| 각 소속 조직 관리자 | 직무상 필요 사양 확인 및 예외 요청 승인 |
| 정보보안팀 | 보안 설정 기준 확인 |
| 전 직원 | 지급 장비의 업무 목적 사용 및 관리 |

## 지급 기준
신규 입사자에게는 기본적으로 "맥북 프로 14"를 지급합니다. 기본 지급은 입사일 전후의 재고와 조달 상황을 고려해 준비하며, 동일 급의 후속 모델이 공급되는 경우에는 운영상 대체 지급할 수 있습니다. 다만 기본 기준은 맥북 프로 14로 유지합니다.

직군별 기본 사양은 다음과 같습니다.

| 대상 | 기본 사양 |
|---|---|
| 개발 직군 | 메모리 "32GB" 모델 |
| 그 외 직군 | 업무 성격에 맞는 표준 사양 모델 |

개발 직군에는 개발본부 소속 구성원뿐 아니라 실제 담당 업무가 개발인 경우를 포함합니다. 예를 들어 개발본부의 페이코어 소속 개발자와 플랫폼·SRE팀의 인프라 개발 업무 담당자는 개발 직군 기준을 적용합니다. 반대로 데이터팀, 제품기획팀, 고객지원팀 등은 소속만으로 개발 직군으로 보지 않으며 실제 담당 업무 기준으로 판단합니다.

노트북은 입사 시 1인 1대 지급을 원칙으로 하며, 공용 장비나 테스트 장비는 이 문서의 지급 기준 대상에서 제외합니다. 운영체제와 보안 설정은 회사 표준에 맞춰 초기 구성합니다.

## 교체 및 예외
업무용 노트북의 "교체 주기는 4년"입니다. 교체 시점은 최초 지급일을 기준으로 판단합니다. 교체 주기 도래 전이라도 다음 사유가 있으면 예외 검토가 가능합니다.

1. 제조상 결함 또는 반복 고장으로 정상 업무가 어려운 경우
2. 직무 변경으로 기본 사양으로 업무 수행이 곤란한 경우
3. 수리 비용과 예상 사용 기간을 고려할 때 교체가 더 적절한 경우
4. 보안 또는 운영 기준 변경으로 계속 사용이 어렵다고 판단되는 경우

예외 교체나 상향 사양 요청은 소속 조직 관리자가 사유를 확인한 뒤 플랫폼·SRE팀에 요청합니다. 필요 시 정보보안팀 또는 관련 관리 부서가 검토에 참여할 수 있습니다. DB 관리자처럼 운영 환경 접근이 많은 역할도 예외가 자동 승인되지는 않으며, 실제 업무 필요와 장비 상태를 기준으로 판단합니다.

분실, 파손, 침수 등 사용자 과실이 의심되는 경우에는 일반 교체와 분리해 검토합니다. 이 경우 사실 확인 후 재지급 여부와 비용 부담 원칙을 별도로 안내합니다.

## 위반 시 조치
지급 기준을 우회하기 위해 사실과 다른 직무 정보를 제출하거나, 승인 없이 장비를 임의 교체 또는 전용하는 행위는 정책 위반으로 봅니다. 위반이 확인되면 장비 회수, 재신청 제한, 관리자 통보가 이루어질 수 있습니다. 고의 훼손이나 중대한 관리 소홀은 회사 자산 관리 기준에 따라 추가 조치할 수 있습니다.

문의가 필요한 경우 인사팀 또는 플랫폼·SRE팀에 문의합니다. 정책 해석이 필요한 사안은 소속 조직 관리자와 먼저 협의한 뒤 전달합니다.
