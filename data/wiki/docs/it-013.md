# 프린터·회의실 PC 드라이버 설치

## 문서 개요
이 문서는 사내 프린터와 회의실 PC 연결에 필요한 드라이버 설치 절차를 안내합니다. 설치 파일은 사내 네트워크에 연결된 상태에서 내려받아야 하며, 설치 권한이 없는 경우에는 IT 헬프데스크로 요청합니다.

회의실 PC는 공용 장비이므로 개인 설정을 남기지 않도록 사용 후 로그아웃합니다. 또한 회의실 PC에 개인 계정으로 로그인하는 것은 금지되며 발표 자료는 게스트 전송 폴더를 통해서만 옮깁니다.

## 지원 환경
사내 배포 패키지는 아래와 같습니다.

| 구분 | 운영체제 | 비고 |
|---|---|---|
| 프린터 드라이버 | Windows용 2종 | 일반 출력용, 스캔 포함 복합기용 |
| 프린터 드라이버 | macOS용 1종 | 통합 패키지 |
| 회의실 PC 연결 드라이버 | Windows, macOS | 발표용 디스플레이 연결에 필요할 수 있음 |

설치 전 확인 사항은 아래와 같습니다.

- 사내 네트워크에 연결되어 있어야 합니다.
- 운영체제 업데이트가 진행 중이면 완료 후 설치합니다.
- 기존에 같은 장치의 오래된 드라이버가 있으면 제거 후 재설치하는 것이 좋습니다.
- 회의실 PC 재설치가 필요한 경우 딥워크 데이에는 회의실 PC 재설치 작업을 오전 11시 이전에만 예약할 수 있습니다. 딥워크 데이는 매주 수요일이며 정기 회의를 잡지 않는 날입니다.

## 설치 단계
1. 사내 네트워크에 연결합니다.
2. IT 헬프데스크 안내에 따라 운영체제에 맞는 드라이버 패키지를 내려받습니다.
3. 내려받은 설치 파일을 실행합니다.
4. 설치 중 장치 종류를 선택하는 화면이 나오면 사용 목적에 맞는 프린터 또는 회의실 디스플레이 연결 항목을 선택합니다.
5. 설치가 끝나면 운영체제를 한 번 로그아웃하거나 재시작합니다.
6. 재로그인 후 장치 목록에서 프린터 또는 연결 장치를 확인합니다.

Windows에서 프린터를 설치할 때는 다음 순서로 진행합니다.

1. 설정을 엽니다.
2. 프린터 추가 메뉴에서 장치 검색을 실행합니다.
3. 목록에서 해당 프린터를 선택하고 설치를 완료합니다.

macOS에서 프린터를 설치할 때는 다음 순서로 진행합니다.

1. 시스템 설정을 엽니다.
2. 프린터 추가 화면으로 이동합니다.
3. 목록에서 해당 프린터를 선택한 뒤 드라이버가 자동 지정되었는지 확인하고 추가합니다.

## 접속 확인
설치 후에는 아래 항목을 확인합니다.

- 테스트 문서가 정상 출력되는지 확인합니다.
- 흑백과 컬러 선택이 필요한 장치에서는 기본값이 올바른지 확인합니다.
- 회의실에서 외부 디스플레이가 정상 인식되는지 확인합니다.
- 회의실 PC 사용 시 발표 자료가 게스트 전송 폴더에만 저장되어 있는지 확인합니다.

회의실 PC에서는 브라우저 자동 로그인, 개인 파일 저장, 개인 계정 연동을 하지 않습니다. 사용이 끝나면 게스트 전송 폴더의 자료를 삭제하고 로그아웃합니다.

## 문제 해결
프린터가 목록에 보이지 않으면 사내 네트워크에 연결한 뒤 3분 후 장치 검색을 다시 실행합니다. 그래도 보이지 않으면 기존 드라이버를 제거한 뒤 다시 설치합니다.

설치 파일이 실행되지 않으면 아래를 확인합니다.

- 내려받은 파일이 운영체제와 맞는지 확인합니다.
- 보안 경고가 표시되면 게시자가 사내 배포 파일인지 확인합니다.
- 관리자 권한이 필요한 경우 IT 헬프데스크로 요청합니다.

회의실 PC 연결이 되지 않으면 아래 순서로 확인합니다.

1. 케이블이 올바르게 연결되어 있는지 확인합니다.
2. 회의실 디스플레이 입력 소스가 맞는지 확인합니다.
3. 연결 드라이버를 다시 설치합니다.
4. 동일 증상이 계속되면 회의실 이름, 사용한 운영체제, 발생 시각을 적어 IT 헬프데스크로 전달합니다.

설치 지원이나 재설치 예약이 필요하면 IT 헬프데스크로 문의합니다. 예약 요청 메일은 helpdesk@saesol.example로 보내며, 제목에 장비 종류와 위치를 함께 적습니다.
