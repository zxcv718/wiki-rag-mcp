# 업무용 메신저 알림 장애 대응

업무용 메신저 알림이 오지 않거나 늦게 오는 경우에 따라 확인 순서와 지원 요청 기준을 정리합니다. 개인 설정 문제인지, 일시적인 지연인지 먼저 구분한 뒤 필요한 경우 IT 헬프데스크로 접수합니다.

## 먼저 확인할 사항

알림 장애는 계정 세션 만료나 브라우저 알림 권한 설정 때문에 발생하는 경우가 많습니다. 아래 순서대로 확인합니다.

1. 사내 메신저 화면이 정상적으로 열리는지 확인합니다.
2. 다온 세션 만료 여부를 확인합니다.
3. 브라우저 또는 운영체제의 알림 차단 여부를 확인합니다.
4. 모바일과 데스크톱에서 같은 증상이 재현되는지 확인합니다.
5. 솔데이 진행 시간인지 확인합니다.

다온은 사내 계정·SSO 시스템입니다. 알림이 오지 않으면 다온 세션 만료 여부를 먼저 확인하고 만료된 경우 다시 로그인하면 대부분 즉시 복구됩니다.

## 증상별 점검 방법

### 알림이 갑자기 모두 오지 않는 경우

가장 먼저 다온 세션 상태를 확인합니다. 화면은 열리지만 새 메시지 알림만 오지 않는 경우에도 세션이 만료된 상태일 수 있습니다.

조치 방법은 다음과 같습니다.

1. 사내 메신저 탭을 새로고침합니다.
2. 로그인 화면 또는 세션 만료 안내가 보이면 다시 로그인합니다.
3. 재로그인 후 본인에게 시험 메시지를 보내 알림 수신 여부를 확인합니다.

대부분은 이 단계에서 복구됩니다.

### 데스크톱에서만 알림이 오지 않는 경우

브라우저의 사이트 알림 권한을 확인합니다. 데스크톱 알림 권한이 꺼져 있으면 브라우저별 사이트 권한에서 saesol.example 도메인을 허용으로 바꿔야 합니다.

| 확인 항목 | 조치 |
|---|---|
| 브라우저 알림 차단 | 사이트 권한에서 알림을 허용으로 변경합니다. |
| 운영체제 집중 모드 | 집중 모드 또는 방해 금지 상태를 해제합니다. |
| 브라우저 탭 음소거·백그라운드 제한 | 브라우저를 완전히 종료한 뒤 다시 실행합니다. |

권한 변경 후에도 바로 반영되지 않으면 브라우저를 재시작합니다.

### 모바일에서만 알림이 오지 않는 경우

앱 알림이 운영체제에서 차단된 경우가 많습니다. 앱 자체 설정과 기기 알림 설정을 모두 확인합니다.

1. 기기 설정에서 해당 앱의 알림이 허용인지 확인합니다.
2. 배터리 절약이나 백그라운드 제한이 켜져 있으면 해제합니다.
3. 모바일 네트워크 또는 와이파이를 전환해 다시 확인합니다.

모바일만 문제인 경우에는 기기 설정 영향일 가능성이 높습니다.

### 알림이 늦게 오는 경우

솔데이 진행 시간에는 전사 공지 채널 알림이 우선 전달되므로 일반 채널 알림이 최대 5분 지연될 수 있습니다. 이 시간대에는 일시적인 지연만 있고 이후 정상화되면 별도 조치가 필요하지 않습니다.

## 지원 요청 기준

아래 조건에 해당하면 IT 헬프데스크 티켓을 생성합니다.

- 모바일과 데스크톱에서 모두 알림이 끊긴 상태가 20분 넘게 지속되는 경우
- 재로그인과 알림 권한 확인 후에도 동일한 증상이 반복되는 경우
- 같은 팀에서 여러 사람이 동시에 같은 증상을 보고하는 경우

티켓에는 다음 내용을 함께 적습니다.

- 증상 시작 시각
- 발생 기기 종류와 브라우저 이름
- 모바일과 데스크톱 동시 발생 여부
- 다온 재로그인 여부
- saesol.example 알림 권한 확인 결과
- 솔데이 진행 시간과 겹쳤는지 여부

## IT 헬프데스크에 전달할 예시

아래 형식으로 정리하면 확인이 빠릅니다.

```text
제목: 사내 메신저 알림 미수신
증상 시작: 2026-07-26 14:10
영향 범위: 데스크톱, 모바일 모두
확인 내용:
- 다온 재로그인 완료
- 브라우저에서 saesol.example 알림 허용 확인
- 모바일 앱 알림 허용 확인
- 20분 이상 동일 증상 지속
비고:
- 같은 팀 2명도 유사 증상 보고
```

증상이 해소되면 티켓에 복구 시각과 마지막으로 수행한 조치를 덧붙입니다.
