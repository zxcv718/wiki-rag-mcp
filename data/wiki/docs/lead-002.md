# 2027 예산 편성 초안

## 목적
이 문서는 2027년 연간 예산 편성의 기본 방향, 제출 일정, 검토 원칙을 정리한 운영 기준입니다. 각 조직은 본 문서를 기준으로 예산 요청안을 작성하고, 경영진·팀장은 조직 내 우선순위를 정리해 제출합니다.

이번 편성은 기존 운영의 안정성 유지와 사업 목표 달성에 직접 연결되는 항목을 우선합니다. 특히 인력 운영, 제품 유지보수, 서비스 안정성, 법적·보안상 필수 비용을 먼저 반영합니다. 신규 투자성 예산은 필요성만으로는 편성하지 않으며, 분기 목표와 핵심 결과 지표인 OKR과의 연결이 명확해야 합니다.

## 편성 기준
2027년 총예산에서 인건비 비중은 62%로 잡습니다. 인건비에는 기존 인력 유지에 필요한 급여성 비용과 확정된 채용 계획에 따른 비용을 포함합니다. 외부 협력사 비용은 인건비와 구분해 별도 항목으로 작성합니다.

예산 요청은 아래 기준에 따라 작성합니다.

1. 기존 운영 유지 비용과 신규 요청 비용을 구분합니다.
2. 신규 요청은 목적, 기대 효과, 미집행 시 영향, 집행 시점을 함께 적습니다.
3. OKR과 연결되지 않은 신규 예산은 받지 않습니다.
4. 법적 의무, 정보보안, 장애 예방, 고객 영향 최소화와 직접 연결되는 항목은 우선 검토합니다.
5. 단순 증액 요청은 인정하지 않으며, 전년 집행 근거와 2027년 필요 사유를 함께 제시합니다.

조직별로 특히 확인할 사항은 다음과 같습니다.

| 조직 | 중점 확인 사항 |
| --- | --- |
| 개발본부 | 제품 개발, 유지보수, 필수 기술 부채 해소의 우선순위를 구분합니다. |
| 플랫폼·SRE팀 | 공용 인프라 운영, 용량 증설 필요성, 안정성 개선 근거를 함께 제시합니다. |
| 데이터팀 | 정산 데이터 처리와 분석 업무에 필요한 운영성 비용을 구분합니다. |
| 정보보안팀 | 필수 통제 항목과 권고 항목을 나누어 제출합니다. |
| 제품기획팀 | 릴리스 계획과 직접 연결되는 비용만 요청합니다. |
| 고객지원팀 | 문의 증가 대응에 필요한 운영 비용 중심으로 작성합니다. |
| 인사팀, 재무팀 | 전사 공통 비용은 중복 편성되지 않도록 사전 조정합니다. |

## 제출 일정
팀별 예산 요청은 10월 17일까지 받습니다. 제출 기한 이후 접수분은 원칙적으로 본예산 검토 대상에서 제외하며, 불가피한 사유가 있는 경우에만 별도 판단합니다.

일정은 아래와 같이 운영합니다.

1. 9월 말까지 각 조직은 내부 초안을 정리합니다.
2. 10월 1주차부터 팀장 검토를 진행합니다.
3. 10월 17일까지 조직별 요청안을 제출합니다.
4. 제출 이후 경영진·팀장 합동 검토에서 중복, 우선순위, 집행 가능성을 조정합니다.
5. 최종 확정 전까지 재무팀이 형식과 합계 오류를 확인합니다.

제출 문서는 표 형식으로 정리하며, 항목별 산출 근거를 빠짐없이 적습니다. 설명이 필요한 항목은 별도 메모를 덧붙이되, 본문만으로도 의사결정이 가능하도록 작성합니다.

## 담당 및 검토 방식
예산 편성의 총괄 책임은 재무팀이 맡습니다. 조직별 초안 작성 책임은 각 팀장이 집니다. 여러 조직에 걸친 비용은 요청 조직이 먼저 취합하되, 관련 조직과 사전 합의를 거쳐 제출합니다.

검토 역할은 아래와 같이 구분합니다.

- 경영진·팀장: 우선순위 조정과 승인 여부 판단을 합니다.
- 재무팀: 편성 기준 적용, 중복 확인, 총액 정합성 검토를 합니다.
- 제품기획팀: 제품 계획과의 연결성을 확인합니다.
- 정보보안팀: 보안상 필수 항목 여부를 검토합니다.
- 플랫폼·SRE팀 및 DB 관리자: 인프라와 운영 DB 관련 요청의 타당성을 확인합니다.
- 인사팀: 채용 계획이 포함된 인건비 요청의 전제 조건을 확인합니다.

문의는 재무팀 공용 메일 budget@saesol.example로 받습니다. 검토 중 보완 요청이 있을 수 있으며, 요청 조직은 근거 자료를 추가 제출해야 합니다.
