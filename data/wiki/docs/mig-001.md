# 서버실 출입 기록부 양식

## 대상

이 문서는 서버실에 출입하는 전 직원을 대상으로 합니다. 외부 협력사가 서버실에 출입해야 하는 경우에도 동일한 방식으로 기록합니다. 단, 실제 출입 승인 여부와 동행 필요 여부는 별도 운영 기준을 따릅니다.

구 위키에서 사용하던 양식을 옮겨 둔 안내 문서이며, 서버실 출입 시 기본적으로 남겨야 하는 기록 항목과 작성 방법을 정리합니다.

## 내용

서버실에 들어갈 때는 "출입 기록부"에 이름과 시각을 적습니다. 출입 기록은 출입 이력 확인, 시설 점검 이력 추적, 사고 발생 시 확인 자료로 사용합니다.

기록부에는 아래 항목을 적습니다.

| 항목 | 작성 내용 |
|---|---|
| 날짜 | 출입한 날짜 |
| 이름 | 출입자 본인 이름 |
| 소속 | 본인 소속 |
| 입실 시각 | 서버실에 들어간 시각 |
| 퇴실 시각 | 서버실에서 나온 시각 |
| 출입 목적 | 작업 또는 확인 사유 |
| 비고 | 동행자, 특이사항 등이 있으면 기재 |

기록은 본인이 직접 작성합니다. 여러 명이 함께 들어가는 경우에도 각자 한 줄씩 작성합니다. 대신 적거나 나중에 몰아서 적지 않습니다.

## 작성 방법

1. 서버실에 들어가기 전에 기록부의 빈 줄을 확인합니다.
2. 날짜, 이름, 소속, 입실 시각, 출입 목적을 먼저 적습니다.
3. 서버실에서 작업을 마친 뒤 퇴실 시각을 추가로 적습니다.
4. 동행자가 있거나 장비 반입, 반출 등 별도 확인이 필요한 내용이 있으면 비고에 적습니다.
5. 잘못 적은 경우에는 기존 내용을 알아볼 수 있게 한 줄로 긋고 옆에 다시 적습니다.

아래 형식으로 작성합니다.

| 날짜 | 이름 | 소속 | 입실 시각 | 퇴실 시각 | 출입 목적 | 비고 |
|---|---|---|---|---|---|---|
| 2023-05-02 | 김하늘 | 플랫폼·SRE팀 | 14:05 | 14:40 | 장비 상태 확인 |  |
| 2023-05-02 | 이서준 | 외부 협력사 | 15:10 | 16:00 | 케이블 점검 | 담당자 동행 |

시각은 알아보기 쉬운 형태로 일관되게 적습니다. 퇴실 시각을 바로 적지 못한 경우에는 서버실에서 나온 직후 같은 줄에 이어서 적습니다. 빈칸으로 오래 두지 않습니다.

## 유의사항

출입 기록은 형식적으로 작성하지 않습니다. 실제 출입한 사람, 실제 시각, 실제 목적을 기준으로 적습니다. 이름만 적고 시각을 비워 두면 기록으로 활용하기 어렵기 때문에 누락 없이 작성합니다.

기록부가 없거나 기존 기록부를 모두 사용한 경우에는 임시 용지에 같은 항목으로 먼저 작성하고, 관리 담당자에게 기록부 보충을 요청합니다. 임시로 작성한 기록은 이후 기록부에 정리해 옮깁니다.

기록부가 훼손되었거나 이전 기록을 확인하기 어려운 상태이면 별도 보관이 필요할 수 있으므로 임의로 폐기하지 않습니다.

## 문의처

기록부 비치 상태, 양식 추가, 보관 상태 확인이 필요하면 플랫폼·SRE팀에 문의합니다. 출입 승인이나 보안 관련 판단이 필요한 경우에는 해당 관리 담당자에게 확인합니다.

문의 예시는 아래와 같습니다.

- 기록부가 모두 사용되어 새 양식이 필요한 경우
- 퇴실 시각을 누락한 뒤 정정이 필요한 경우
- 외부 협력사 출입 기록 작성 위치를 확인해야 하는 경우
- 기록부가 분실되었거나 훼손된 경우

일반 문의는 사내 메일로 전달하며, 필요한 경우 관리 담당자가 후속 안내를 진행합니다.
