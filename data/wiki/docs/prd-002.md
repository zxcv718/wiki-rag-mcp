# 솔북 무료 체험 안내

## 배경
이 문서는 솔북의 현재 무료 체험 조건을 정리합니다. 대상 독자는 제품기획팀, 개발본부, 고객지원팀입니다. 솔북은 매장 예약 관리 앱이며, 솔페이와 결제가 연동됩니다.

무료 체험은 신규 가입자가 유료 전환 전에 기능을 사용해 볼 수 있도록 제공하는 기본 정책입니다. 가입 전환과 요금제를 맡는 그로스 스쿼드는 이 정책을 기준으로 화면 문구와 전환 흐름을 관리합니다. 고객지원팀은 가맹점 문의 응대 시 본 문서의 조건을 기준으로 안내합니다.

본 문서는 2026-09-18 기준으로 작성합니다. 이후 변경 가능성은 별도 변경 이력으로 관리합니다.

## 사용자 시나리오
1. 신규 사용자가 솔북에 가입합니다.
2. 가입 시점부터 무료 체험이 시작됩니다.
3. 사용자는 체험 기간 동안 예약 등록, 예약 확인, 예약 관리 기능을 일반 사용과 동일한 흐름으로 사용합니다.
4. 체험 중 예약 건수에는 제한은 없다.
5. 체험 종료가 가까워지면 사용자에게 사전 안내를 제공합니다.
6. 사용자가 유료 전환을 진행하지 않으면 체험 종료 후에는 유료 이용이 필요한 상태로 전환됩니다.

고객 문의가 들어오면 다음과 같이 설명합니다.

| 항목 | 안내 기준 |
|---|---|
| 체험 기간 | 무료 체험 기간은 30일입니다 |
| 예약 건수 | 체험 중 예약 건수 제한은 없다 |
| 종료 안내 | 체험 종료 7일 전에 알림을 보냅니다 |

## 기능 요구사항
무료 체험 운영 시 다음 요구사항을 적용합니다.

### 1. 체험 시작과 기간
- 무료 체험은 가입 완료 시점에 시작합니다.
- 무료 체험 기간은 30일입니다.
- 동일 계정의 현재 체험 상태와 종료 예정일은 사용자에게 확인 가능해야 합니다.

### 2. 체험 중 사용 범위
- 체험 사용자는 예약 기능을 사용할 수 있어야 합니다.
- 체험 중 예약 건수 제한은 없다.
- 예약 건수와 무관하게 체험 기간 자체는 연장되지 않습니다.

### 3. 종료 예정 알림
- 체험 종료 7일 전에 알림을 보냅니다.
- 알림에는 체험 종료 예정 사실과 유료 전환 필요 여부를 포함합니다.
- 알림 문구는 과장 없이 현재 상태를 명확히 전달해야 합니다.

### 4. 안내 문구 일관성
- 가입 화면, 요금 안내 화면, 고객 응대 문구에서 기간과 제한 조건이 동일해야 합니다.
- 문구 해석에 차이가 없도록 "30일", "제한은 없다", "7일 전" 기준을 그대로 사용합니다.
- 제품기획팀이 문구를 조정할 경우 고객지원팀 안내 문구도 함께 갱신합니다.

## 제외 범위
이 문서는 무료 체험의 기본 조건만 다룹니다. 아래 항목은 포함하지 않습니다.

- 유료 요금제의 상세 금액과 청구 방식
- 전액 환불 가능 기간
- 솔페이 연동 세부 설정 절차
- 광고, 쿠폰, 별도 프로모션에 따른 예외 정책
- 체험 종료 후 데이터 보관 방식의 상세 운영 절차

위 항목이 필요한 경우 관련 문서에서 확인합니다. 다만 고객 응대나 화면 문구에서는 본 문서의 무료 체험 조건과 모순되는 표현을 사용하지 않습니다.

## 일정
현재 운영 기준의 반영 일정은 다음과 같습니다.

- 2026-09-18부터 무료 체험 기본 조건은 본 문서 기준으로 적용합니다.
- 제품 화면 문구, 고객 응대 문구, 릴리스 노트의 표현은 같은 기준일 내에 맞춰 정리합니다.
- 추가 변경이 필요한 경우 제품기획팀에서 변경 이력 갱신 후 관련 부서에 공유합니다.
