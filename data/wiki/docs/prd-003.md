# 솔북 예약금 결제 정책

## 배경

이 문서는 솔북 예약에 연결되는 예약금 결제와 취소 처리 규칙을 정의합니다. 대상 독자는 제품기획팀, 개발본부, 고객지원팀입니다. 본 정책은 솔북에서 예약 생성 시 고객에게 예약금 결제를 요청하는 흐름과, 예약 취소 또는 예약 상태 변경 시 예약금을 어떻게 처리하는지에 대한 기준을 설명합니다.

솔북은 매장 예약 관리 앱이며, 솔페이와 결제가 연동됩니다. 따라서 솔북 예약금 결제는 솔페이 연동 매장에서만 사용할 수 있습니다. 솔페이 연동이 없는 매장은 예약금 기능을 노출하지 않으며, 예약은 예약금 없이 운영합니다.

## 사용자 시나리오

1. 점주가 솔북에서 예약금 사용 여부와 금액을 설정합니다.
2. 고객이 예약 가능한 시간대를 선택하고 예약 정보를 입력합니다.
3. 고객은 예약 링크에서 예약금을 결제합니다.
4. 결제가 완료되면 예약은 예약금 결제 완료 상태로 확정됩니다.
5. 고객 또는 점주가 예약을 취소하면 자동환불 설정과 취소 시점에 따라 환불 여부가 결정됩니다.

점주는 예약 시작 24시간 전까지는 점주가 예약금 자동환불 옵션을 켤 수 있습니다. 이 옵션이 켜진 상태에서 정책상 자동환불 대상인 취소가 발생하면 시스템은 예약금 환불을 자동으로 요청합니다. 자동환불 옵션이 꺼져 있으면 취소 후 환불 처리는 점주가 별도로 판단합니다.

## 기능 요구사항

### 1. 사용 조건

| 항목 | 정책 |
|---|---|
| 사용 가능 매장 | 솔페이 연동 매장만 가능 |
| 적용 단위 | 예약 건별 적용 |
| 결제 주체 | 예약 고객 |

예약금 기능은 매장 단위로 사용 가능 여부를 판단합니다. 솔페이 연동이 해제되었거나 유효하지 않은 경우에는 신규 예약에 예약금 결제를 붙이지 않습니다.

### 2. 예약금 금액

예약금은 예약 건당 최소 5000원부터 최대 200000원까지 설정할 수 있습니다. 금액은 점주가 설정하며, 고객은 예약 링크에서 표시된 금액만 결제할 수 있습니다. 예약 생성 후에는 해당 예약 건의 예약금 금액을 변경하지 않습니다. 금액 변경이 필요하면 기존 예약을 취소하고 새 예약으로 다시 진행합니다.

### 3. 결제 실패 제한

예약금 결제 실패가 3회 연속 발생하면 해당 예약 링크는 30분 동안 다시 결제를 시도할 수 없습니다. 이 제한은 같은 예약 링크 기준으로 적용합니다. 제한 시간 동안 고객이 다시 접속하더라도 결제 버튼은 비활성화하거나 재시도 불가 안내를 표시합니다. 30분이 지나면 다시 결제를 시도할 수 있습니다.

### 4. 취소 및 환불 처리

자동환불은 점주가 사전에 옵션을 켠 경우에만 동작합니다. 자동환불 옵션은 예약 시작 24시간 전까지 설정할 수 있으며, 그 이후에는 변경하지 않습니다.

환불 처리 원칙은 다음과 같습니다.

1. 예약이 취소되었고 자동환불 옵션이 켜져 있으면 자동환불을 요청합니다.
2. 예약금이 결제되지 않은 예약은 환불 대상이 아닙니다.
3. 이미 환불이 완료된 예약에 대해서는 중복 환불을 요청하지 않습니다.
4. 자동환불 대상이 아닌 경우에는 고객지원팀 문의 시 점주 안내 기준에 따라 처리합니다.
