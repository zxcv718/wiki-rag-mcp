# 솔페이 영수증 재발송 기능 명세

## 배경
본 문서는 솔페이에서 결제 완료 후 영수증을 다시 발송하는 기능의 동작 조건과 운영 기준을 정리합니다. 본 기능은 가맹점이 고객 요청에 따라 영수증을 다시 전달해야 하는 상황을 처리하기 위한 목적입니다. 주 사용자는 고객지원팀이며, 제품기획팀과 개발본부는 동일 기준으로 기능을 검토하고 운영 이슈를 줄이기 위해 본 문서를 참고합니다.

영수증 재발송은 기존 결제 정보를 바탕으로 동일한 영수증 내용을 다시 보내는 기능입니다. 새로운 결제를 만들거나 결제 금액, 수신자 외의 거래 정보를 수정하는 기능은 포함하지 않습니다.

## 사용자 시나리오
1. 가맹점 또는 고객이 영수증 미수신을 사유로 고객지원팀에 재발송을 요청합니다.
2. 고객지원팀 상담원은 결제 상태를 확인합니다.
3. 결제가 "승인 완료" 상태이면 관리자 화면에서 재발송을 실행합니다.
4. 재발송 수단은 문자와 이메일 2가지이며 둘 중 하나만 선택해서 보냅니다.
5. 발송 결과를 확인한 뒤 요청자에게 처리 사실을 안내합니다.

고객지원팀이 영수증 재발송 문의를 받으면 L2 에스컬레이션 없이 관리자 화면에서 즉시 처리할 수 있습니다. 다만 결제 상태가 조건에 맞지 않거나 재발송 제한 횟수를 초과한 경우에는 즉시 처리 대상이 아닙니다.

## 기능 요구사항
### 1. 대상 결제 조건
- 영수증 재발송은 승인된 거래 중 "승인 완료" 상태의 결제에서만 사용할 수 있습니다.
- 승인 완료가 아닌 결제는 재발송 버튼을 노출하지 않거나 실행 시 차단해야 합니다.
- 재발송은 원 결제의 영수증 내용을 기준으로 수행하며, 결제 정보 자체를 변경하지 않습니다.

### 2. 발송 수단
| 항목 | 요구사항 |
| --- | --- |
| 지원 수단 | 문자, 이메일 |
| 선택 방식 | 1회 요청당 한 가지 수단만 선택 |
| 동시 발송 | 지원하지 않음 |

- 문자와 이메일 2가지 중 하나만 선택해서 보냅니다.
- 같은 요청에서 문자와 이메일을 동시에 보내지 않습니다.
- 수신 정보가 비어 있거나 형식이 맞지 않으면 발송하지 않습니다.

### 3. 재발송 제한
- 같은 결제 건의 영수증은 1시간에 최대 3회까지 재발송할 수 있습니다.
- 제한 횟수는 결제 건별로 계산합니다.
- 최근 1시간 내 재발송 이력이 이미 3회인 경우 추가 요청은 거절합니다.
- 제한 초과 시 상담원은 다른 수단으로 우회 발송하지 않고, 일정 시간 후 다시 시도하도록 안내합니다.

### 4. 운영 처리 기준
- 고객지원팀은 대상 결제와 수신 정보를 확인한 뒤 관리자 화면에서 즉시 처리합니다.
- 별도 개발 대응이나 L2 에스컬레이션은 기본 흐름에 포함하지 않습니다.
- 발송 실패가 반복되더라도 본 기능 범위에서는 재발송 가능 조건과 횟수 제한만 보장합니다.

## 제외 범위
다음 항목은 본 기능 명세에 포함하지 않습니다.
- 영수증 양식 변경
- 문자 또는 이메일 내용 편집
- 결제 금액, 승인 시각, 가맹점 정보 수정
- 복수 수신자에게 동시 발송
- 환불 거래의 영수증 재발송 정책
- 외부 협력사 인력의 운영 권한 범위
