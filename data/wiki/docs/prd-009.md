# 솔북 무료 체험 안내 (2025)

## 배경

이 문서는 솔북의 무료 체험 조건을 제품, 개발, 고객 응대에서 동일하게 안내하기 위한 기준을 정리합니다. 솔북은 매장 예약 관리 앱이며, 솔페이와 결제가 연동됩니다. 무료 체험은 신규 사용자가 실제 운영 전 기본 기능을 확인할 수 있도록 제공하는 범위로 정의합니다.

무료 체험은 유료 전환 전 사용 가능 범위를 명확히 안내하는 것이 중요합니다. 안내 문구가 채널마다 다르면 사용자 기대와 실제 동작이 달라질 수 있으므로, 본 문서의 기준을 상담, 화면 문구, 안내 자료에 동일하게 반영합니다.

## 사용자 시나리오

1. 사용자가 솔북 가입을 완료합니다.
2. 가입 직후 무료 체험 상태로 서비스를 사용할 수 있습니다.
3. 사용자는 체험 기간 동안 매장 예약 접수 기능을 사용합니다.
4. 사용자가 체험 조건 내에서 예약을 운영합니다.
5. 체험 종료 시점에는 유료 이용 여부를 결정합니다.

대표 시나리오는 다음과 같습니다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 솔북을 처음 사용하는 신규 사용자 |
| 체험 기간 | 14일 |
| 예약 가능 수 | 체험 중 100건까지 |
| 사용 목적 | 실제 매장 운영 전 기능 확인 |

고객지원팀은 사용자가 체험 범위를 문의할 경우 기간과 예약 가능 수를 우선 안내합니다. 제품기획팀과 개발본부는 화면 문구와 동작이 이 기준과 다르지 않도록 확인합니다.

## 기능 요구사항

### 1. 체험 시작

- 무료 체험은 솔북 가입 후 바로 시작되는 것으로 처리합니다.
- 사용자는 별도 결제 없이 체험을 시작할 수 있어야 합니다.
- 체험 상태 여부는 사용자에게 확인 가능한 형태로 제공해야 합니다.

### 2. 체험 기간

- 무료 체험 기간은 14일입니다.
- 체험 가능 여부 판단은 가입 시점을 기준으로 처리합니다.
- 체험 기간이 끝난 뒤에는 체험 상태로 계속 사용할 수 없도록 처리해야 합니다.

### 3. 예약 가능 범위

- 체험 중에는 예약을 100건까지 받을 수 있습니다.
- 여기서 예약 건수는 사용자가 실제로 접수한 예약을 기준으로 계산합니다.
- 예약 가능 범위에 도달한 경우에는 추가 예약 접수가 되지 않아야 하며, 사용자는 제한 사유를 화면에서 확인할 수 있어야 합니다.

### 4. 안내 문구

- 사용자에게 노출되는 안내에는 체험 기간과 예약 가능 수가 함께 표시되어야 합니다.
- 고객 응대 시에도 동일한 문구 기준을 사용합니다.
- 예시 문구는 다음과 같습니다.

```text
솔북 무료 체험은 14일 동안 제공됩니다.
무료 체험 중에는 예약을 100건까지 받을 수 있습니다.
```

### 5. 예외 처리

- 체험 중 제한에 도달했을 때 시스템 오류처럼 보이는 표현은 사용하지 않습니다.
- 체험 종료 또는 예약 한도 도달은 정상적인 이용 조건으로 안내합니다.
- 수동 연장, 개별 예외 제공, 별도 보상은 본 문서 범위에 포함하지 않습니다.

## 제외 범위

다음 항목은 이 문서에서 정의하지 않습니다.

- 유료 전환 절차와 결제 수단 상세
- 체험 종료 후 데이터 보관 방식
- 예약 취소 건의 집계 방식 세부 규칙
- 솔페이 연동 설정 절차
- 화면 문구의 디자인 배치와 시안
- 고객별 개별 프로모션 정책

위 항목이 필요할 경우 별도 기획 문서에서 정의합니다. 본 문서는 무료 체험의 기본 조건과 서비스 동작 기준만 다룹니다.

## 일정

- 기획 기준 확정일은 2025-03-10으로 합니다.
- 이 문서는 2025년 운영 기준 안내용으로 사용합니다.
- 제품기획팀은 사용자 노출 문구와 고객 안내 문서를 본 기준에 맞춰 정리합니다.
- 개발본부는 체험 기간 및 예약 수 제한이 서비스 동작에 반영되어 있는지 확인합니다.
- 고객지원팀은 문의 응대 시 본 문서 기준으로 안내합니다.
