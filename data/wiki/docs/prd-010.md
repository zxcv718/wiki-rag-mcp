# 솔페이 PG 타임아웃 안내 문구

## 배경
솔페이 결제 과정에서 PG사 응답이 지연되면 사용자는 결제가 실패한 것으로 오인하기 쉽습니다. 그러나 PRJ-204는 즉시 실패가 확정된 상태가 아니라 솔게이트가 PG사 응답을 기다리다 시간 초과된 경우를 의미합니다. 이 문서는 해당 상황에서 사용자에게 노출할 안내 문구, 자동 재조회 범위, 고객지원팀 확인 기준을 정리합니다.

본 문서의 목적은 중복 결제 오인과 불필요한 반복 시도를 줄이고, 사용자와 고객지원팀이 동일한 기준으로 상태를 확인하도록 하는 데 있습니다.

## 사용자 시나리오
1. 사용자가 솔페이 결제 화면에서 결제를 요청합니다.
2. PG사 응답이 지연되어 PRJ-204가 발생합니다.
3. 화면에는 결제 실패 문구 대신 현재 상태가 "결과 확인 중"임을 안내합니다.
4. 사용자는 같은 화면에서 결과 갱신을 기다리거나, 자동 재조회 종료 후 직접 새로고침합니다.
5. 결과가 확인되면 화면은 최종 상태에 맞게 갱신합니다.
6. 사용자가 문의하면 고객지원팀은 접수 후 승인 중복 여부를 우선 확인합니다.

## 기능 요구사항
### 1. 사용자 안내 문구
PRJ-204 발생 시 결제 화면에는 실패, 취소, 재결제 유도 문구를 우선 노출하지 않습니다. 안내의 핵심은 현재 결제가 종료되지 않았을 수 있으며 "결과 확인 중" 상태라는 점입니다.

표시 문구 예시는 아래 기준을 따릅니다.

| 구분 | 문구 |
| --- | --- |
| 기본 안내 | 결제 요청이 접수되었습니다. 현재 "결과 확인 중"입니다. |
| 보조 안내 | 네트워크 또는 PG 응답 지연으로 결과 확인이 늦어지고 있습니다. |
| 행동 안내 | 화면을 닫지 말고 최대 20초 안에 결과를 다시 확인해 주세요. |

문구는 사용자가 즉시 같은 주문을 다시 시도하도록 유도하지 않아야 합니다.

### 2. 재조회 규칙
같은 주문번호 기준 자동 재조회는 총 "2회"까지 수행합니다. 자동 재조회가 모두 끝난 뒤에는 추가 자동 재시도를 하지 않고, 사용자가 직접 화면을 새로고침하는 방식만 허용합니다.

적용 원칙은 아래와 같습니다.

1. 자동 재조회는 같은 주문번호에만 적용합니다.
2. 자동 재조회 중에는 중복 결제 가능성을 줄이기 위해 신규 결제 시도 버튼을 비활성화합니다.
3. 자동 재조회 종료 후에는 수동 새로고침 안내를 노출합니다.
4. 수동 새로고침 이후에도 결과가 확정되지 않으면 고객지원팀 문의 경로를 안내합니다.

### 3. 고객지원팀 확인 기준
고객지원팀 매뉴얼에는 PRJ-204 문의가 접수되면 "10분" 안에 승인 중복 여부를 확인하도록 적습니다. 확인 시에는 같은 주문번호 기준으로 승인 이력이 중복되었는지 먼저 확인하고, 사용자에게는 중복 결제 여부가 확인되기 전까지 재결제를 바로 권하지 않습니다.

### 4. 화면 상태 처리
PRJ-204 상태에서는 결제 완료와 결제 실패를 단정하는 색상, 문구, 아이콘을 사용하지 않습니다. 상태 확인 전까지는 중립적인 안내를 유지합니다. 또한 사용자가 페이지를 이탈해도 문의 시 주문번호로 확인할 수 있도록 주문번호는 화면에서 확인 가능해야 합니다.

## 제외 범위
이 문서는 PRJ-204 발생 시 사용자 문구와 조회 규칙만 다룹니다. 환불 정책, 정산 처리, PG사별 세부 응답 차이, 내부 운영 절차의 상세 구현, 데이터 적재 방식은 범위에 포함하지 않습니다. 고객지원팀 내부 교육 자료의 전체 문안도 본 문서에서 정의하지 않습니다.

## 일정
제품기획팀은 본 문서를 기준으로 화면 문구와 동작을 확정합니다. 개발본부는 확정 문구 기준으로 결제 화면 반영 범위를 검토합니다. 고객지원팀은 문의 응대 문구와 중복 승인 확인 절차를 매뉴얼에 반영합니다.

세부 일정은 각 조직의 릴리스 계획에 따르며, 변경이 필요하면 제품 기획 스페이스에서 문구 확정본을 기준으로 다시 협의합니다.
