# 솔페이 요금제 운영 기준

## 배경
이 문서는 솔페이의 요금제 구성과 가입 전환 운영 기준을 정리합니다. 제품기획팀, 개발본부, 고객지원팀이 동일한 기준으로 안내와 기능 반영을 수행하는 것을 목적으로 합니다.

솔페이 기본 요금제는 스타터, 스탠다드, 프로의 3단계로 운영합니다. 각 요금제는 가맹점의 거래 규모와 운영 복잡도에 맞춰 안내하며, 가입 화면과 상담 전환 화면에서도 같은 명칭을 사용합니다.

그로스 스쿼드는 가입 전환과 요금제를 맡는 스쿼드입니다. 요금제 문구, 노출 순서, 상담 전환 흐름에 변경이 필요한 경우 그로스 스쿼드가 변경안의 DRI를 지정하고, 관련 부서와 검토 범위를 정리합니다.

## 사용자 시나리오
1. 신규 가맹점이 솔페이 가입 화면에 진입합니다.
2. 사용자는 요금제 소개 영역에서 스타터, 스탠다드, 프로를 확인합니다.
3. 월 거래 규모가 작고 빠른 시작을 원하는 사용자는 스타터를 선택합니다.
4. 사용자의 최근 거래 지표가 프로 상담 전환 조건에 해당하면, 프로는 즉시 결제 대신 상담 신청 중심으로 안내합니다.
5. 고객지원팀은 동일 기준으로 가맹점 문의에 응대하고, 상담이 필요한 경우 제품기획팀과 개발본부가 합의한 화면 문구를 기준으로 설명합니다.

대표 시나리오는 아래와 같습니다.

| 상황 | 노출 기준 | 운영 방식 |
|---|---|---|
| 소규모 신규 가맹점 | 일반 가입 화면 진입 | 스타터 우선 검토를 안내합니다 |
| 성장 중인 가맹점 | 일반 가입 화면 진입 | 스탠다드 또는 프로 상담을 함께 검토합니다 |
| 고거래액 가맹점 | 최근 30일 승인 거래액 조건 충족 | 프로 상담 전환을 안내합니다 |

## 기능 요구사항
1. 요금제 구성
   - 기본 요금제는 스타터, 스탠다드, 프로의 3단계로 제공합니다.
   - 화면, 안내 문구, 고객 응대 스크립트에서 동일한 순서와 명칭을 사용합니다.

2. 스타터 운영 기준
   - 스타터 요금제는 월 거래 500건 이하 가맹점을 대상으로 합니다.
   - 스타터의 월 기본료는 19000원입니다.
   - 가입 화면과 안내 문구에는 대상 조건과 월 기본료를 함께 표시합니다.

3. 프로 상담 전환 기준
   - 프로 요금제 상담 전환 조건은 최근 30일 승인 거래액 1억원 이상입니다.
   - 해당 조건을 만족하는 경우 즉시 결제 완료보다 상담 신청을 우선 노출합니다.
   - 고객지원팀 문의 응대 시에도 같은 조건으로 안내합니다.

4. 문구 변경과 검토
   - 요금제 문구 변경안은 그로스 스쿼드가 초안을 작성하거나 취합합니다.
   - 변경안마다 DRI 1명을 지정합니다.
   - DRI는 제품기획팀, 개발본부, 고객지원팀의 확인 범위를 정리하고 반영 일정을 관리합니다.
   - 대외 노출 문구와 내부 응대 문구는 같은 의미를 유지해야 합니다.

## 제외 범위
이 문서는 요금제의 운영 기준과 가입 전환 기준만 다룹니다. 아래 항목은 포함하지 않습니다.

- 정산 상세 정책과 회계 처리 방식
- 계약서 조항과 법무 검토 절차
- 광고, 프로모션, 쿠폰 등 한시 캠페인 운영
- 솔북의 요금제 정책
- 인프라 용량 계획이나 데이터 적재 구조
