# 2026년 7월 솔페이 릴리스 노트

## 배포일

| 항목 | 내용 |
| --- | --- |
| 배포 대상 | 솔페이 |
| 배포 일자 | 2026-07-27 |
| 배포 방식 | 하늘 |
| 전환 절차 | 하늘 카나리 단계 검증 완료 후 전체 전환 |

이번 배포는 하늘에서 카나리 단계 검증을 마친 뒤 전체 전환했습니다. 초기 검증 구간에서 결제 요청, 승인 결과 수신, 관리자 화면 주요 동선을 확인했고, 이상 징후가 없어 동일 버전으로 전체 반영했습니다. 배포 중 고객 화면 중단은 없었습니다.

## 새 기능

### 1. 관리자 화면 "영수증 재발송" 추가

관리자 화면에 "영수증 재발송" 기능을 추가했습니다. 기존에는 고객이 영수증을 다시 받아야 할 때 고객지원팀이 결제 이력을 확인한 뒤 별도 안내를 해야 했습니다. 이번 변경으로 관리자 화면에서 대상 결제를 확인하고 재발송을 직접 처리할 수 있습니다.

적용 범위는 다음과 같습니다.

- 이미 승인 완료된 결제 건에 대해 사용할 수 있습니다.
- 재발송 요청 시 기존 결제 정보는 변경하지 않습니다.
- 재발송 처리 결과는 관리자 화면에서 바로 확인할 수 있습니다.

고객지원팀은 영수증 미수신 문의를 받았을 때 먼저 관리자 화면에서 재발송 가능 여부를 확인해 주시기 바랍니다.

## 개선

### 1. SP-E1001 재시도 안내 문구 단순화

SP-E1001 발생 시 고객 화면의 재시도 안내 문구를 2단계로 단순화했습니다. 기존 문구는 상황 설명과 다음 행동이 한 화면에 길게 표시되어, 같은 문의가 반복되는 경우가 있었습니다. 이번 변경에서는 고객이 바로 이해할 수 있도록 안내를 나눴습니다.

- 1단계: 현재 결제가 진행되지 않았음을 짧게 안내합니다.
- 2단계: 다시 시도할 수 있는 방법만 표시합니다.

이번 변경은 고객이 결제 실패 원인을 길게 읽지 않아도 다음 행동을 확인할 수 있도록 정리한 것입니다. 고객지원팀은 관련 문의 응대 시 화면에 표시된 두 단계 안내를 기준으로 설명해 주시기 바랍니다.

### 2. 모아 조회 범위 확대

솔게이트 호출 실패 로그는 모아에서 결제번호 기준으로 30일 동안 조회할 수 있게 바꿨습니다. 기존에는 운영 확인 시점과 로그 확인 시점이 벌어지면 조회가 어려운 경우가 있었습니다. 이번 변경으로 고객 문의나 운영 점검 시 과거 실패 이력을 같은 기준으로 확인할 수 있습니다.

조회 시 확인할 수 있는 항목은 다음과 같습니다.

- 결제번호
- 호출 시각
- 실패 여부
- 기본 오류 메시지

개발본부와 고객지원팀은 결제 실패 문의 확인 시 결제번호를 기준으로 먼저 모아에서 이력을 조회해 주시기 바랍니다.

## 버그 수정

### 1. 관리자 화면 결제 상세 진입 안정화

일부 결제 건에서 관리자 화면의 상세 진입 시 로딩이 길어지는 경우를 수정했습니다. 이번 배포에서는 결제 상세 조회 시 필요한 데이터 호출 순서를 정리해 첫 화면 응답을 안정화했습니다.

### 2. 재시도 안내 화면 문구 중복 제거

결제 실패 후 다시 시도하는 흐름에서 같은 안내 문장이 반복 노출되던 문제를 수정했습니다. 이번 수정은 SP-E1001 화면 변경과 함께 반영됐으며, 고객이 한 번에 읽어야 하는 문장 수를 줄였습니다.

## 알려진 문제

- 영수증 재발송 대상이 아닌 결제 건에서는 버튼이 보이지 않거나 실행되지 않을 수 있습니다. 이 경우 별도 오류가 아니라 사용 조건에 맞지 않는 상태입니다.
- 모아에서 결제번호로 조회할 때 입력값에 공백이 포함되면 결과가 없을 수 있습니다. 조회 전 결제번호 형식을 다시 확인해 주시기 바랍니다.
- 고객 화면 문구는 단순화됐지만, 실제 카드 승인 가능 여부는 고객의 결제 수단 상태에 따라 달라질 수 있습니다. 동일 고객이 반복 문의하는 경우 고객지원팀에서 결제 시각과 결제번호를 함께 확인해 주시기 바랍니다.
