# 솔북 예약 취소 사유 코드 명세

## 배경
본 문서는 솔북 예약 취소 시 저장하는 사유 코드와 화면 동작을 정의합니다. 취소 사유는 고객지원팀의 문의 응대, 제품기획팀의 VOC 검토, 개발본부의 데이터 해석 기준을 맞추기 위해 사용합니다. 사유 값이 화면마다 다르게 입력되면 취소 원인 집계가 달라지므로, 입력 가능한 값과 추가 입력 조건을 고정합니다.

솔북은 매장 예약 관리 앱이며, 솔페이와 결제가 연동됩니다. 따라서 예약 취소는 예약 운영 이슈와 결제 이슈를 함께 반영할 수 있어야 합니다. 본 문서는 취소 처리 시점의 저장 규칙과 조회 규칙만 다루며, 환불 정책이나 별도 정산 처리 규칙은 다루지 않습니다.

## 사용자 시나리오
1. 매장 운영자가 예약 상세 화면에서 예약을 취소합니다.
2. 시스템은 취소 사유 선택 항목을 표시합니다.
3. 운영자는 사유를 선택하고 저장합니다.
4. 사유가 중복 예약인 경우, 시스템은 BK-4010 여부를 추가로 확인받습니다.
5. 저장된 사유는 예약 이력과 상세 화면에서 조회할 수 있습니다.
6. 예약 종료 후 180일 동안 수정할 수 없고 조회만 가능하다.

위 시나리오에서 BK-4010은 솔북에서 같은 예약 슬롯이 두 번 잡힌 에러를 뜻합니다. 해당 체크는 중복 예약 중에서도 오류 연관 건을 구분하기 위한 용도입니다.

## 기능 요구사항
### 1. 사유 코드 정의
솔북 예약 취소 사유 코드는 고객 요청, 매장 사정, 중복 예약, 결제 실패의 4개로 고정한다.

| 코드명 | 화면 표시 문구 | 설명 |
|---|---|---|
| CUSTOMER_REQUEST | 고객 요청 | 고객이 일정 변경, 단순 취소 등을 이유로 취소한 경우입니다. |
| STORE_ISSUE | 매장 사정 | 매장 휴무, 인력 부족, 운영 불가 등 매장 사유로 취소한 경우입니다. |
| DUPLICATE_BOOKING | 중복 예약 | 동일 시간대 예약이 중복으로 접수된 경우입니다. |
| PAYMENT_FAILURE | 결제 실패 | 결제 연동 과정에서 예약 확정이 불가해 취소한 경우입니다. |

### 2. 화면 동작
- 취소 사유는 단일 선택으로 입력합니다.
- 기본 선택값은 두지 않습니다.
- 사유를 선택하지 않으면 저장할 수 없습니다.
- 중복 예약 사유를 선택하면 BK-4010 연관 여부를 확인하는 체크박스를 추가로 보여 준다.
- 위 체크박스의 문구는 `BK-4010 연관 건입니다`로 표시합니다.
- 중복 예약이 아닌 다른 사유를 선택하면 해당 체크박스는 노출하지 않습니다.
- 체크박스 값은 참 또는 거짓으로 함께 저장합니다. 중복 예약이 아닌 경우에는 값 없이 저장합니다.

### 3. 조회 및 수정
- 저장된 취소 사유는 예약 상세 화면과 취소 이력에서 조회할 수 있습니다.
- 취소 사유는 예약 종료 후 180일 동안 수정할 수 없고 조회만 가능하다.
- 조회 화면에서는 저장된 사유 문구와, 중복 예약인 경우 BK-4010 연관 여부를 함께 표시합니다.

### 4. 검토 기준
제품기획팀은 매달 첫 영업일에 전월 취소 사유 비율을 VOC와 함께 검토한다. 검토 목적은 사유 분포의 급격한 변화와 고객 불만의 상관 여부를 확인하는 데 있습니다. 개발본부와 고객지원팀은 필요 시 해당 검토 결과를 참고할 수 있습니다.

## 제외 범위
다음 항목은 본 문서의 범위에 포함하지 않습니다.
- 취소에 따른 환불 금액 계산
- 취소 알림 발송 문구
- 예약 취소 권한 정책
- 취소 사유 통계 화면의 상세 구성
- 외부 협력사 사용 화면
