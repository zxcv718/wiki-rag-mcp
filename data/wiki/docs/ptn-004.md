# 협력사 보안 서약과 교육 안내

## 대상과 원칙
이 문서는 레드브릭소프트에서 파견 온 협력 개발자가 업무 시작 전에 완료해야 하는 보안 서약 제출과 필수 교육 기준을 안내합니다. 대상은 외부 협력사 인력 중 개발 업무를 수행하는 인원이며, 개발본부에서 온보딩 확인에 참고합니다.

모든 외부 협력사는 첫 출근 전까지 보안 서약서를 제출해야 합니다. 서약서는 서명일로부터 1년 동안 유효합니다. 유효기간이 지난 뒤에도 업무가 계속되면 갱신본을 다시 제출해야 합니다. 제출이 확인되지 않으면 계정 개설 절차를 진행하지 않습니다.

## 첫날까지 할 일
첫 출근 전 또는 첫날 업무 시작 전에 아래 항목을 모두 완료합니다.

1. 보안 서약서를 작성하고 서명합니다.
2. 서명한 서약서를 정보보안팀 메일로 제출합니다.
3. 교육 대상자로 등록되었는지 개발본부 담당자에게 확인합니다.
4. 보안 교육 영상을 시청합니다.
5. 마지막 확인 퀴즈를 완료합니다.

계정은 교육 완료 확인 후 열립니다. 협력 개발자는 계정이 열리기 전에 30분 분량의 보안 교육 영상을 시청하고 마지막 확인 퀴즈에서 8문항 중 7문항 이상 맞아야 합니다. 기준에 미달하면 재응시 후 통과해야 하며, 통과 전에는 업무용 계정을 사용할 수 없습니다.

| 항목 | 기준 | 확인 주체 |
| --- | --- | --- |
| 보안 서약서 제출 | 첫 출근 전까지 | 정보보안팀 |
| 서약서 유효기간 | 서명일로부터 1년 | 정보보안팀 |
| 교육 영상 시청 | 계정 개설 전 완료 | 정보보안팀, 개발본부 |
| 확인 퀴즈 | 8문항 중 7문항 이상 정답 | 정보보안팀 |

제출 문의는 security@saesol.example로 보냅니다. 메일 제목은 `협력사 보안 서약 제출 / 소속 / 이름` 형식으로 작성합니다.

## 첫 주에 지킬 사항
첫 주에는 테스트 과정에서 다루는 데이터 범위를 특히 주의합니다. PII 등급은 개인정보 민감도를 1~3등급으로 나눈 사내 기준이며, 1등급이 가장 민감합니다.

PII 등급 1등급 또는 2등급 데이터가 있는 화면을 테스트해야 하는 경우에는 마스킹된 샘플만 사용할 수 있고 원본 다운로드는 금지됩니다. 화면 확인, 재현 테스트, 캡처 공유가 필요한 경우에도 원본이 드러나지 않도록 마스킹 상태를 유지해야 합니다. 테스트 자료가 불분명하면 개발본부 담당자와 정보보안팀에 먼저 확인합니다.

또한 개인 저장소, 개인 메일, 개인 메신저로 업무 자료를 옮기지 않습니다. 업무 중 알게 된 고객 정보나 정산 관련 정보는 업무 목적 범위에서만 확인합니다.

## 둘째 주에 확인할 사항
둘째 주에는 본인이 제출한 서약과 교육 이수 상태가 정상 반영되었는지 다시 확인합니다. 개발본부 담당자는 협력 개발자의 시작일 기준으로 누락 여부를 점검하고, 누락이 있으면 즉시 보완을 요청합니다.

보안 서약과 교육 이수 기록은 정보보안팀이 분기마다 점검하며, 누락자가 있으면 해당 계정을 당일 오후 6시까지 일시 중지합니다. 계정이 중지되면 개발 업무, 테스트, 문서 열람이 모두 제한될 수 있으므로 누락 안내를 받으면 같은 날 안에 조치합니다. 서약서 유효기간 만료가 예정된 경우에도 만료 전에 갱신본을 제출해야 합니다.

## 도움받을 곳
- 보안 서약 제출, 교육 이수 확인, 데이터 취급 기준 문의: 정보보안팀, security@saesol.example
- 온보딩 일정, 업무 시작일, 개발본부 배정 문의: 개발본부 담당자
- 테스트 중 데이터 노출 우려가 있는 경우: 작업을 멈추고 정보보안팀과 개발본부 담당자에게 즉시 알립니다.

문의할 때는 소속 회사, 이름, 시작 예정일 또는 시작일, 문의 내용을 함께 적습니다. 답변 전까지 기준이 불명확한 작업은 진행하지 않습니다.
