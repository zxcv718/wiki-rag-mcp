# 솔패스 접근 로그 보존 기준

## 목적
이 문서는 솔패스 접근 로그의 보존 기간과 조회 승인 요건을 정해 원격 접속 이력의 추적 가능성을 확보하고, 로그 원문 접근을 최소 권한으로 통제하기 위한 기준을 정의합니다. 솔패스는 제로트러스트 원격 접속 서비스로, 솔넷 VPN을 대체합니다.

본 기준은 정보보안팀이 운영 점검과 사고 대응에 필요한 범위에서 로그를 관리할 수 있도록 하되, 불필요한 원문 열람과 과도한 공유를 제한하는 것을 목적으로 합니다.

## 적용 범위
본 기준은 다음 대상에 적용합니다.

- 솔패스에서 생성되는 사용자 접근 로그
- 솔패스의 관리자 작업 이력을 포함한 관리자 감사 로그
- 로그 보존, 조회, 점검, 결과 공유에 관여하는 정보보안팀
- 로그 조회 결과를 전달받는 경영진·팀장 및 개발본부

외부 협력사의 솔패스 사용 이력이 존재하는 경우에도 동일한 보존 및 조회 기준을 적용합니다.

## 통제 항목
### 1. 로그 보존 기간
로그 종류별 보존 기준은 아래와 같습니다.

| 로그 종류 | 보존 기간 | 비고 |
| --- | --- | --- |
| 솔패스 접근 로그 | 180일 | 사용자 접속, 인증 시도, 접속 실패 이력을 포함합니다 |
| 관리자 감사 로그 | 365일 | 관리자 설정 변경 및 관리 작업 이력을 포함합니다 |

관리자 감사 로그는 이번 달 변경으로 기존 270일에서 365일로 연장합니다. 보존 기간이 만료된 로그는 운영상 필요한 보관 구간이 끝난 뒤 삭제하거나 재사용이 불가능한 형태로 처리합니다.

### 2. 로그 원문 조회 통제
솔패스 로그 원문 조회는 정보보안팀 내부 승인 절차를 거친 경우에만 가능합니다.

1. 로그 원문 조회는 정보보안팀 내 담당자와 검토자를 포함한 2명 승인 후 가능합니다.
2. 승인 요청에는 조회 목적, 조회 범위, 필요한 기간을 명시합니다.
3. 개발본부에는 집계 결과만 공유할 수 있으며, 개별 계정 식별이 가능한 로그 원문은 공유하지 않습니다.
4. 경영진·팀장에게 보고가 필요한 경우에도 원칙적으로 요약 통계와 판단 결과 중심으로 전달합니다.

사고 조사나 법적 대응 등으로 예외적 상세 확인이 필요한 경우에도 원문 조회 자체는 동일하게 2명 승인 기준을 유지합니다.

## 예외 승인
기본 기준을 벗어나는 로그 보존 연장이나 추가 조회가 필요한 경우에는 정보보안팀이 사유를 기록하고 승인 이력을 남겨야 합니다.

- 보안 사고 조사로 특정 기간 로그의 보존 연장이 필요한 경우
- 감사 대응으로 관리자 감사 로그의 추가 확인이 필요한 경우
- 외부 기관 제출 등으로 조회 사실과 범위를 명확히 남겨야 하는 경우

예외 승인 시에는 조회 목적, 대상 기간, 승인자, 처리 결과를 문서로 남깁니다. 개발본부 요청만으로는 로그 원문을 직접 제공하지 않으며, 필요한 경우 정보보안팀이 검토 후 집계 결과로 대체합니다.

## 점검
정보보안팀은 월 1회 솔패스 접근 로그를 점검합니다. 정기 점검 항목은 다음과 같습니다.

1. 실패 로그인 상위 20개 계정을 추출합니다.
2. 반복 실패, 시간대 편중, 다수 위치 시도 등 이상 패턴 여부를 확인합니다.
3. 이상 징후가 확인되면 추가 분석 필요 여부를 판단합니다.
4. 점검 결과는 월별 기록으로 남기고, 필요한 경우 경영진·팀장에 보고합니다.

이번 달 변경으로 실패 로그인 점검 대상은 기존 상위 10개 계정에서 20개 계정으로 확대합니다. 개발본부와의 공유가 필요한 경우에도 계정별 원문이 아닌 집계 결과와 이상 여부만 전달합니다.
