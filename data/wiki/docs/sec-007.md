# 모아 관리자 권한 월간 감사

## 개요
본 문서는 모아 관리자 권한 보유 현황과 월간 감사 결과를 기록합니다. 모아는 로그·지표·트레이스를 모으는 사내 관측 플랫폼입니다. 감사 결과는 권한 최소화와 운영 계정 정합성 확인을 목적으로 관리합니다.

월간 감사는 매달 셋째 주 수요일 오전에 수행하고, 결과는 정보보안 스페이스에 3영업일 안에 게시합니다. 본 문서는 2026-07 감사 기준 결과를 정리한 문서이며, 최종 수정일 시점의 운영 기준만 반영합니다.

## 점검 범위와 기간
이번 점검은 운영 중인 모아 관리자 권한 보유 계정을 대상으로 수행했습니다. 점검 범위에는 정보보안팀, 플랫폼·SRE팀, 데이터팀 소속 계정이 포함됩니다. 외부 협력사인 레드브릭소프트 소속 계정은 모아 관리자 권한을 가질 수 없으므로, 감사 시에는 관리자 권한 여부가 아니라 조회 전용 권한 보유 여부만 확인합니다.

점검 항목은 아래와 같습니다.

1. 현재 관리자 권한 보유 인원 확인
2. 소속 조직과 권한 부여 목적 일치 여부 확인
3. 접근 재인증 상태 확인
4. 미응답 또는 불필요 권한 계정 회수 여부 확인
5. 외부 협력사 계정의 조회 전용 권한 유지 여부 확인

접근 재인증은 분기마다 권한 보유자가 계속 필요한지 확인하는 절차를 말합니다.

## 감사 결과
2026-07 감사 기준으로 모아 관리자 권한 보유자는 총 11명입니다. 조직별 분포는 아래와 같습니다.

| 구분 | 인원 | 비고 |
|---|---:|---|
| 정보보안팀 | 3명 | 감사 및 보안 운영 목적 |
| 플랫폼·SRE팀 | 6명 | 운영 관리 목적 |
| 데이터팀 | 2명 | 데이터 확인 및 운영 지원 목적 |
| 합계 | 11명 |  |

이번 감사에서는 접근 재인증 미응답 상태로 남아 있던 계정 2개를 발견했습니다. 해당 계정은 같은 날 오후 2시에 권한을 회수했습니다. 회수 완료 후 관리자 권한 목록과 감사 기록을 함께 대조해 반영 상태를 확인했습니다.

레드브릭소프트 소속 계정은 별도 확인 결과 관리자 권한 보유 사례가 없었습니다. 다만 감사 절차상 해당 계정은 조회 전용 권한 보유 여부만 점검 대상으로 유지합니다.

## 조치 내역
이번 감사에서 수행한 조치는 아래와 같습니다.

1. 접근 재인증 미응답 계정 식별
2. 소속 및 사용 목적 재확인
3. 같은 날 오후 2시에 권한 회수
4. 회수 후 관리자 권한 목록 재조회
5. 감사 결과 문서화 및 정보보안 스페이스 게시 준비

이번 회수 건은 즉시 조치가 가능한 상태였으며, 추가 승인 대기 없이 처리했습니다. 회수된 계정은 필요 시 소속 팀장의 사유 확인과 정보보안팀 검토를 거쳐 다시 요청해야 합니다.

## 후속 계획과 기한
다음 월간 감사도 동일하게 셋째 주 수요일 오전에 수행합니다. 감사 담당자는 수행일 당일에 원본 점검 기록을 정리하고, 결과 문서는 3영업일 안에 정보보안 스페이스에 게시합니다.

추가로 아래 사항을 유지합니다.

- 접근 재인증 미응답 계정은 감사 당일 우선 확인합니다.
- 관리자 권한이 필요 없는 계정은 확인 즉시 회수 대상으로 분류합니다.
- 레드브릭소프트 소속 계정은 관리자 권한 부여 불가 원칙을 유지합니다.
