# 결정 기록 (ADR) 목록

형식: 맥락, 선택지, 결정, 감수한 비용, 재검토 조건. 결정이 바뀌면 기존 파일을 지우지 않고 상태를 `대체됨`으로 바꾼 뒤 새 ADR을 추가합니다.

이 폴더의 파일은 `scripts/adr_sync.py`가 설계서(`docs/design.md`)에서 만듭니다. 고칠 때는 설계서를 고칩니다.
