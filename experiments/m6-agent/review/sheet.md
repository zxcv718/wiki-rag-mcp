    merchant_id,
    business_date,
    SUM(CASE
        WHEN transaction_type = 'APPROVAL' THEN amount
        WHEN transaction_type = 'CANCEL' THEN -amount
        ELSE 0
    END) AS net_amount

GROUP BY merchant_id, business_date;

-- 2. 정산 원장 settlement_amount 확인

    merchant_id,

FROM settlement_ledger
WHERE merchant_id = '<가맹점 식별값>'

### [hr-014] 연차 사용과 승인 기준 (버전 6, 수정 2024-03-09)

[신청·처리 절차] 1. 연차 사용자는 사용 일자와 단위를 정해 연차를 신청합니다.

3. 연속 사용 기간이 길거나 같은 날짜에 팀 내 사용자가 많은 경우, 팀장은 업무 공백 계획을 확인합니다.

   1. 신청 일자와 단위가 맞는지  
   2. 인수인계가 필요한 업무가 있는지  
   3. 같은 팀의 동시 부재 인원이 과도하지 않은지
